# 初版の検証と残る確認事項

確認日：2026-09-13。対象は今回作成した進め方・三つの skill・テンプレート・入口。自己レビューと机上実行であり、独立したモデルによる実行評価ではない。

## 完成したもの

要求探索から実装引き継ぎまでのレールと、既製品の導入・見送りの出口を用意した。原文・根拠・現在案・判断履歴・未決事項を保存して再開できる。日常担当 sol が、工程ごとの問いと進める条件を読んで使える具体性を目指した。

terra へ渡す確定作業の契約、astra へ持ち込む相談材料も定義した。モデルの自動切替や外部 plugin への依存は導入していない。

## 行動について確認した範囲

[シナリオ](scenarios.md) を進め方・skill の分岐へ照合し、次を確認した。入力から別モデルを実行して得た出力ではない。

| ケース | 机上で得られる進行・結論 | 確認した規則 |
| --- | --- | --- |
| A 個人用 | 要求と比較から小さな自作へ進める。四点の整合を具体例で追える | 不要な収益モデルを強制しない。詳細は worked-example.md |
| B 他人へ販売 | 公開調査・代案・価格仮説・小さな検証計画を作れる。未検証需要の許容が残れば確認待ち | ペルソナ想定を実証と混同しない |
| C 既製品 | 設定・接続・確認・復旧を詰め、導入準備完了へ進める | 自作の DB やバックエンドを強制しない |
| D 未回答 | 主場面・比較・費用幅は進め、所有者・権限の確定だけ止める | 未回答の依存範囲を明記して独立作業を継続 |
| E 検索不能 | 要求・条件付き案・代替手段・確認手順を残せる | 未確認の外部機能を捏造しない |
| F 前提変更 | 育成中へ戻して共有の影響を更新し、再レビューする | 完了状態と旧レビューを失効させる |
| G 見送り | 理由と再検討条件を残して終了する | 空の設計・実装計画を作らない |
| H レビューのみ | 指摘と対応方針を返す | レビューを設計変更の権限と混同しない |

[貸出記録の例](worked-example.md) では、要求、費用、範囲、画面、保存データ、処理責務、登録再試行・返却取消・復元失敗まで一貫して記述できることを確認した。この例は架空で、採用した技術や実在製品の成立を検証したものではない。

## 機械的な確認

- skill-creator の `quick_validate.py` で三つの SKILL.md がすべて有効。
- 19個の Markdown ファイルにある33本のローカル参照先がすべて存在することを確認。三つの自動発見用リンクが意図した skill 正本を指すことも確認。
- 費用比較の例と貸出記録例の時間計算を再計算し、一致を確認。`git diff --check` で既存ファイルへの差分に問題なし。
- 製品実装は今回の対象外。アプリケーションテストは実行していない。

## この初版で残る確認事項

リポジトリを使い始めるために、今すぐユーザーが答える必要のある未決事項はない。次の点は、実案件の入力や利用結果があって初めて確定できる。

| 項目 | 現時点の扱い | 確認するタイミング |
| --- | --- | --- |
| 最初に育てる実際のアイデア | 架空の案件を ideas/ に登録しない | 最初の投入時 |
| 好み・満足水準・許容する費用や時間 | 案件ごとの入力から抽出し、不足は条件付き案にする。共通値を勝手に設定しない | 比較や到達点を左右するとき |
| 実装先の技術・規約 | 持ち運べる引き継ぎを標準とし、実装先依存の判断を区別する | 実装先が判明したとき |
| sol での自律運用の品質 | 読み順・具体例・分岐を整備済み。sol 実行での実証は未実施 | 最初の実案件、または独立した実行評価時 |
| このレールで負担が減るか | ユーザーの判断時間や手戻りの実測はない | 一件を実装・運用へ引き渡した後 |

これらを埋めるために初回から質問票を出さない。実際に判断を変える時点で、推奨案と影響を添えて必要な情報だけをまとめる。

## 改善・差し戻し条件

実案件で、ユーザーへ判断を戻しすぎる、資料を埋めるだけで体験が決まらない、上流比較が形式化する、確認待ちでも進められる作業を残す、といった振る舞いが出たら、その実例を入力として improve-rail を使う。初版の章やファイル数を維持することを目的にしない。

ドキュメントレビューは tumeda-dev の「読み終えた人が何を実行できるか」「節の存在だけで通さない」という観点を部分的に利用した。逐次承認ゲートや同 plugin の作業ディレクトリ契約は採用していない。
