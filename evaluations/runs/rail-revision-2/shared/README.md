## 自律的に確定したこと

- 対象は一世帯・二人・最大50品目、品名と0以上の整数個数のみ。
- 一覧で `− / 個数 / ＋` を押し、クライアントから絶対個数ではなく差分を送る。
- 同時更新、通信後の再送、権限、50品目上限、0未満、同名、訂正、退会・復旧の動作を確定した。
- Supabase Auth/Postgres と静的フロントエンドを採用し、Cloudflare Pages へ直接配備する。無料枠で月額0円を見込むが、無料枠変更時は月1,000円を超える有料移行を自動承認しない。
- 初回は手動 CSV エクスポートで復旧可能性を確保する。賞味期限、栄養、通知、自動購入、バーコード、献立は非目標。
