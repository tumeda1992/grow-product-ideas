## 再開する人へ

直前に確定したこと：AI製品そのものの開発ではなく、問題選択と価値検証を兼ねる7食の手動コンシェルジュ試行を次善コストの小さい案として自律確定した。入力不足をAIに推測させず、確認または安全な複数候補へ戻す。

次の一手：Q1を一問だけ確認する。回答後、必要ならQ2〜Q4の該当項目だけ確認し、`design.md` の代表例を実データに置き換えて7食試行を行う。

再確認する前提・古くなりうる根拠：特定サービスの機能・料金は未調査。利用するサービスを選ぶ時点で、公式の地域、プラン、データ利用・削除条件を確認する。
