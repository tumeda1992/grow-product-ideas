## 状態・次の一手

独立受取レビュー I1（全mutationの再送契約）と I2（改名前後名の履歴）は、自作案を採用しないため未決のまま残さず、自作API・独自履歴・改名/アーカイブ仕様を今回の範囲から除いた。Grocy の確認済み stock transaction と既存認証だけを使う。

次の一手は、外部登録・課金の許可後に handoff.md を上から実施し、X1を最初の実データ投入前に判定すること。未実行の実装テストはない（製品実装をしないため）。未実行の導入・実操作確認は、実インスタンス、二人のログイン、X1、バックアップ取得・復元、一週間利用である。
