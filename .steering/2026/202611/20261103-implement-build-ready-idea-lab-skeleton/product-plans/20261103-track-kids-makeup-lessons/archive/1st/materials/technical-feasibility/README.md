## 中身

- 期限と残り回数の計算: 日付の計算と数え上げであり、技術的な不確実性は無い（材料`core-logic`の三つの規則の例で、手計算で期限と残り回数が出ることを確かめた）。
- LINEの通知: LINE公式アカウントから家族の二人へ送る。無料の枠（月200通とする記事が複数）に対し、送る量は月に十数通の見込み（振替が月2〜3件、一件あたり2回、二人へ）で、枠に収まる。Messaging APIでの送信が無料の枠に数えられる仕様は未確認だが、収まらなくても月の上限に達するだけで、取り返しのつかない影響は無い。

動かして確かめることはしていない。動かさないと分からない挙動のうち、出口や作るものを変えるものは無いと判断した。
