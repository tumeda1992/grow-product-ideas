# target-user-voices: 習い事の振替を期限切れにしてしまう親の困りごと

## 要求した問いと粒度

| 問いのidentifier | 問いの文面 | 求めた粒度 | この材料で満たしたか |
| --- | --- | --- | --- |
| `why-to-build/pain-to-solve` | 解きたい痛みは何で、今どうしのいでいるか（このアイデアでは「振替を期限切れにするのは、どの場面で何が見えていないからか」） | 同じ痛みを持つ人が何に困り、今何をしているかが分かる程度。利用者は家族（自分と妻）なので参考 | 満たした |

## 中身

### 使う人の像

利用者は自分と妻の二人である。子ども二人が別々の習い事に通い、欠席した分の振替は教室ごとに回数の上限と期限が違う。妻が頭の中と各教室のアプリで把握しており、自分は残り回数も期限も分からないため、予約を代わりに取れない。

### 集めた声

| どこで見たか | 何に困っているか | 今どうしのいでいるか |
| --- | --- | --- |
| 振替の可否についての解説記事（ファイナンシャルフィールド） | 振替を認めない教室もあり、規約は教室ごとに違う | 教室の規約を確認する |
| 教室の振替の案内（申込フォーム、スイミングスクールの資料） | 振替は数日前までの予約が条件、休校日の振替は事前予約が前提、曜日やクラスで振替不可の枠がある | 教室の決まりに従って予約する |
| 教室向けの振替管理アプリ（できた!DEKITA、みんなのれっすん等） | 教室側では振替の期限と残数の管理が要るため、教室向けの道具がある | 教室の道具であり、親が複数の教室をまとめて見る道具ではない |

### 声から読めること

- 振替の規則（回数の上限、期限の基準、予約の締切）は教室ごとに違う。
- 複数の教室の振替を、親の側でまとめて把握する声や道具は見つからなかった。

## 確かめた方法と限界

- 一般通説では利用者へのインタビューで得るものを、ウェブ上の記事と教室の案内で代替した。探した場所はウェブ検索（「習い事 振替 管理 アプリ 期限 回数」「習い事 振替 期限切れ 消化できない」）。親の個人の声（SNS、掲示板）は見つからず、読めていない。
- 落ちる精度: 親の困りごとは、記事ではなく教室の案内から推し量っている。痛みの量は利用者役の回答に頼る。
