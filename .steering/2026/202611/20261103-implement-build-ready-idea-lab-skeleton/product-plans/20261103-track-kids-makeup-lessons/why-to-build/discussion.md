# なぜ作るか層の決定過程（振替の件）

## 論点1: 妻の直近の失効の一回と、ふだんの一週間と、どうなっていたいか

**ステータス:** 決定

**種別:** 認識合わせ

### イテレーション0（論点1）: 痛む人の語りを取る

#### 提案0（論点1）

依頼した利用者は夫だが、振替を覚えている負担を最も持つのは妻である。痛みを夫の見立てのまま書かないため、妻に、次を語ってもらってほしい。夫が聞いた答えとして書く。

| 聞くこと | 答えで何が変わるか |
| --- | --- |
| 直近に振替を失効させた一回を、時系列で、その時何をし、何を考え、何を感じたか | 痛みの解像度。核心が、失効なのか、覚えておく負担なのか、別のものか |
| ふだんの一週間の中で、振替のことをいつ、どう扱っているか | 痛みが続く場面と、今のしのぎ方の破れ目 |
| どうなっていたいか | アウトカムの姿の元。全部を手放したいのか、一部なのか |

あわせて、夫に聞きたい。妻から振替の話を聞いた時、どう思うか。いつなら予約できるか。習い事は、あと何年続きそうか。

#### 検討記録（論点1・イテレーション0）

起点: [層の記録](README.md)の決め方の2（痛む人の体験に潜り、広げ切る）。前の記録（[archive/2nd](../archive/2nd/why-to-build/discussion.md)）は、痛みを夫の答え（「管理は妻が頭の中でやっていて、私は残り回数も期限も分からない」）から書いており、妻の語りを取っていなかった。

#### 提案0へのフィードバック（論点1）

**結果:** 回答

妻（夫が聞いた答え）:

> 先月、英会話の振替を失効させた。12月に娘が熱で休んだ分のチケット。60日あると思って安心してたら、年末年始と、息子のスイミングの振替と、ピアノの発表会の準備が重なって、頭から抜けてた。2月の頭にアプリを開いたら期限切れになってた。2,500円がもったいないのもあるけど、娘に「振替、行けなくなっちゃった」って言うのが嫌だった。あなたに言ったら「言ってくれれば予約したのに」って言われて、それがまた嫌だった。言うって、何を？って思った。
>
> 欠席の連絡は、朝のバタバタの中でやる。振替の残りは、だいたいでしか覚えてない。週末にまとめて確かめようと思って、できない週もある。スイミングは月2回までだから、月末になると「今月まだ使える？」って気になる。
>
> 自分が覚えていなくても大丈夫だと思えたらいい。全部あなたにやってほしいわけじゃない。ピアノは先生とのやりとりがあるから自分でやりたい。スイミングと英会話は、あなたが自分で気づいて取ってくれたら助かる。

夫:

> 手伝いたいけど、何がいつまでなのか分からない。言われればやる。でも、妻にとっては、言うこと自体が負担らしい。平日の夜なら予約できる。スイミングは上の子が小学校を出るまで（あと3年）、英会話は下の子があと5年くらい、ピアノはたぶん続く。学校のプリントの提出期限も妻が全部覚えてるけど、あれは紙で来るから別かな。

（ユーザー役。振替の家族は自演の設定であり、assistantが想定して書いた）

### 決定（論点1）

妻の語りと夫の答えを、層の記録の決め方の2の場面の表と入口の表に書いた。妻は全部を手放したいのではなく、ピアノは自分でやり、スイミングと英会話は夫が自分で気づいて取ってほしい。夫は平日の夜なら予約できる。習い事は、スイミングがあと3年、英会話があと5年、ピアノは続く見込みである。

## 論点2: 痛みの核心を、頼むことまで妻の仕事になっていることに置く

**ステータス:** 決定

**種別:** 提案

### イテレーション0（論点2）: 核心

#### 提案0（論点2）

核心を、「振替について知っておくべきことが妻の頭の中にしかなく、夫は自分では気づけないため、頼むことまで含めて妻が担っている」に置く。失効、子どもへの申し訳なさ、何もない日の気がかりは、ここから生まれる。

**発案者の視野の外にあった点:** 前の記録の核心は「妻だけが担い、夫が代われない」だった。夫は「言われればやる」と代われるつもりでいたが、妻の語りでは、頼むこと自体が妻の仕事として残っていた（「言うって、何を？」）。核心を「代われる」で止めると、夫が頼まれて動く形でも解けたことになり、妻の頭の中のものは残る。

#### 検討記録（論点2・イテレーション0）

起点: [層の記録](README.md)の決め方の3と4（吸い出す、核心を選ぶ）。もう一段「なぜ妻の頭の中にしかないか」を問うと、欠席の連絡が妻を通ること、家事の分担へ降りるが、振替を越えるため、ここで止める。

#### 提案0へのフィードバック（論点2）

**結果:** 合意

> そう。頼まなくても動いてくれるのが大事。

（ユーザー役。夫が妻に確かめた答え）

### 決定（論点2）

痛みの核心は、振替について知っておくべきことが妻の頭の中にしかなく、夫は自分では気づけないため、頼むことまで含めて妻が担っていること、とする。

## 論点3: アウトカムの大きさと測り

**ステータス:** 決定

**種別:** 提案

### イテレーション0（論点3）: どこまでを含め、何で近づいたと見るか

#### 提案0（論点3）

| 決めること | 案 |
| --- | --- |
| 含めるもの | 三つの教室の振替 |
| 外すもの | 学校のプリントの提出期限（同じ形だが、紙で来て出どころが違う。広げる候補として残す）。予約そのものの代行（使い切るのに要らない）。家事の分担の全般（振替を越える） |
| 測り | 核心: 妻に頼まれずに、夫が自分で気づいて予約した回数。症状: 失効が年約5回から0回になる。気持ち: 三か月後に妻に、覚えていなくても大丈夫と思えているか、こっそりアプリを確かめていないかを聞く。失効を子どもや夫に言いにくいことが起きていないか |

**発案者の視野の外にあった点:** 着想と動機は失効だけを測りにしていた。核心が頼むことにあるなら、失効が0回でも、妻が毎回夫に頼んでいれば解けていない。核心の測り（夫が自分で気づいて予約した回数）が要る。

#### 検討記録（論点3・イテレーション0）

起点: [層の記録](README.md)の決め方の4（大きさを選ぶ、測りを付ける）。

#### 提案0へのフィードバック（論点3）

**結果:** 合意

> それでいい。プリントは、振替がうまくいったら考える。

（ユーザー役）

### 決定（論点3）

アウトカムの大きさと測りを、提案0のとおりにする。学校のプリントは、広げる候補として残し、振替がうまくいった後に考える。

## 論点4: なぜ作るか層を閉じる

**ステータス:** 決定

**種別:** 確認

### イテレーション0（論点4）: 層の閉じ

#### 提案0（論点4）

`why-to-build.md`の「この層の閉じ」に沿って、次を確かめてほしい。

| 確かめること | この件で |
| --- | --- |
| 痛みの核心と、それを痛む人の語りから取ったか | 核心は、頼むことまで妻の仕事になっていること（論点2）。妻の語りから取った（論点1。夫が聞いた答え） |
| アウトカムの姿（言い分）と大きさ | 正本の[アウトカム](../README.md#アウトカム)。言い分は四つ。三つの教室の振替を含め、学校のプリント等を外した（論点3） |
| 近づいたかの測り | 核心、症状、気持ちのそれぞれ（論点3） |
| 作ることで得たいものの内訳と強さ | 痛みを解くこと、作る楽しみ。どちらも、それだけでやる意味が残る。この題材で作りたい |

この層を閉じると、何が成り立てばよいか層とどう解くか層は、仮のアウトカムで閉じていたため、差し戻しで確かめ直すことになる。

#### 検討記録（論点4・イテレーション0）

起点: [層の記録](README.md)の確認。

#### 提案0へのフィードバック（論点4）

**結果:** 合意

> それでいい。

（ユーザー役）

### 決定（論点4）

なぜ作るか層を閉じる。アウトカムが仮のものから変わったため、何が成り立てばよいか層へ差し戻す。
