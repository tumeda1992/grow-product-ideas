# なぜ作るか（振替の件の層の記録）

- 状態: 閉じた（[論点4](discussion.md#論点4-なぜ作るか層を閉じる)）
- 決めるもの: 正本の[なぜ作るか](../README.md#なぜ作るか)

## 受け取った物差し

受け入れ時の入力（正本の[受け入れ時の入力](../README.md#受け入れ時の入力)）。この層の前に層は無い。

## 決め方

### 1. 受け取った言葉を仕分ける

| 入力 | 言葉 | 仕分け | 扱い |
| --- | --- | --- | --- |
| アイデア | 子どもの習い事の振替の期限と残り回数を管理したい | 手段（管理）。中に症状の手がかり（期限、残り回数） | 手段は、どう解くか層へ預ける。なぜ期限と残り回数なのかを、潜る入口にする |
| 動機 | 失効をなくしたい | 症状 | なぜ失効するかを、潜る入口にする |
| 動機 | こういうのを作るのは好き | 楽しみ | 作ることで得たいものへ |
| 着想 | 期限の前にLINEで通知が来ればいい | 手段 | どう解くか層へ預ける。なぜLINEか（毎日見る所に来てほしい）を、潜る入口にする |

### 2. 痛む人の体験に潜り、広げ切る

声の出どころ: 依頼した利用者は夫である。最も重い痛み（振替を覚えている負担）を持つのは妻であり、夫が妻に聞いた答えとして語りを取った（[論点1](discussion.md#論点1-妻の直近の失効の一回とふだんの一週間とどうなっていたいか)）。

| 場面 | 行い | 頭の中 | 気持ち | 誰の |
| --- | --- | --- | --- | --- |
| 子どもが熱を出した朝 | 看病しながら、アプリで欠席を連絡する（ピアノは連絡帳） | 振替は付くか、今月あと何回か | 慌ただしい。考える余裕が無い | 妻 |
| 週末 | まとめて確かめようとして、できない週がある | 三つの規則、期限、残り回数 | 自分しか分からない作業を一人でやる | 妻 |
| 月末（スイミング） | 今月の残りを気にする | 月2回までの残り | 小さな気がかり | 妻 |
| 行事が重なる時期（年末年始、発表会の前） | 振替のことが頭から抜ける | ― | 気づかない | 妻 |
| 期限切れに気づく | アプリで期限切れを見る | 2,500円を捨てた。子どもに言わなければ | 子どもへの申し訳なさ、自責 | 妻 |
| 夫に話す | 「言ってくれれば予約したのに」と言われる | 言うって、何を | 頼むことまで自分の仕事になっている、という苛立ち | 妻 |
| 妻から話を聞く | 聞くだけ | 何がいつまでか分からない | 手伝いたいのに手伝えないもどかしさ | 夫 |
| 何もない日 | 何もしていない | 忘れていないか | 小さく、ずっと重い | 妻 |

| 入口 | 出たもの |
| --- | --- |
| ものごとの一生 | 欠席の連絡、振替が生まれる（規則が教室ごとに違う）、期限前に気づく、予約する（枠、締切）、受講か失効。どの段にも痛みがある |
| 人 | 妻（覚える、連絡する、予約する）、夫（頼まれれば代わるが、自分では気づけない）、子ども二人（失効で振替に行けない）、教室（規則を決め、期限前に知らせない） |
| 実際に起きたこと | 先月、英会話の振替を失効させた。昨年度は5回、約12,500円 |
| 今のしのぎ方 | 妻の記憶と、教室のアプリをときどき開くこと。週末のまとめての確かめは、できない週がある |
| 着想の裏 | 毎日見る所に来てほしい。残り回数は、使える振替がいくつ残っているか分からない不安から |
| 隣の痛み | 学校のプリントの提出期限も、妻が全部覚えている。紙で来て、出どころが違う |
| 解いた後 | 夫が、スイミングと英会話の予約を引き受ける（同意している）。妻は、ピアノは自分でやりたい（全部を手放したいのではない） |
| 期間 | スイミングはあと3年、英会話はあと5年、ピアノは続く見込み |

### 3. 痛みを吸い出し、つなぐ

| 痛み | 生むもの |
| --- | --- |
| a 振替について知っておくべきことが妻の頭の中にしかない | b、c、d、e を生む |
| b 夫は、頼まれれば代わるが、自分では気づけない。そのため、頼むことまで妻の仕事になる | a を残したままにする |
| c 行事が重なる時期に、頭から抜けて失効する（年約5回、約12,500円） | a の結果 |
| d 子どもに「行けなくなった」と言う申し訳なさと、自責 | c の結果 |
| e 何もない日にも「忘れていないか」が頭にある | a の結果 |

### 4. 畳む

| 段 | 振替の件で |
| --- | --- |
| 核心を選ぶ | a と b（[論点2](discussion.md#論点2-痛みの核心を頼むことまで妻の仕事になっていることに置く)）。「なぜ妻の頭の中にしかないか」をもう一段問うと、欠席の連絡が妻を通ること、家事の分担と降りるが、そこまで降りると振替を越え、下の層の物差しにならないため、ここで止めた |
| どうなっていたいかを取る | 「自分が覚えていなくても大丈夫だと思えたらいい。スイミングと英会話は、あなたが自分で気づいて取ってくれたら助かる」（妻） |
| 姿を書く | 正本の[アウトカム](../README.md#アウトカム)。言い分は、ア 知っておくべきことが妻の頭の外にあり、妻が覚えていなくてよい、イ 頼まなくても、二人のどちらも自分で気づいて動ける、ウ 使える振替を期限の内に使い切る、エ その状態が続いている。「覚えていなくても大丈夫と思える」は気持ちであり、測りに置いた |
| 大きさを選ぶ | 含める: 三つの教室の振替。外す: 学校のプリントの提出期限（同じ形だが、紙で来て出どころが違う。広げる候補として残す）、予約そのものの代行（使い切るのに要らない）、家事の分担の全般（振替を越える）（[論点3](discussion.md#論点3-アウトカムの大きさと測り)） |
| 測りを付ける | 核心: 妻に頼まれずに、夫が自分で気づいて予約した回数。症状: 失効が年約5回から0回になる。気持ち: 三か月後に妻に、覚えていなくても大丈夫と思えているか、こっそりアプリを確かめていないかを聞く。失効を子どもや夫に言いにくい、ということが起きていないか |
| 値打ちと期間を出す | 失効は年約12,500円で、5年で数万円である。妻の頭の負担と、子どもへの申し訳なさと自責は、お金にならず、利用者はそちらを重く見る |

広げたものの分け方:

| 分け先 | もの |
| --- | --- |
| アウトカムに入れるもの | 核心 a・b から導いた姿と言い分、測り |
| 外したもの | 学校のプリント、予約の代行、家事の分担の全般 |
| 下の層へ渡す材料 | 2の場面の表。妻はピアノを自分でやりたい。夫は平日の夜なら予約できる。最も余裕が無いのは子どもが熱を出した朝で、行事が重なる時期には頭から抜ける |

### 5. 作ることで得たいものを分ける

| 得たいもの | それだけでも、やる意味が残るか | 題材 |
| --- | --- | --- |
| 痛みを解くこと | 残る | ― |
| 作る楽しみ | 残る（「作るのは純粋に楽しいから、多少時間がかかっても作りたい」） | 自分たちの困りごとなので、作りがいがある（この題材で作りたい） |

## 差し戻し

この層は、差し戻しを受けていない。この層を閉じた後、何が成り立てばよいか層へ、アウトカムの変化を返した（[何が成り立てばよいか層の記録](../what-must-hold/README.md#差し戻し)）。

## 確認

| 揃えば満たした | 満たしたか |
| --- | --- |
| 1: 入力の全ての言葉が、四つのどれかに分けられている。手段の言葉が、痛みにもアウトカムにも残っていない | 満たした（1） |
| 2: 痛む人の言葉で、場面ごとの行いと、頭の中と、気持ちが語れる解像度になっている。声の出どころが書かれている。新しい入口から潜っても、新しい痛み、新しい人、新しい事実が出ない | 満たした（2）。妻の語りは、夫が聞いた答えとして書いた |
| 3: 全ての痛みが一件ずつ取り出され、どの痛みが他を生むかがつながっている | 満たした（3） |
| 4: 核心から姿が導かれ、姿が言い分に割れ、手段の言葉と気持ちを含まない。大きさに、外したものと理由がある。測りが、核心・症状・気持ちのそれぞれにある。値打ちと期間が、お金にならないものを含めて書かれている。広げたものが、三つのどれかに分けられている | 満たした（4） |
| 5: 得たいものが分けられ、それぞれに、それだけで、やる意味が残るかと、題材を問うかが書かれている | 満たした（5） |
