## 決め方

### 1. 体験理解 — 価値を見つけ、目標を選ぶために現実を捉える

| 材料 | 何が起き、どう捉えたか | 出どころ |
| --- | --- | --- |
| 入口 | 管理したい・LINEは手段の着想、失効をなくしたいは症状の改善、作るのが好きは独立の動機。元の言葉を正本へ残した | 旧自演から維持した設定 |
| 振替の失効 | 期限切れ、自責、夫に頼む負担、何もない日にも覚えていること。妻が行為だけでなく始動を担っていた | 以前の[論点1](discussion.md#論点1-妻の直近の失効の一回とふだんの一週間とどうなっていたいか)の当人役の語り |
| 学校の同意書 | 子どもが週の初めに渡し、週末締切までに夫が署名し提出した。妻が二度促し提出まで気にしていた。間に合ったことだけでは負担は消えない | 追加の検証設定と[論点5](discussion.md#論点5-学校行事も含む目標と範囲を選ぶ)の当人役の語り |
| 望む関わり | 妻は先生から子どもの様子を聞くこと、子どもと行事の準備を楽しむことを残したい。管理を抱えることとは別に捉えた | 旧設定と追加設定 |
| うまく回る隣の体験 | 家計の更新等は夫が自ら担い、妻が進捗を聞かない。全分野を母親が管理しているわけではない | 追加設定の夫役の語り |
| 夫が引き受けたいことと負担 | 学校行事の対応も引き受けたいが、毎晩長い照合作業は増やしたくない。具体の手段の費用は未比較で、howへ渡す | 追加設定の夫役の語り |
| 子どもと余白 | 普段の友達との関わりや、時々家で歌を聞いてもらう楽しみを保つ。新しい練習の義務で余白を埋めたいわけではない | 検証用の子ども役・親役の設定 |

検証用の子ども役の体験では、上の子は別の曜日の振替より友達との遊びを選んだ回があり、普段の教室を辞めたいわけではない。下の子は知っている子のいない振替で黙って帰った一方、家で歌を聞いてもらった後に次の教室で歌いたがった。
これらも、受講数だけでは良さを代理できないことを吟味するために追加した設定である。

本人の語り、assistantの仮説、選んだ目標を分けた。全て自演の設定であり、実在の人から取った語りや独立に確認した事実ではない。
価値発見から学校の一回へ問いを戻したことで、「夫が署名できる」ことと、「妻が動かし完了まで追う役割が外れる」ことを分けられた。
姿の試し割りからも、妻が全てを仕分けて渡す所までを担っていないかを問い返し、目標の始点を描き直した。

### 2. 価値発見 — 体験に根ざして、変える価値のある可能性を育てる

| 可能性 | 当てた体験と、判断が分かれた所 |
| --- | --- |
| 振替の失効を減らし使い切る | 意図して別の予定を選ぶ場合と、知らないうちに機会を失う場合が異なる。受講数だけでは本人たちにとっての良さを代理できない |
| 妻が振替を覚えて頼み続けない | 独立した改善として価値はあるが、学校では同じ望まない役割が残る |
| 振替と学校行事を、妻が起点・進捗を管理し続けずに回す | 両方で役割が変わり、望む機会を家族で選びながら関わりと余白を保つ可能性がある |
| 家族の全期限を変える | 家計等は既に夫が自ら回しており、同時に変える根拠が無い。大きくするだけでは価値は増えない |
| 親子の学びをさらに増やす | 良い体験から可能性は広がるが、今回は新しい義務を増やすより既存の楽しさと余白を保つことを重く見る |

家計の良い体験は、監督しなくても他の人が引き受ける未来を描く根拠にした。特定の道具をそのまま借りる話にはしない。
残したい先生・子どもとの関わりと、記憶・仕分け・割り当て・催促の役割を分け、全てを手放すか全て担うかという二択へ畳まなかった。
何を目標とするかを、対象名の大小でなく、片方が叶っても他方が残る場面と、誰が何を引き受けるかから育てた。

### 3. 目標設定 — 目指す変化を選び、whatの物差しへ畳む

| 決めたこと | 判断と根拠 |
| --- | --- |
| 引き受ける変化 | 振替と学校行事で、妻が家族の行動を起こし続け最後まで追う役割を変える。振替だけでも改善は成立するが、学校でも残る役割と得られる余白を重く見て両方を選んだ（[論点5](discussion.md#論点5-学校行事も含む目標と範囲を選ぶ)） |
| 始点と終点 | 担当へ渡した後だけでなく、欠席や知らせの発生から必要な家族側の行いを終えるまで。最初の姿で、妻が全件を仕分けて渡す負担が残った反例から戻した |
| 姿・大きさ・測り | 正本の[アウトカム](../README.md#アウトカム)。家族側の行いが済むことと、実際に望む機会・関わりへ届いたかを分ける（[論点6](discussion.md#論点6-起点からの役割を含む姿と測りを定める)） |
| 外すものと理由 | 家計等の既に回る分野、家族の全事務、新しい家庭学習全般。価値が無いのでなく、今回同時に変える必要や優先を確認できなかった。紙かアプリかでは選ばない |
| 値打ちと期間 | 旧設定の失効は年約12,500円。金銭以外に、提出に間に合っても数日気にし続ける負担と、望む関わりの価値を持つ。親が現在の教室や学校行事の対応を担う期間を対象とし、自立度や家族の事情で選び直す |
| 作ることで得たいもの | 改善と作る楽しみを独立して残す。この題材で作りたいという動機を保ち、作る判断と費用はhowへ渡す |

暮らしの変化を中心へ戻した姿は正本に置く。
予約・提出等を終えることを不要にはせず、それを満たすだけで妻が全件の状況を聞き出し続ける暮らしが残るなら、価値へ届いたとはしない。
不安や後悔が絶対に無くなることではなく、起点からの始動と進捗の管理を妻の仕事として抱え続ける暮らしが変わったかを見る。
この改稿は新しい家族の優先を取得したものではなく、既に選んだ価値を出口の主文へ戻すものである（[論点8](discussion.md#論点8-暮らしの変化を姿の中心へ戻す)）。

whatへの試し割り（核の言い換えで終えず、成立要件として新たに問うもの）:

| 言い分 | 条件を導く時の問い |
| --- | --- |
| 妻が全件の始動と完了を追う暮らしから離れる | 妻の全件の仕分けが無くても始められるかに加え、担当の不在時に引き継ぐ人が、残る行い・期限・次の引受け先・実際に済んだ行いの根拠を、不在者や妻の記憶から一件ずつ聞き出さずに区別できるか |
| 本人たちの望みと必要な事情から選ぶ | 意味ある機会が閉じる前に、誰が何を知る必要があるか |
| 家族が選んだ対応を果たす | 担当の決定と実施の完了を分け、予約・提出・当日の必要な行いと、それぞれの期限を条件として導けるか |
| 望む関わりと日々の余白を保つ | 管理役を引き受け直さず望む関わりへ加われるか。ほかの家族の長い照合等へ負担を移しただけなら、その負担をhowの比較へ渡し、許容の線が目標を左右するならwhyへ返せるか |
| 状態が続く | 繁忙や不在で、妻が全体の起点・進捗を黙って引き取る形へ戻らないか |

学校や教室の具体の規則・情報の出どころ・当日に必要な行い・不在時の事情はwhatで確かめる材料として渡す。全条件をここで確定していない。
外部の中止や体調まで無条件に保証する姿にせず、家族側の行いの不足と外部事情を経過から分けて測る。必要ならwhatから姿・目標へ返す。

## 差し戻し

[旧正本](../archive/3rd/README.md)と[旧whyの層の記録](../archive/3rd/why-to-build/README.md)を保存した。
旧目標は三つの教室の振替を使い切ることで、学校は対象外だった。今回の目標は学校行事も含み、本人たちの望みを踏まえた選択と、起点から家族側の対応を終える担い方を物差しにする。
whatとhowへ物差しの変化を返し、どちらも確かめ直し待ちにする。whatで新しい条件を導き直した後に、howはその条件で確かめ直す。
旧whatは条件9を追加した後の検証が未完、旧howは旧8条件での選定であり、その未完を新しい目標への合格へ読み替えない。

## 確認

| 揃えば満たした | 満たしたかと根拠 |
| --- | --- |
| 目標の選択を左右する場面について、行い・当時の認識・気持ちと、その後の出来事や評価を読み分けられる。誰の声かと、確認できた範囲が明らかで、価値の仮説を支えること・覆すこと・まだ分からないことへ結びついている。 | 自演の設定の範囲で満たした。場面・声の出どころ・役割と良さを分け、学校と平穏な夜の体験へ問いを戻した（1、論点5） |
| 体験に根ざす価値の可能性について、どの場面がどう変わり、何を保ち失い、誰が負担を担うかを比べられる。仮目標を覆す可能性も吟味し、選択を変えうる未探索・未確認と、判断に使える根拠が区別されている。 | 自演の設定の範囲で満たした。候補の得失を場面で比べ、家族全般や学びの拡張も含めて、目標を選ぶ違いを育てた（2、論点5） |
| 選んだ変化と範囲に、得る価値・失う価値・負担を踏まえた理由がある。姿が手段を含まずに言い分へ割れ、元の場面でも必要な価値を落としていない。姿への進みと実際の価値をいつ何で測るか、値打ちと期間、作る行為から得たいもの、残す不確かさと選び直す条件が読める。 | 自演の設定の範囲で満たした。範囲と姿の始点を描き直し、測り・値打ちと期間・動機・whatへ返す未確認を残した（3、論点6・7） |

実在の家族の望みや実運用の成果、全ての題材での有効性、三つの仕事の最小性は確認していない。観測結果を捏造せず、後続で反例が出たら該当する仕事へ戻す。
