# 習い事の振替を、家族の二人で期限内に使い切る

子ども二人が通う三つの習い事の振替を、妻一人の記憶に頼らず、二人のどちらが動いても期限の内に使い切れるようにする。教室のアプリで見られるものはそのまま見て、見られないピアノの分と、締切に気づくことを、表計算と毎朝家族のカレンダーへ予定を作るscriptで補う。

- 状態: 検討中（どこまで作るか層と、どう作るか層は、まだ今の形で書いていないため、通していない）
- 閉じた層: 何が成り立てばよいか、どう解くか

## なぜ作るか

<!-- この節を決める層と決めるもの: なぜ作るか層（まだ今の形で書いていない）。それまでは、grow-product-idea が何が成り立てばよいか層を始める前に、受け入れ時の入力から利用者と置き、閉じを通っていない仮のものとして書く。 -->

なぜ作るか層の閉じを通っていない、仮のものである。

### 解く痛み

子ども二人が、スイミング、ピアノ、英会話の三つの教室に通っている。欠席した分の振替は、教室ごとに規則が違う。

| 教室 | 振替の規則 | 予約の締切 |
| --- | --- | --- |
| スイミング | 月2回まで。欠席した月の翌月末まで | 前日まで（アプリ） |
| ピアノ | 年度に4回まで。年度末（3月31日）まで | 1週間前まで（先生とのLINE） |
| 英会話 | 欠席ごとに発行。発行日から60日 | 前日まで（アプリ） |

期限と残り回数が散らばり、昨年度は5回（約12,500円）失効した。核心は、管理を妻だけが担い、夫が代われないことである。

### 作ることで得たいもの

振替の管理を二人で分けられるようにすること。作ること自体の楽しみ（学びの目的は無い）。

### アウトカム

> 振替のことを妻が一人で抱えず、二人のどちらが動いても、使える振替を期限の内に使い切れている

近づいたかの測り: 作った後、三か月たったら、妻に、教室のアプリをこっそり確かめているかを聞く。確かめに行かなくても回っていると妻が思えていれば、近づいている。

根拠: 前の記録の[解く痛み](archive/2nd/README.md#解く痛み)と[作ることで得たいもの](archive/2nd/README.md#作ることで得たいもの)。測りは[何が成り立てばよいか 論点3](what-must-hold/discussion.md#論点3-妻の安心をアウトカムの測りに入れるか)。予約の締切は[何が成り立てばよいか 論点1](what-must-hold/discussion.md#論点1-条件を決めるのに要る家族と教室の事実)

## 満たすべき条件

<!-- この節を決める層と決めるもの: what-must-hold／満たすべき条件 -->

| # | 一文 | 確かめ方 |
| --- | --- | --- |
| 1 | 欠席した日のうちに、その欠席で振替が生まれるか、生まれる振替の期限と予約の締切が、教室の規則のとおりに決まり、二人のどちらも、妻の記憶に頼らずに分かる | 妻がいない日に欠席を連絡した夫が、その振替が生まれるか、期限と予約の締切を言え、それが教室の規則と一致する。一件も間違えない |
| 2 | 欠席が、教室へ連絡した日のうちに、連絡した人の手で、相手に頼らずに記録されている | 夫が欠席を連絡した日に、妻に頼まずに記録が済んでいる |
| 3 | 二人のどちらも、教室へ欠席を連絡できる | 夫が、妻に頼まずに、どの教室にも欠席を連絡できる |
| 4 | 予約しようとする時（平日の夜、家で）、二人のどちらも、相手に聞かずに、まだ予約していない使える振替の一件ずつについて、子ども・教室・期限・予約の締切が分かる | 夫が妻に聞かずに「まだ予約していない振替はどれで、それぞれいつまでに、いつまでに予約が要るか」に答えられ、それが教室の記録と一致する |
| 5 | 予約の締切の7日前までに、二人のどちらかが、その振替に気づく | 締切の7日前の時点で、二人のどちらかが、その振替の締切を知っている |
| 6 | 気づいた日のうちに、その振替を予約する人が、締切までに予約できる人の一人に決まる | 気づいた日に、二人とも「誰が予約するか」に同じ答えを言え、その人が締切までに予約できる（出張等で予約できない日でない） |
| 7 | 片方が予約した、受講した日のうちに、もう片方がそれを知れる | 夫が予約した日の夜に、妻がその振替を予約済みと言え、それが教室の記録と一致する |
| 8 | 使えないもの（上限を超えた欠席、期限切れ、規則の外の振替）が、使える振替の一件として数えられない | 期限切れの振替を、二人とも使える振替に数えない |

期限までの枠が埋まって使えない振替は、失効として受け入れる。振替の日に休んだ時は、英会話は有効期限の内に取り直し、スイミングとピアノは失効として受け入れる。

根拠: [何が成り立てばよいか層の記録](what-must-hold/README.md)、[何が成り立てばよいか 論点1](what-must-hold/discussion.md#論点1-条件を決めるのに要る家族と教室の事実)、[論点2](what-must-hold/discussion.md#論点2-手の外にあるものを条件で寄せるか受け入れるか)

## 解き方

### 解き方の選択肢

<!-- この節を決める層と決めるもの: how-to-solve／解き方の選択肢 -->

基準は、二人が、予約しようとする時に、教室のアプリと連絡帳を直接見る形である。スイミングと英会話の欠席、期限と残り、予約、受講は、教室のアプリを夫も同じ世帯の保護者アカウントで見られるため、基準で届く。

| 補う点 | 選択肢 |
| --- | --- |
| 1 締切の7日前に気づく | 欠席を連絡した直後に、家族のカレンダーへ予定を手で作る／一覧から毎朝scriptが予定を作る（一覧の束）／LINEで知らせる（着想どおり、作る）／教室に知らせてもらう（頼めるか確かめていない） |
| 2 誰が予約するか | 予定の名前に書く／教室ごとに決めておく（片方がいない時は、もう片方）／一覧の列に書く |
| 3 ピアノの振替（期限、残り回数、締切、予約） | 規則のメモを見て手で出し、予定に書く／一覧に記録し計算式で出す（一覧の束） |
| 4 三つの教室をまとめて見る（良くする） | 選ばない／一覧に記録する（一覧の束） |
| 5 黙って止まった時に拾う（良くする） | 選ばない／週に一度、教室のアプリと家族のカレンダーを見比べる |

根拠: [どう解くか層の記録](how-to-solve/README.md)、[どう解くか 論点1](how-to-solve/discussion.md#論点1-出どころは何を見せ誰が見られるか)。材料[alternatives](materials/alternatives/README.md#候補補う点)

### 解き方の選定

<!-- この節を決める層と決めるもの: how-to-solve／解き方の選定 -->

| 補う点（組） | 選んだもの | 決め手 | 選び直す条件 |
| --- | --- | --- | --- |
| 1・3・4（一覧の束） | フォームで欠席・予約・受講を記録し、表計算の計算式で期限・残り回数・締切を出し、毎朝scriptが締切の7日前の振替について家族のカレンダーに予定を作る。表計算を正とし、予定はscriptだけが作る | 次点の作らない組と比べ、約32時間（補正後16〜62時間）を、三つの教室を一度に見ること、ピアノの残りと締切を手で数えないこと、教室のアプリの表示が変わっても崩れないことと、作る楽しみに払う。主な理由は作る楽しみであり、手間が減ること（年約50分）は理由にしない | ピアノが教室のアプリで振替の残りと期限を見せるようになった。scriptの保守が年2時間を大きく超えた。作る楽しみが得られなかった |
| 2 | 教室ごとに予約する人を決めておく（スイミングと英会話は夫、ピアノは妻。片方がいない時は、もう片方） | 次点の一覧の列と比べ、欠席のたびに書く受け渡しが要らない方を重く見た | 片方がいない時に、もう片方が予約し忘れたことが起きた |
| 5 | 週に一度、日曜の夜に、教室のアプリと家族のカレンダーと表計算を見比べる（繰り返しの予定で起こす。妻、いない時は夫） | 年約4時間を、作り忘れ・写し忘れ・scriptの停止・通知が届かなくなった時を拾うことに払う | 見比べで一度も取りこぼしを拾わないまま、半年が経った |

作るものは、表計算の計算式と、毎朝家族のカレンダーへ予定を作るscriptである。フォーム、表計算、家族のカレンダー、教室のアプリは、既にある道具を使う。
