# 子どもの機会を、妻一人の管理に頼らず家族で選び対応する

全体の目標は、三つの教室の振替と学校行事の申込み・同意を、知らせの受け取りや欠席の発生から家族側の対応を終えるまで、妻一人の管理に頼らず選び進めることである。
今回の版は学校の手続だけを原本・紙の用件票・既存の家族カレンダーで三週試し、コードを作らない。三教室の振替の管理と失効の痛みは残り、学校部分の改善も実測前である。

- 状態: 作らない（この模型の今回の版は学校限定の三週の非開発試行。全体の目標の達成や実利用の成功ではなく、自作を恒久的に否定する決定でもない）
- 閉じた層: なぜ作るか、何が成り立てばよいか、どう解くか（学校限定の試行版の選定）

## なぜ作るか

### 体験と価値

子ども二人が通う三つの教室の振替では、妻が規則・残り・期限を覚え、夫へ頼むことまで担っていた。旧自演には、昨年度5回・約12,500円の失効と、自責、何もない日にも気にし続ける語りがある。
追加設定の遠足の同意書は、提出には間に合ったが、妻が夫へ署名を頼み、二度声を掛け、提出まで気にしていた。夫が行為だけを代わっても、初動と進捗の管理は妻に残る。
妻は、先生から子どもの様子を聞くことや、子どもと行事の準備を楽しむことは残したい。家計の更新等は夫が自分で担い、妻が催促せず回る良い体験もある。
夫は学校行事の対応も引き受けたいが、毎晩長い照合作業を増やすことは望んでいない。手段を選ぶ時には、この既知の望みも守る。
子どもが普段の友達と学ぶことや、家で歌を聞いてもらうことの楽しさを保ち、受講数の消化のために望む体験を失わないことにも価値を置く。

今回選んだのは、振替と学校行事で、妻が家族の行動を起こし続けて最後まで追う役割を変えることである。
振替だけでも改善は成立するが、学校でも残る同じ望まない役割と、変われば得られる余白を重く見て両方を含めた。紙かアプリかで決めたものではない。
既に回る家計、家族の全事務、新しい家庭学習全般は、今回同時に変える必要や優先を確認できなかったため含めない。価値が無いと判定したものではなく、望みや事情が変われば選び直す候補として残す。

これらは、旧自演から維持した設定、追加の検証設定、当人役の語りと選択であり、実在の利用者の発言・観測結果ではない。
学校の一般的な規則・通知方法、当日の行いの具体、繁忙や不在時の事情は、whatが条件を導くために確かめる材料として残る。遠足の一回の設定を学校の全規則へ一般化しない。
値打ちは、旧設定の年約12,500円に加え、間に合っても何日も覚えて促し続ける負担と、望む関わり・余白を保つことにある。金額へ無理に換算しない。
続く期間は、親が現在の教室と学校行事の対応を担う間である。旧設定ではスイミングはあと3年、英会話はあと5年、ピアノは続く見込み。学校の残年数は根拠なく作らず、子どもの自立度や家族・学校の担い方が変われば選び直す。

### アウトカム

> 三つの教室の振替と学校行事の申込み・同意をめぐって、妻が全件を覚え、家族を動かし、完了まで気にして追い続ける暮らしから離れ、家族が本人たちの望みと事情を踏まえて機会を選び、選んだ対応を果たしながら、先生や子どもとの望む関わりと日々の余白を保てている状態が続いている。

| 持つもの | 中身 |
| --- | --- |
| 言い分 | ア 妻が全件の始動と完了を追い続ける暮らしから離れている。イ 家族が本人たちの望みと事情を踏まえて機会を選び、その対応を果たしている。ウ 先生や子どもとの望む関わりと日々の余白が保たれている。エ その状態が続いている |
| 大きさ | 三つの教室の振替と学校行事の申込み・同意について、機会の発生・知らせの受け取りから対応の完了までを含める。家計等の既に望む形で回る分野、家族の全事務、新しい家庭学習全般は含めない。予約・提出・当日に必要な家族側の行いを期限内に終えることは、この変化を支える成立要件としてwhatで導く。相手の中止や体調を無条件に防ぐ保証はしないが、行いが済んだだけで価値へ届いたとは数えない |
| 測り | 日々の一巡や忙しい時期の具体の数件から、妻が全件の状況を聞き出し、次を促し、終わるまで確かめ続ける役割から離れたか、家族が望む機会を選んで対応でき、望む関わりと余白を保てたかを見る。その理由として、必要な判断材料、予約・提出・当日の行いの完了、担当や状況の受け渡しも確かめる。意図した見送りと気づく前の失効を分け、外部の中止・体調と家族側の不足も分ける。夫の長い照合等へ負担が移っただけではないかも見る。測るため妻へ毎晩の全件照合を課さず、未観測を成功に数えない |

### 作ることで得たいもの

暮らしの改善と、作る楽しみを独立して持つ。どちらも、それだけで取り組む意味があるという旧自演の動機を保つ。
発案者は自分たちの題材で作ることを望むが、その楽しみを暮らしの改善に必要な手段だったという理由へ混ぜない。作るかと具体の負担はhowで比べる。

## 満たすべき条件

以下は全体の目標の物差しであり、固定した自演設定の模型として閉じた条件群である。
howで部分案を選ぶ場合も全体を満たした扱いにせず、今回の改善と受け入れる未達・損失を別に示す。

| 条件 | 一文と確かめ方 |
| --- | --- |
| A. 着手する用件を捉える | 対象用件が発生した時、または既に選んだ対応・期限・担当・完了の扱いを変える知らせが来た時、対応を始める保護者が、意味ある選択と必要な行いを終えられる間に原情報を把握して着手し、その成立が妻の全件の仕分け・割当を待つ形に依存しない。<br>確かめ方: 原情報の到着・欠席の発生・変更から着手までを辿る。妻の全件の仕分けが無ければ始まらない案は未達。 |
| B. 選べる対応を材料から決める | 各用件について、意味ある選択肢が閉じる前に、判断する家族が、選択を変える規則・予定・本人たちの望みと事情を確かめ、受講・参加・見送り等の対応を決め、その対応に必要な次の行いが特定されている。<br>確かめ方: 規則・予定・本人の望みに一致する実際の選択と、残る行いを辿る。無応答の失効は意図した見送りではない。 |
| C. 行いを引き受けて進める | 選んだ対応に必要な各行いについて、期限内に実施できる保護者の引受けが成立し、その人が原本・連絡先・判断材料を使って未完を進め、その進行が妻の全件の割当・都度の指示・催促に依存しない。<br>確かめ方: 実施可能な本人の引受け、使う原本・連絡先、未完の進行を辿る。担当欄の名前だけでは足りない。 |
| D. 選んだ行いを実際に終える | 各用件で選んだ対応に必要な予約・申込み・同意の提出・当日の家族側の行いが、それぞれの規則と期限に従って実際に完了し、担当の決定・意向・準備途中だけをその完了として扱わない。<br>確かめ方: 予約先の了承、学校での原本回収、必要な当日の準備・送迎の実施を辿る。署名済みと提出済みを区別する。 |
| E. 必要な人が今の状況を区別する | 対応の継続、家族の予定調整、望む関わりへの参加にその用件の状況が要る時、関係する保護者が、判断が間に合ううちに今有効な対応・残る行いと期限・引受け先・完了と扱える根拠を区別でき、その把握が妻の全件の再照合や連絡できない担当の記憶に依存しない。<br>確かめ方: 次の判断に必要な時点で、現に有効な対応・残り・担当・完了の根拠が原情報と一致するかを見る。 |
| F. 望む関わりへ加わる | 本人が残したいと確認した先生・子どもとの関わりについて、関わる人が必要な機会・予定・材料へ間に合って参加でき、そのために対象用件全ての受け口・割当・未完の管理を引き受け直す必要がない。<br>確かめ方: 妻の先生との会話と親子の準備、夫の望む参加へ辿れるかを見る。参加のために全件管理を戻す案は未達。 |
| G. 管理の作業と残したい時間を両立する | 対象用件を回すために各保護者が引き受ける受領・確認・受渡し・照合等の作業が、通常時と繁忙・不在時の必要な時間・頻度において、whyで残すと選んだ生活の時間や関わりと両立する最低線に収まっている。<br>確かめ方: 下記の追加設定の時間・繁忙量へ、受領・確認・実施・共有・照合・復旧の作業を人別に全て計上する。量が不明なら案の見積り・試行へ返す。 |
| H. 引継ぎを成立させる | 進行中の対象用件で担当の不在・交替により引継ぎが必要な時、次に対応する保護者が、残る行いを終えられる間に引き受け、残る行い・その期限・既に済んだ行いの根拠を区別して対応を続けられ、その成立が妻の全件の整理・照合・催促や不在者への聞き直しに依存しない。<br>確かめ方: 元担当へ聞けない入力で、次の本人が残る行いに間に合ううちに引き受け、原本・期限・完了の根拠から進めるかを見る。 |

### 判定する最低線と受容の範囲

追加設定として、管理・手続きの全作業を夫は週60分、妻は週30分までとし、原則19時30分–20時で割り振る。
毎日の20時–20時30分の親子の時間を管理へ使わず、重なる週・不在時にも同じ上限で比べる。
これは当人役がこの実演のために選んだ線であり、実在の家族の許容時間を推測した結果ではない。
通常週は振替一件と学校一件、重なる週は三教室の振替各一件と学校二件・二日間の担当不在を入力にする。
各手段の人別の作業量はhowで見積もり・試行する。P・QがGを満たすとはまだ判定していない。

学校の一件は金曜登校時の担任による原本回収で提出完了となる。準備の15分、引受け先の使える時間、当日の原本・持物の確認まで繋ぐ。
三教室の規則は既存設定を保ち、時点は一律の7日前ではなく、選びたい機会・相手の規則・残る行い・動ける時間から定める。
子どもが望まない平日への置換や、気づかなかった失効を、意図して選んだ対応へ読み替えない。
満席・中止・病気や対応不能時は、残る選択と損失を見て対応・見送りを選ぶ。望む機会へ届かなかった価値は実現済みに数えず、家族側の失念・未対応は外部事情と分ける。
前提や本人の望みが変わる場合には、用件の対応か目標・条件のどこを選び直す必要があるかを確かめる。

根拠: [whatの層の記録](what-must-hold/README.md#現在の決定)、[追加設定と当人役の選択](what-must-hold/README.md#閉じ直しに用いた追加設定と自演内の選択)、[閉じ直しの決定過程](what-must-hold/discussion.md#論点10-固定した追加設定で条件群を閉じ直す)。

## 解き方

### 解き方の選定

| 補う点 | 選んだもの・決め手 | 選び直す条件 |
| --- | --- | --- |
| 原情報から着手 | 学校の原本を夫が受け口から確認する。妻の全件の仕分けを前提にしない | 不在時の受け口が消える、妻の仕分け・催促が戻る |
| 次の行いと引受け・根拠 | 原本と紙の用件票、既存の家族カレンダーの予定。全履歴の一覧と新しい連携を作る前に、本人の引受けから提出までを小さく試す | 紙と予定が食い違う、通知が届かない、引受け・提出が間に合わない |
| 計算・通知の自作と範囲 | 三教室と全領域の移行、自作は今回見送る。学校の一巡を低い導入で観察する価値を選び、振替の痛みと作る楽しみを今回得ない損失を受け入れる | 三週終了、作業時間の超過、通知・計算が主な負荷だと判明、振替の先送りの損失が変わる |

### 今回届ける範囲と、受け入れる未達

学校申込み・同意について、夫が原本から始め、本人たちが対応を選び、引受け・残る行いと根拠を渡し、実際の提出までを妻の全件管理に頼らず進める版を試す。
準備週に導入し、通常週一件・重なる週二件と夫の二日間の不在を通す三週に限る。A–FとHをこの学校部分で繋ぎ、Gと役割・余白の変化を測る。
三教室の始動・規則・予約・未完の管理は今回変えず、妻のそこに残る負担と失効の痛みを受け入れる。全体のA–G・Hを満たしたことにはしない。

ソフトウェアを作る時間は0、導入は夫の15／30／60分の見立てで準備週の上限内に分ける。
学校部分の通常週は夫27–41分・妻0–3分、重なる週は夫34–57分・妻18–26分を見込むが、実測と照会・復旧の追加は未確認である。変えない振替まで含む家族全体のGを通過させない。
この模型では既存の紙・カレンダーの追加支払いを置かない。全体の手動案の導入1／2／4時間、一部自作の補正後24／56／112時間を先に払うより、学校の一巡と人別の負荷を先に観察する選択である。
自作の楽しみは今回得ない。後でその理由で作る場合は、暮らしの改善のために不可欠だったという理由へ混ぜない。

通知の到達を開始前に確かめ、引受けと提出の根拠、人別の時間、妻の仕分け・催促、親子の時間を記録する。
未確認を効果とせず、超過・未着・引受けの不成立では新規投入を止め、残る行いと担い手を明示して戻す負荷も数える。
三週後又は上表の変化が起きた時に、継続・全体へ広げる・自作する・やめるを選び直す。実際に三週の運用を実施したという記録ではない。

根拠: [howの比較と選定](how-to-solve/README.md#新しい目標での比較と選定)、[当人役の選択](how-to-solve/discussion.md#論点5-学校の手続を先に試す部分案を選ぶ)、[候補と費用](materials/alternatives/README.md#新しい目標の候補と費用学校と三教室)。

## 出口

今回の版は、学校の一巡を既存の道具で試すためコードを作らない。振替を含む全体の変化は残す物差しであり、達成済みにしない。
自作や全体版は、学校の試行で分かった負荷と関わり・余白、振替に残る損失、作る楽しみの価値から選び直す候補である。
これは固定した自演設定の模型としての出口であり、実在の家族への導入や、その改善の実績ではない。
