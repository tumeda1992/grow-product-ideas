## 閉じ直しに用いた追加設定と、自演内の選択

以下は今回assistantが補った検証用の設定と、当人役の選択である。
既存記録から取得した家族の事実でも、利用者本人への聞き取りでもない。この設定の模型を採用するかはsteeringの論点67で判断する。
学校一件の設定を全ての学校へ一般化せず、家族・相手の規則や望みが変われば条件の適用と最低線を確かめ直す。

### 設定した事実

三教室の上限・有効期限・予約締切は[旧正本の規則](../archive/3rd/README.md)、取り直し可否と枠の埋まり方は[旧自演の回答](discussion.md#論点1-条件を決めるのに要る家族と教室の事実)を維持する。
スイミングは月2回まで・翌月末まで・前日締切、ピアノは年4回まで・3月31日まで・一週間前締切、英会話は欠席ごと・60日・前日締切である。
英会話のみ有効期限内の取り直しが可能で、ほか二教室は振替を休むと再度の振替はできない。
スイミングの土曜枠は約二週間前、平日枠は約一週間前に埋まる既存の設定も保つ。枠の確保を保証する値ではない。
今回の当日の行いは、教室が求める持物の用意と送迎を保護者が引き受ける設定とする。予約が済んでも、その行いと家族の予定が繋がるまで当日の対応済みにはしない。

今回の学校の一件では、月曜に原本が届き、保護者の確認・署名・提出準備に15分かかる。
金曜登校時に子どもが担任の回収へ原本を渡すと提出完了であり、家庭での署名や子どもへ渡しただけでは完了ではない。
別の受領番号や保護者による窓口への持参は、この一件には要らない。
当日の家族側の行いとして、子どもと持物を前夜に用意し、登校時に原本があることを確認する。
子どもが渡したか不明なら未確認とし、担任への照会を残る行いとして扱う。受領確認が別に必要な学校の例へ、この完了線を流用しない。

二人とも教室の家族アカウントを使える。妻に届く先生のLINEや紙は、一度の原文の受渡しで夫も使える設定とする。
夫も先生へ連絡できる。妻が全件を読み分け、要約・割当して初めて始まる設定にはしない。
家族内の管理記録・通知は保護者二人だけが見られる。予約・提出で相手へ必要な情報を伝える既存の行いは続けるが、新しい第三者やサービスへの開示は許可した設定にしない。
これは既存の開示の前提の効く範囲を、この模型について明示した補足である。

負荷を比べる入力は、通常週が振替一件と学校一件、重なる週が三教室の振替各一件と学校二件で、途中で担当の二日間の不在も起きるものとする。
これは作業量の見積りに渡す検証用の件数であり、現実の最大件数の測定ではない。

### 当人役が選んだ最低線と、届かない時の扱い

| 自演で問うたこと | 当人役の選択（assistantによる自演） |
| --- | --- |
| 管理を代わるために、何の時間まで使えるか | 夫役は管理・手続き全体に週60分まで、妻役は週30分までを選んだ。原則19時30分–20時の範囲で割り振り、毎日の20時–20時30分の親子の時間は管理に使わない |
| 重なる週や不在の時はどうするか | 同じ上限で比べる。妻役は、必要な一件を引き受ける協力は選ぶが、全件の整理・割当・催促を引き受け直さない。収まらなければG未達の案として比較する |
| 子どもの望みと、残る枠が違う時はどうするか | 子ども役は、普段の友達との土曜を第一に選ぶ。平日で同じ経験とはしない。別の回でも行きたいかをその回に聞き、選んだ場合だけ平日を対応に含める |
| 先生・子どもとの関わりをどう残すか | 妻役は先生から様子を聞くことと遠足前夜の親子の準備を残す。夫役も参加したい行事を選ぶ。手続きの担当者と、関わりへ参加する人を同一に固定しない |
| 満席・中止・病気・二人とも動けない時はどうするか | 残る選択と失う機会を見て、別の機会か見送りを当人役が選ぶ。欠席発生前に埋まった枠や中止・病気は防ぐ保証にしない。家族側の失念・未対応は外部事情と呼ばず未達に残す |
| 望みが競合し、同時には果たせない時はどうするか | 片方の希望を条件の文言で消さない。その用件の選択を当事者で決め、目標の優先を変える対立ならwhyへ返す。この模型では土曜へ届かなければ常に平日でよいという一括同意は置かない |

分数は既存の望みから推測した値ではなく、判定の線を固定して方法を通すために今回追加した選択である。
時間に数えるのは受領・原情報の確認・相談・予約・署名・受渡し・完了確認・照合・障害時の復旧であり、別名の仕事へ逃がさない。
望んで残す先生との会話・親子の準備・参加そのものは、減らしたい管理時間と分ける。管理作業を親子の時間へ移して達成扱いにしない。
実施に要る作業量はまだ分かっていない。ここで選んだのは許容する最低線であり、紙・共有記録その他の案がその線を満たすという採用ではない。

二人とも対応できない時に、誰かがいることにしてC・Hを通さない。
必要な辞退等も間に合って選べた見送りと、行いたかったのに行えなかった損失を分ける。後者は全体の達成に数えない。
howでその損失を含む部分案を選ぶ余地はあり、全体の未達を消さず今回の改善と受容を同じ採用の中で決める。

## 追加設定での判定と、howへ渡すもの

学校の15分の行いについて、水曜19時30分–20時が最後に使える時間という不在の入力では、必要な原本と引受けが19時45分までに揃う必要がある。
19時46分では14分しかなく、金曜の期限前というだけではC・Hを満たさない。
これはこの不在の一件の線である。普段の全用件を水曜19時45分へ揃えず、選びたい機会・相手の規則・実施順序と使える時間から用件ごとに定める。
既存の水曜20時–20時30分の例は条件の判別用に置いた別のテスト入力であり、今回の家族の時間の選択に転用していない。

紙の原本と受渡し用の記録を使うP、保護者だけが見られる共有記録と原本の所在を使うQへ、同じ入力を当てた。
一巡の想定では、月曜に夫が子どもの持ち帰った原本を見て用件を起こす。子ども役は遠足への参加を望み、家族の予定と矛盾しないことを確認し、参加を選ぶ。
夫が手続きを引き受けるが、出張前に署名・提出準備を終えなかった入力とする。未署名の原本、金曜の提出、残る15分の行いを受渡す。
Pではその原本と紙の用件メモ、Qでは共有記録から辿れる原本の所在を使い、妻が水曜19時30分に未完を引き受ける。
妻が確認・署名・提出準備を終え、木曜は望んで残す子どもとの持物の準備へ加わる。金曜登校時の原本の確認、子どもによる担任への提出へ繋ぐ。
原本が担任に渡ったことを確認できた時に初めて提出済みとし、子どもの返答だけで分からなければ照会を残す。
ただし紙を渡す・共有欄を読むだけで引受けが成立するとは扱わず、金曜に原本が回収されるまでは提出済みにしない。
P・Qの説明でA–F・Hを照合できるが、受領から完了確認・変更・照合までの人別の総作業量は未見積りである。
両案のGは判定保留であり、合格や採用ではない。上限は定まったため、その不足は条件の再議論ではなくhowでの説明・見積り・試行へ渡す。

教室の側も、ピアノの欠席の原情報を一度受渡し、夫が規則・残り回数・予定と子どもの希望を確かめて予約を引き受け、先生の了承を得る一巡を置く。
Pの紙・Qの共有記録のどちらでも、その了承と対象回、未完の持物・送迎を区別する。妻が望む先生との会話へ参加する予定と必要な材料も受渡す。
準備・送迎を実施し、妻はその会話へ加わる。妻が全ての用件を覚えて夫を催促し直すことを、その経路の前提にしない。
日程だけ記録して妻へ知らせない対照ではE・Fが未達となり、予約完了で全てを済みとする対照ではD・Eが未達となる。
この一巡も想定した出来事の机上照合であり、実際の受講・会話の観測ではない。準備・送迎や原情報の受渡しに要る時間を、費用や成立可能性から除外しない。

| 対照・反例として変えたもの | 判定と帰結 |
| --- | --- |
| 紙を共有記録へ替え、原情報・実際の引受け・完了の根拠を同じにする | A–F・Hの判定は同じ。媒体を条件にしていない |
| 引受けが19時46分になる | C・H未達。資料が存在し金曜前でも通らない |
| 二人とも相手が出すと思い、署名済みを提出済みとする | C・D・E未達。役割欄や済みの欄では埋まらない |
| 妻が全件を整えて配る役割を戻す | A・C・E・Hの依存を満たさない。夫が提出だけ代わっても全体の変化ではない |
| 夫が毎晩30分の照合をする／作業を妻の上限外へ移す | G未達。全体の物差しを保ち、部分案として選ぶなら損失を示す |
| 手段の一巡の所要時間だけが分からない | Gは判定保留。家族の上限を未定に戻さず案の見積りへ返す |
| 子どもが望まない平日枠を自動で取る | B未達。消化数で選んだ機会を置き換えない |
| 欠席発生前に土曜枠が満席だった | Aの着手の遅さと決めつけない。残る機会と損失を見て選ぶ。望む受講の実現には数えない |
| 予約後の日時変更、英会話の再欠席、年度や月の上限の変化 | 有効な規則からA・Bへ戻りC–Eを更新する。旧い予約済みの表示で終わらない |
| 妻へ準備の日や材料が渡らない／親子の時間で照合をさせる | 前者はE・F、後者はG未達。提出が済んだ一点で価値の成立にしない |

65で行ったwhyの四つの言い分と条件の間・時間経過・人の不在・外の変化の照合を引き継ぎ、追加設定でその残りの判定を確かめた。
手の内の対応を終えたとしても、体調・中止・先に埋まった望む枠による機会の損失までは防げない。
その場合も参加や受講を実現したことにはせず、条件に届かなかったものとその原因、実現していない価値を測りに残す。
家族の失念・未対応、望まない関わりの剥奪、上限を超える管理の移し替えは、条件か測りで不足にできる。
自責や安心の変化と実際の余白は実利用後のwhyの測りでも確かめ、条件の机上検査だけで実現したとは書かない。

この模型のwhatは、固定した設定と自演内の選択の範囲で閉じる。実在の家族の条件確定や、全ての未来の十分性の証明ではない。
howへは全体の条件A–G・H、規則、時間の上限、通常・重なる週の入力、選んだ見送りと未達の区別を渡す。
howでは作らない・完全案・部分案・保留を、今回届ける改善、残る痛み・負担、費用と不確かさで比べる。既存の旧選定を新しい目標への選定として再利用しない。

## 新しいwhyから導いた条件群（全体を検証する版）

これはwhatを閉じる前の検討版である。以下のA–Gは条件群として今回組み立てた候補、Hは既に採用した引継ぎの条件である。
記号は参照用であり、工程数や固定の最小構成を表さない。A–Fを順番に一度ずつ実行すればよいという意味でもない。
情報の変化があればBの選択からC・Dを見直し、状況把握と関わり・負担の不足はA–Gの該当箇所へ戻す。
HはC・Eを不在時に成立させる採用済みの境界であり、八つの独立した工程を実行する形ではない。

| whyの言い分 | 条件群で確かめる接続 |
| --- | --- |
| 妻が全件の始動と完了を追う暮らしから離れる | Aで原情報から着手し、Cで実施を引き受け、Eで必要な状況を把握する。引継ぎが要ればHを問う |
| 家族が望みと事情を踏まえて機会を選び、その対応を果たす | Bの実際の選択からCの引受け、Dの完了へ繋げる |
| 望む関わりと日々の余白を保つ | Eでその関わりに要る材料へ到達し、Fで全件の管理を戻さず参加する。Gで各人の作業と残したい生活の時間の両立を問う |
| その状態が続く | Aの発生だけでなく変更も拾い、B–GとHを変更後の条件へ再度当てる |

### A. 着手する用件を捉える

> 対象用件が発生した時、または既に選んだ対応・期限・担当・完了の扱いを変える知らせが来た時、対応を始める保護者が、意味ある選択と必要な行いを終えられる間に原情報を把握して着手し、その成立が妻の全件の仕分け・割当を待つ形に依存しない。

機会が発生してから担当へ渡すまでを妻一人の役割にしない。変更を新規用件の外へ落とさない。

確かめ方: 欠席や原本の到着から、誰が何を受け取り、何の一件としていつ着手したかを辿る。妻の選別と入力を除くと始まらない案は満たさない。先生の連絡で日時が変わった場合も同じく辿り、旧用件が済みという理由で放置する案を通さない。原情報を一度転送する協働は妨げない。

### B. 選べる対応を材料から決める

> 各用件について、意味ある選択肢が閉じる前に、判断する家族が、選択を変える規則・予定・本人たちの望みと事情を確かめ、受講・参加・見送り等の対応を決め、その対応に必要な次の行いが特定されている。

機会を消化するだけでなく、本人たちが望む体験を選ぶ。材料があることを選択の成立へ読み替えない。

確かめ方: 当時どの選択肢があり、誰が何を知ってどの対応を選んだかを辿り、その選択肢・期限が相手の規則と一致するかを見る。無応答の失効を選んだ見送りにしない。規則を越えた上限や期限切れを選択肢へ残さない。本人たちの優先が競合して未決なら、判定者が代わりに決めない。

### C. 行いを引き受けて進める

> 選んだ対応に必要な各行いについて、期限内に実施できる保護者の引受けが成立し、その人が原本・連絡先・判断材料を使って未完を進め、その進行が妻の全件の割当・都度の指示・催促に依存しない。

実施だけ代わって妻が段取りと追跡を抱える形を通さない。

確かめ方: 名前の欄でなく、当人が何を引き受け、いつ何を使って進め、未完ならどう続けるかを辿る。二人とも相手が動くと思う案は満たさない。担当が不在・交替する時は、採用済みHの引継ぎを併せて問う。

### D. 選んだ行いを実際に終える

> 各用件で選んだ対応に必要な予約・申込み・同意の提出・当日の家族側の行いが、それぞれの規則と期限に従って実際に完了し、担当の決定・意向・準備途中だけをその完了として扱わない。

引受け・能力の決定と、価値に必要な行いの実施の間を塞ぐ。

確かめ方: 相手の予約が成立したやり取り、規則に従った原本の提出、必要な当日の準備等を、実際の出来事から見る。署名と提出、送信途中と予約成立を分ける。見送りを選んだ時も辞退連絡等が必要かを規則から確かめ、要らない予約は要求しない。学校の受領規則が未確認なら、署名済みを提出済みと確定しない。

### E. 必要な人が今の状況を区別する

> 対応の継続、家族の予定調整、望む関わりへの参加にその用件の状況が要る時、関係する保護者が、判断が間に合ううちに今有効な対応・残る行いと期限・引受け先・完了と扱える根拠を区別でき、その把握が妻の全件の再照合や連絡できない担当の記憶に依存しない。

処理は済んでいても妻が一件ずつ状況を作り直して追う負担や、望む準備へ加われない隙間を扱う。

確かめ方: 例えば妻が子どもと遠足の準備をする前に、参加の決定、提出の扱い、準備の日と材料、残る分担が分かり、それが原本・予定・実際の行いと一致するかを見る。全員に全履歴を毎日確認させず、その人の次の判断に効く範囲を問う。済みの欄だけで根拠が分からず妻が全件を聞き直す案を通さない。

### F. 望む関わりへ加わる

> 本人が残したいと確認した先生・子どもとの関わりについて、関わる人が必要な機会・予定・材料へ間に合って参加でき、そのために対象用件全ての受け口・割当・未完の管理を引き受け直す必要がない。

管理役を手放すことで、望んだ先生との話や親子の準備まで失わない。

確かめ方: 先生から様子を聞く、子どもと行事の準備を楽しむ等の確認済みの関わりについて、参加しようとする所から実際の場面まで辿る。管理を夫へ移すと妻へ日程や材料が渡らず参加できない案は満たさない。夫が手続きを担い、妻は準備だけへ加われる案は通せる。先生の不在や行事の中止、家族の時間の競合は、情報があるという理由だけで実現済みにしない。

### G. 管理の作業と残したい時間を両立する

> 対象用件を回すために各保護者が引き受ける受領・確認・受渡し・照合等の作業が、通常時と繁忙・不在時の必要な時間・頻度において、whyで残すと選んだ生活の時間や関わりと両立する最低線に収まっている。

妻の追跡を他の家族の望まない長い全件照合へ移すだけで、家族の余白を保ったことにしない。

確かめ方: 案の一巡に必要な作業を担い手ごとに辿り、何分・何回・どの時期に集中するかと、残したい時間や関わりを照合する。夫が毎晩長い全件照合を担わないと成立しない案は、既知の望みに反し満たさない。妻が一度原本を渡すことや手作業そのものは禁止しない。まだ残したい時間の具体が分からなければwhyへ、作業の量が分からなければ手段の説明・実測へ返す。どちらも未確認のまま合格にせず、固定の秒数や推測の許容時間を置かない。

### 時点と最低線を、選びたい機会と必要な行いから定める

A・B・C・Eの時点を、一律の「締切の7日前」へ揃えない。
相手の期限、意味のある選択肢が閉じる時期、受付や原本を使える時間、家族が動ける時間、必要な行いの順序と所要時間を照合する。
選択肢を選べる最後の機会と、その対応を終えられる最後の着手機会の両方を守る必要がある。

旧自演では、スイミングの土曜枠は約2週間前には埋まり、平日なら1週間前でも取れる設定だった。
しかし新しいwhyで本人たちが選びたい機会を残すなら、平日へ移すことがその回の望みと両立するかもBで確かめる。
「予約締切の7日前ならよい」という旧線だけでは、望む土曜の機会を残したことにならない。
逆に、欠席の発生前にその土曜枠が閉じていたなら、家族へ「もっと早く気づく」を課して解けたことにしない。
他の対応を選ぶか、今回は機会へ届かないことを受け入れるかを、残る選択と外部事情の判断へ返す。

学校については、署名や原本を扱える時間も含めて、残る行いを期限内に終えられるかを辿る。
実際の受付・所要時間・家族の時間が未確認なら、その用件の最低線は未確定であり、仮の時刻を正本の基準にしない。

### 引継ぎの成立（新しいwhyに対する一条件の検討版）

この条件は、妻が全件の始動と完了を追い続ける暮らしから離れ、その状態が続くための一つの成立要件である。
条件群は未確定であり、正本の確定条件やhowの選定には進めない。
模型の記述として採用した経緯は[論点8](discussion.md#論点8-引継ぎが成立する一条件を検討版へ置く)に残す。

#### 条件の一文

> 進行中の対象用件で担当の不在・交替により引継ぎが必要な時、次に対応する保護者が、残る行いを終えられる間に引き受け、残る行い・その期限・既に済んだ行いの根拠を区別して対応を続けられ、その成立が妻の全件の整理・照合・催促や不在者への聞き直しに依存しない。

#### 引継ぎが要る場面と、ここで決めること

対象は三つの教室の振替と学校行事の申込み・同意のうち、対応が決まり進行中で、担当の不在・交替により別の保護者が次の判断や行いを担う必要がある用件である。
不在というだけで全件を移さず、担当が戻ってからそのまま間に合う用件には、交替を要求しない。
戻るまでに必要な行いの機会が閉じるのに、誰も引き受けず妻が拾い直すなら満たさない。

引継ぎ先が知るのは、その用件の続きを決めるための未完・期限・完了の根拠である。
例えば署名済みの同意書では、署名が済んだことと学校へ提出したことを分け、原本の所在と、残る提出の期限・担い手を辿れる必要がある。
全ての履歴の写真や受領番号を求めず、次の判断を変える範囲を確認する。
電話の了承で予約が成立する教室なら、対象回と了承を得た経過の記録も根拠になりうる。公式の受領番号が存在すると推測しない。
「予約済み」「提出済み」の欄だけで、何を終えたと扱ったかが分からない案は通さない。

根拠が無い時は、未確認を済みと取り違えない。
ただし未確認の表示だけで合格にはならず、相手への確認等を含めて残る行いへ間に合う必要がある。
確認に要る時間も、後の時間の照合へ含める。

#### 確かめ方と、時点の最低線

引継ぎが必要になる直前の一件を取り、元の担当は連絡できないものとして、その案の受け渡しを辿る。
引継ぎ先本人が、どの用件を引き受けたか、何が済みで何が残るか、いつまでに何をするかを答え、原本・受付の規則・実際の行いと矛盾しない根拠から次の対応へ進めるかを確かめる。
名前を担当欄へ置いただけ、二人とも相手が行うと思っている状態は引受けと数えない。
画面や紙に情報が存在するだけでも足りず、引継ぎ先が使える時点で実物や連絡先へ到達できる必要がある。

相手の期限、原本や受付を使える時間、引継ぎ先が動ける時間、残る行いの順序と所要時間を同じ入力へ置き、期限内に終えられる最後の着手機会までに引受けと必要な区別が成立するかを見る。
複数の受付や行いがある場合は、単に締切から所要時間を引くだけでなく、その順で実施できるかを辿る。
実際の規則や使える時間が未確認なら、その用件の最低線は未確定であり、合格にはしない。

次は条件の判別能力を試す追加のテスト入力であり、実際の学校や家族の事実ではない。
署名済みの同意書を残した担当が連絡できず、別の保護者が引き継ぐ必要がある。
残る確認・提出準備は15分、引継ぎ先が動ける最後の時間は水曜20時–20時30分、提出は金曜登校時とする。
ほかに待ち時間が無いこの入力では、20時15分までに引き受け必要な材料を使えていれば残り15分で進められるが、20時16分に初めて揃う案は金曜より前でも間に合わない。
この曜日や15分を他の用件の固定の基準にはしない。

#### 同じ入力で通す案・落とす案・判定を保つ案

| テスト用の案・場面 | この一条件での判定 |
| --- | --- |
| 署名済みの原本と残る提出の期限を紙で渡し、引継ぎ先が水曜20時に引き受け、原本を使って準備へ進む | この入力では満たす見込み。紙だから落とさない |
| 共有記録から同じ原本の所在と残りを辿れ、水曜20時に引継ぎ先が引き受けて進む | 同じく満たす見込み。共有記録を使うこと自体は採用しない |
| 必要な情報はあるが、二人とも相手が続きを行うと思っている | 満たさない。引受けが成立していない |
| 水曜20時16分に初めて引受けと必要な材料が揃う | 満たさない。残る14分では15分の行いを終えられない |
| 「提出済み」とだけあり、実際には署名済み原本が家に残り、引継ぎ先は残る提出をしない | 満たさない。完了の区別が実物と食い違う |
| 全件の状態を妻が毎晩照合し、引継ぎ先へ残りを配って初めて進む | 満たさない。引継ぎの成立が妻の全件管理に依存する |
| 「家族が必要な時に確認する」としか案に書かれていない | 判定保留。誰がいつ何を使って引き受けるかの説明を案の側へ返す |
| 学校の受領の仕方や原本の入手可能な時刻が不明で、間に合うかが決まらない | 判定保留。その事実を確認し、未確認のまま通さない |

これは使う前の案を机上で照合した結果であり、実際の提出完了や暮らしの改善を観測したものではない。
運用後は、起きた引継ぎの経過と根拠から、引受け・必要な区別・次の対応がこの線で成立したかを見る。
予約や提出そのものが最後まで完了したかは、条件群の実施完了の要求で別に確かめる必要があり、この一条件だけでは代わりにならない。

#### 協働と、まだ覆っていないもの

妻が一件の原本を渡すこと、自分も関わりたい用件を引き受けること、一度の相談や合意した協力は妨げない。
妻が全件の状態を再構成し、配り、催促しなければ引継ぎが始まらない依存を除く。
全員が全件を毎日見ていることや、一画面への集約は要求しない。

この条件は、担当を固定したまま普段どう始めるか、妻が関わりへ加わる時に必要な状況を知れるか、本人の望みから機会を選べるか、行いが実際に終わるかまでを全て覆わない。
そのため、通常時の情報不足を「不在でないから条件の外」と片付けてwhat全体を閉じない。残る条件を同じwhyから導く。
引継げる保護者がいない日や、外部の受付が終わった場合の扱いも未決で、必ず誰かが動けると仮定したり、受け入れ済みの失敗としたりしない。
既存の子どもの情報の開示の前提は維持し、第三者へ見せる新しい許可をこの検討版から作らない。

## 条件群を一巡した検証

### 入力と検証の射程

教室の規則は旧自演の設定を検査材料へ使った。実際の教室の規則を新たに確認したことにはしない。
スイミングは月2回まで・翌月末まで、ピアノは年度4回まで・3月31日まで、英会話は発行から60日である。
予約締切と振替の取り直し可否は旧記録を辿り、旧7日前という最低線や旧受容の採否を、新しいwhyへ自動採用しない。

学校の追加のテスト入力は、月曜に子どもから原本が届き、金曜登校時までに学校へ原本を提出すること、家族は参加を選んでいることとする。
必要な確認・署名・準備は15分で、担当が使える最後の時間は水曜20時–20時30分、原本を子どもへ渡す保護者は金曜朝に対応できるものと置く。
この検査では、子どもが届けた原本を学校が受け取れば提出が成立する枝を使い、受領の別確認が必要な枝も分けて問う。
これは条件を試すための設定で、実際の家族の新しい採否や学校の規則へ追加するものではない。

### 同じ一件を、紙と共有記録で最後まで辿る

紙の試験案Pでは、夫が連絡袋から原本を拾い、規則と予定・参加の意思を確かめて担当を引き受ける。
署名だけで提出完了にせず、残る提出と担当が分かる位置に原本を渡す。妻は原本と決まった予定から子どもとの準備へ加われ、全件の配布や催促は担わない。
家族内の共有記録を使う試験案Qでも、夫が原情報から用件を拾う。対象の原本、選んだ対応、実際の引受けと残りを辿れる形にし、紙の原本の受渡しと実際の提出まで行う。
Qは項目を用意しただけの案ではなく、Pと同じ時点に同じ家族側の行いが起きるものとして比較する。
家族外へ共有するサービスの利用や、仕組みの実装の成立は仮定せず、手段の選定も行わない。

| 時点 | 共通の入力から辿ったP・Qの行い | 対応する条件 |
| --- | --- | --- |
| 月曜、原本が届く | 夫が原本から用件を把握し、妻が仕分け入力する前に着手する | A |
| 参加を決める時 | 原本の規則、予定、本人たちの意思から参加を選び、署名・提出・当日の準備を分ける | B |
| 実施へ進む時 | 夫が署名と提出準備、金曜朝に動ける保護者が原本の受渡しを引き受ける | C |
| 水曜20時 | 夫が必要な原本を使って署名・準備を終える。残る提出を完了扱いにしない | C・D・E |
| 妻が子どもと準備する前 | 参加と提出の状況、準備の日と材料、残る分担を把握し、準備だけへ加わる | E・F |
| 金曜登校時 | 原本が実際に学校へ渡る。この枝の受付規則に照らして提出を終えたと区別する | D・E |

この入力と具体の行いでは、P・QともA–Fを満たす見込みがあり、媒体だけを理由に判定を変えない。
P・Qの実際の作業量と家族が残したい時間の最低線は未確認で、Gまで満たした合格とはしない。
実際の提出や家族の価値の実現を観測した結果でもない。費用の実測、仕組みの故障への対応等を含むhowの成立は別に確かめる。

変更の検査では、新規の用件だけを拾う案だと一度済んだ後の日時変更を落とせたため、Aに選択・期限・担当・完了の扱いへ影響する知らせも含めた。
これは59で述べた「材料が変われば選び直す」を条件群に具体化したもので、新しい一般則の発見として数えない。

### 余白の最低線と、howで比べる費用を分ける

初案A–FとHでは、夫が全ての処理と共有を担い、妻が望む準備にも加われるが、夫は毎晩長い全件照合が要る案を通せた。
これはwhyの既知の「夫は毎晩長い照合を望まない」と、家族の日々の余白を残す価値を満たさないため、Gを加えた。
Gは、時間をできるだけ短くするという好みではなく、選んだ生活と両立する最低線をhowへ渡す。
その線を満たした手段同士の費用差、速さや便利さ、作る楽しみに払う量はhowで比べる。
手段の具体の作業量はhowで見積もる・試すが、その結果が最低線を越えたなら、満たした案とはせず、手段か目標を選び直す。
実際に余白が戻ったかはwhyの測りでも確認し、作業量の見込みだけを価値の実現と数えない。

紙と共有記録のどちらにもGを当てる。毎晩の全件照合に依存する案は落とし、手作業というだけでは落とさず、作業量の不明な案は判定を保つ。
新しい分単位の上限は仮定しない。本人が残したい具体の時間・関わりと、担い手ごとの作業の時間・頻度・集中する時期が揃えば線を決められる。

### 方法の働きと、閉じる前の実際の残り

現行whatの方法で、全ての言い分から条件を導き、通常の一巡・不在・時間経過・外の変更を同じ物差しへ当てられた。
その過程で、行いが済むこと、必要な人が状況を分かること、望む関わりへ加われることを分け、条件同士の間の抜けを問えた。
全条件を満たすと置いた反例では、余白が物差しから抜けたことを発見し、Gを加えた。
今回の範囲では、これらを行うために方法本文へ新しい一般則を足す必要は見つからなかった。
有限の机上検査であり、全ての未来の十分性や方法の最小性を証明したものではない。

| 閉じる前に決める・確かめるもの | 何で判定が変わるか |
| --- | --- |
| 学校の受付と、当日までの家族側の行い | 署名・受渡し・学校への提出・受領のどこで完了か、いつ誰が動く必要があるかが変わる |
| 本人たちが選びたい機会と、実際に使える時間 | 平日枠でもよいか土曜を残したいかで、選択の時点と残せる機会が変わる。一律の7日前では決めない |
| 家族が残したい時間と、各人の管理の作業量 | 通常時・繁忙・不在時の時間と頻度からGの最低線を決める。既知の毎晩の長い全件照合を望まないことは保ち、未取得の許容分数は作らない |
| 満席・中止・体調、動ける保護者がいない時の扱い | 手の内で寄せるか、他の対応を選ぶか、届かないものとして受け入れるかの採否。早く気づけるはずと推測しない |
| 本人同士の望みが競合する場合の優先 | 条件の文言で価値の優先を勝手に決めず、目標や範囲を変える対立ならwhyへ返す |
| 既存の子どもの情報の前提が学校や追加の仕組みに効く範囲 | 受け手・内容・目的で確かめ、既存の限定した採否から新しい開示を自動許可しない |

これらの事実や採否を、テスト専用の入力や自演の架空の同意で埋めない。
方法の検証結果と、実対象のwhatを閉じる採否は分ける。条件群を検討版へ置いても、正本の確定条件やhowの選定へは進めない。
新しい反例や事実で条件が足りないと分かったら、この群の数や分け方を守らず修正する。

以下は旧物差しでの導出・検証・判断の記録であり、今回の確かめ直しの結果ではない。

## 前に受け取った物差し

なぜ作るか層が閉じたアウトカム（正本の[アウトカム](../archive/3rd/README.md#アウトカム)、[なぜ作るか層の記録](../archive/3rd/why-to-build/README.md)）。

> 振替について知っておくべきことが妻の頭の外にあり、妻が覚えていなくても、頼まなくても、二人のどちらも自分で気づいて動け、使える振替を期限の内に使い切れている状態が続いている

この層は、はじめ、なぜ作るか層を通していない仮のアウトカム（「振替のことを妻が一人で抱えず、二人のどちらが動いても、使える振替を期限の内に使い切れている」）で閉じた。なぜ作るか層を閉じた後、差し戻しで受け取り直した（[差し戻し](#差し戻し)）。

## 決め方

### 1. アウトカムの言い分を割り、言い分ごとに要ることを問う

| 言い分 | 成り立つには、何が要るか | 出た条件 |
| --- | --- | --- |
| ア 知っておくべきことが妻の頭の外にあり、妻が覚えていなくてよい | 振替について知っておくべきこと（どの振替が使えて、いつまでか、いつまでに予約が要るか。規則）が、妻の頭の外にあり、二人とも見られる | 条件1、4 |
| イ 頼まなくても、二人のどちらも自分で気づいて動ける | 振替の一生の中の行い（欠席を連絡し記録する、締切に気づく、予約する、受講を記録する）のどれも、片方だけでできる。予約する人は、相手に頼まれたり知らされたりせずに、自分で気づき、自分が予約する人だと分かる。片方が行ったことが、もう片方に分かる | 条件2、3、5、6、7 |
| ウ 使える振替を期限の内に使い切る | 使える振替が一件ずつ、正しい期限と予約の締切とともに分かる。予約が間に合う時に気づく。使えないものが、使えるものと取り違えられない | 条件1、4、5、6、8 |
| エ その状態が続いている | 上の全てが、一度ではなく、三か月後、一年後、片方がいない月にも成り立つ | 全ての条件（2の「時を進める」「人を抜く」で確かめる） |

前の要求（S1〜S8、[archive/2nd](../archive/2nd/README.md#要求)）から変わったこと: S5（1分以内に記録）とS6（計算が自動）は、どの言い分からも出ない手段の好みであり、どう解くか層の得るもの・払うものへ回した。S7（予約まで任せる）はアウトカムを超える上乗せ、S8（振り返り）はアウトカムの測りの側であり、条件にしない。S2の主語「夫が」は「二人のどちらも」になった。夫が欠席を連絡した時の記録（条件2）が加わった。

### 2. 全ての条件が成り立っているのに、言い分が崩れる日を作る

| 進め方 | ア 妻の頭の外にあり、覚えていなくてよい | イ 頼まなくても、二人のどちらも自分で気づいて動ける | ウ 期限の内に使い切る | エ 続いている |
| --- | --- | --- | --- | --- |
| 条件の間を辿る | 作れなかった（規則が分かること（条件1）の次に要る、一件ずつが分かること（条件4）がある） | 締切の7日前に妻だけが気づき、夫に「スイミングの振替、取っておいて」と頼み、夫が予約した。前の条件5「二人のどちらかが気づく」は成り立つが、頼まなくても、が崩れる。一文が緩い → 条件5を「予約する人が、頼まれたり知らされたりせずに、自分で気づく」に締めた（差し戻し）。予約する人を、気づいた時に決める（前の条件6）なら、決める時に妻が頼むことになる。一文が緩い → 条件6を「振替が生まれた日のうちに決まっていて、二人とも相手に聞かずに言える」に締めた（差し戻し） | 締切の7日前に二人とも気づいた（条件5は成り立つ）が、二人とも相手が予約すると思い、どちらも予約しなかった。気づくことと予約することの間に隙間がある。条件が足りない → 条件6を足した | 作れなかった（下の三つの進め方で、続くかを見た） |

どの進め方から出したとも言いにくい日: 振替の日に子どもが熱を出し、振替も休んだ。手の外 → [論点2](discussion.md#論点2-手の外にあるものを条件で寄せるか受け入れるか)。

### 3. 一文の形にし、確かめ方を付ける

八つの条件の一文と確かめ方は、正本の[満たすべき条件](../archive/3rd/README.md#満たすべき条件)に書いた。性質の違う二つの手段（冷蔵庫の横のボードだけのやり方と、全部作る一覧）を当て、どの条件も、満たす／満たさないが迷わず決まった。例えば条件5は、ボードでは見る習慣に頼るため満たさない（習慣はきっかけの無い受け渡しであり、どう解くか層で崩れやすさとして問う）、作る一覧では締切から逆算した知らせで満たす。

## 予約完了の条件を追加した後の再検証

全ての旧条件が成り立つと置いても、予約が済まない日を作れた。担当の夫は締切の7日前に気づき、期限と未予約の一件を正しく知り、予約する時間もある。二人とも担当は夫だと言える。しかし予約せず、締切を過ぎた。
条件6は担当と能力までしか求めず、条件7は予約が行われた場合の共有であり、予約の実施を求めない。この日は、空き枠が無いことや子どもの体調を原因にしていない。

旧アウトカムの言い分ウ（使い切る）から、正本の条件9（締切までに予約が済んでいる）を追加した。
振替が生まれた日に担当が分かることと、予約締切までに予約が済むことでは、確かめる時点と必要な状態が違う。条件6や7へ混ぜず、別に確かめられる条件にした。
この追加は、受講するか見送るかという別の目標への変更ではない。正本のアウトカムと、外部事情を受け入れる既存の判断は維持する。

条件9を加えたため、旧8条件の確認をそのまま九つ全体の確認にしない。
予約の実施が抜けた日は条件9が満たされないと判定できるが、それだけで条件群全体が十分とは判定しない。
予約を終えた後、実際の受講に至るまでに何が要るか、片方が不在の場合、期限内に取り直す場合も含めて再検証する。送迎や準備の実態が未確認なら、勝手に条件へ足さず、何が分かれば決まるかを残す。

この層の閉じ直しは未実施である。どう解くか層の旧選定は旧8条件に対する結果として残し、この層を閉じ直した後、追加条件を含めて確かめ直す。
この部分の適用と残る検証は、[論点6](discussion.md#論点6-予約完了の条件を追加し条件群を開け直す)から辿る。

## 今回返された物差しの変化

whyは、振替を使い切る旧目標から、学校行事も含め、起点からの妻一人の管理に頼らず対応を選び終える目標へ変わった。
この変化を受け取ったことを残し、旧版の結論を自動的に新目標へ採用しない。状態の判断と新しい結論は、確かめ直しを実行した後に残す。
