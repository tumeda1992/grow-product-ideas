# target-user-voices: 習い事の振替を期限切れにしてしまう親の困りごと

## 要求した問いと粒度

| 問いのidentifier | 問いの文面 | 求めた粒度 | この材料で満たしたか |
| --- | --- | --- | --- |
| `why-to-build/pain-to-solve` | 解きたい痛みは何で、今どうしのいでいるか（このアイデアでは「振替を期限切れにするのは、どの場面で何が見えていないからか」） | 同じ痛みを持つ人が何に困り、今何をしているかが分かる程度。利用者は家族（自分と妻）なので参考 | 満たした |
| `what-to-build/existing-alternatives-fall-short`（材料`alternatives`の入力として） | 既にある道具やその組み合わせでは、痛みのどこが残るか | 親が振替や子どもの予定を、実際にどう管理・共有しているか（しのぎ方）が分かる程度 | 一部（振替に絞った親の声は見つからず、子どもの予定の夫婦での共有の声で補った。[親のしのぎ方](#親のしのぎ方)） |

## 中身

### 使う人の像

利用者は自分と妻の二人である。子ども二人が別々の習い事に通い、欠席した分の振替は教室ごとに回数の上限と期限が違う。妻が頭の中と各教室のアプリで把握しており、自分は残り回数も期限も分からないため、予約を代わりに取れない。

### 集めた声

| どこで見たか | 何に困っているか | 今どうしのいでいるか |
| --- | --- | --- |
| 振替の可否についての解説記事（ファイナンシャルフィールド） | 振替を認めない教室もあり、規約は教室ごとに違う | 教室の規約を確認する |
| 教室の振替の案内（申込フォーム、スイミングスクールの資料） | 振替は数日前までの予約が条件、休校日の振替は事前予約が前提、曜日やクラスで振替不可の枠がある | 教室の決まりに従って予約する |
| 教室向けの振替管理アプリ（できた!DEKITA、みんなのれっすん等） | 教室側では振替の期限と残数の管理が要るため、教室向けの道具がある | 教室の道具であり、親が複数の教室をまとめて見る道具ではない |

### 声から読めること

- 振替の規則（回数の上限、期限の基準、予約の締切）は教室ごとに違う。
- 複数の教室の振替を、親の側でまとめて把握する声や道具は見つからなかった。

### 親のしのぎ方

`propose-alternatives`の入力として、親が振替や子どもの予定を実際にどうしのいでいるかを集め直した。振替そのものを親の側で管理するやり方の声は見つからず、子どもの習い事の予定を夫婦で共有するやり方の声と、親が使う道具の説明で補った。

| どこで見たか | 何をしているか | そこから読めること |
| --- | --- | --- |
| [夫婦の予定共有の解説記事](https://atsoho.com/blog/married-couple-schedule-sharing) | 夫婦で子どもの予定を共有カレンダーで共有する。ホワイトボードは毎週の書き直しと、外出先で確かめられない手間があるとする。家族の全員が一つの仕組みを使い続けることが大事で、一人しか使わない道具は働かない、とする | ホワイトボードの弱さ（書き直し、外出先）と、共有の道具が一人だけに寄ると働かないこと。この件の痛みの核心（妻だけが担う）と同じ失敗の形 |
| [Googleカレンダーで家族の予定を共有する記事（エキサイト）](https://www.excite.co.jp/news/article/E1536909806327) | 家族の予定をGoogleカレンダーで共有し、家庭内のダブルブッキングを防ぐ | 共有カレンダーを、家族の間の予定のずれを防ぐ置き場所として使う例 |
| [習い事の管理についての記事（コエテコ）](https://coeteco.jp/articles/14236) | 習い事が二つ以上になったら、子どもの予定と負担を一度見直す | 習い事の数が増えると、親の管理の負担が目立ってくる |
| [Lesson Manager（App Store）](https://apps.apple.com/jp/app/lesson-manager/id1529588362) | 親の側で習い事の月謝の支払いの状況とメモを管理するアプリ | 親向けの習い事管理アプリはあるが、説明に振替の管理は無い |
| [ママスケ（App Store）](https://apps.apple.com/jp/app/%E3%83%9E%E3%83%9E%E3%82%B9%E3%82%B1-todo%E3%82%84%E3%83%AB%E3%83%BC%E3%83%86%E3%82%A3%E3%83%B3%E3%81%AE%E7%B7%8F%E5%90%88%E7%AE%A1%E7%90%86%E3%82%A2%E3%83%97%E3%83%AA/id1322323262) | 家庭のやることを、期日つきのタスクとして管理する | 振替の期限を、期日つきのやることとして扱う使い方がありうる（説明からの推測であり、そう使っている声は見ていない） |

声から読めること:

- 振替を親の側でまとめて管理する決まったやり方は、見つかった範囲では無い。親は、子どもの予定の共有（共有カレンダー）や、期日つきのやること（タスク）の道具の延長で扱っていると読める。
- 共有の道具は、一人だけが使うと働かない。道具を選ぶことより、二人が使い続けることの方が効く、という声がある。

## 確かめた方法と限界

- 一般通説では利用者へのインタビューで得るものを、ウェブ上の記事と教室の案内で代替した。探した場所はウェブ検索（「習い事 振替 管理 アプリ 期限 回数」「習い事 振替 期限切れ 消化できない」）。親の個人の声（SNS、掲示板）は見つからず、読めていない。
- 落ちる精度: 親の困りごとは、記事ではなく教室の案内から推し量っている。痛みの量は利用者役の回答に頼る。
- 集め直し（親のしのぎ方）: ウェブ検索で「習い事 振替 期限 忘れる 管理 どうしてる 親」「子供 習い事 スケジュール 夫婦 共有 カレンダー 振替」「習い事 振替 失効 もったいない 使い切れない」「ママリ 習い事 振替 管理 アプリ メモ 期限」の四つで探した。上位は教室側の振替管理の解説と教室の規約で、親の個人の声（質問サイト、SNS）の本文は読めていない。読めたのは、夫婦の予定共有の解説記事2件、習い事の管理の記事1件、アプリの説明2件の、計5件。振替に絞った親の声は0件である。
- 集め直しの落ちる精度: 解説記事は書き手の勧めであり、実際に続けている親の声ではない。質問サイトやSNSの本文を読めておらず、声を上げる親のしのぎ方も拾えていない。
