## 解き方の選択肢の決め方

### 1. 出どころの事実を確かめる

### 2. 出どころを直接見る形と、足りない点を出す

基準は、二人が、予約しようとする時に、教室のアプリと連絡帳を直接見る形である。

| 情報 | 基準で届くか | 届かない理由 | 補う点 |
| --- | --- | --- | --- |
| スイミング・英会話の欠席、期限と残り、予約、受講 | 届く | ― | ― |
| 締切の7日前に気づく（条件5） | 届かない | 終点の時点に、人が見に行くきっかけが無い | 補う点1（足りない点） |
| 誰が予約するか（条件6） | 届かない | 家族の決めごとで、置き場所が無い | 補う点2（足りない点） |
| ピアノの期限、残り回数、予約の締切、予約（条件1・4・7） | 届かない | 出どころが見せない（計算が要る）。予約は妻だけが見られる | 補う点3（足りない点） |
| 三つの教室をまとめて見る | 届く（三つを見れば） | ― | 補う点4（良くする点） |
| 受け渡しや作ったものが黙って止まった時に拾う | ― | ― | 補う点5（良くする点） |

前の答え（[archive/2nd](../archive/2nd/README.md#解き方)）は、全ての情報をこちらの表計算へ集めていた。基準で届くスイミング・英会話の情報まで足りない点に数え、届かない理由が無いのに受け渡し（欠席と予約の写し）を増やしていた。

### 3. 補う点ごとに、選択肢を出す

候補と事実は、材料[alternatives](../materials/alternatives/README.md#候補補う点)から読んだ。

| 補う点 | 選択肢 | 情報の流れ（置き場所、受け渡しの担い手ときっかけ） | 当てにする事実（確かめたか） |
| --- | --- | --- | --- |
| 1 締切の7日前に気づく | ア: 欠席を連絡した直後に、家族のカレンダーへ締切の7日前の予定を手で作る（作らない） | 置き場所: 家族のカレンダー。受け渡し: 欠席を連絡した人が、ついでに予定を作る。締切が近いことは、カレンダーの通知（自動）が二人へ渡す | 相手が作った予定にも自分の既定の通知が付く（利用者が試した。[材料の論点2](../materials/alternatives/discussion.md#論点2-共有カレンダーで相手が作った予定に自分の既定の通知が付くか)） |

| | ウ: 二人にLINEで知らせる（着想どおり。作る） | 置き場所: 作る一覧。受け渡し: 作るものが毎朝送る | Messaging APIの無料の通数（出典を読んだ） |

| 2 誰が予約するか（着想が触れない） | ア: 予約する人を、1アの予定の名前に書く（作らない） | 受け渡し: 予定を作った人が、ついでに書く | ― |
| | イ: 教室ごとに予約する人を決めておく。片方がいない時は、もう片方（作らない） | 置き場所: 二人の決めごと（家族のカレンダーの説明欄に書く）。欠席のたびの受け渡しは無い | ― |
| | ウ: 一覧の列に書く（一覧の束を取る時） | 受け渡し: 記録した人が書く | ― |
| 3 ピアノの振替 | ア: 規則のメモを見て、期限と残り回数と締切を手で出し、1アの予定に書く。予約したら予定の名前に足す（作らない） | 置き場所: 規則のメモ、家族のカレンダー。受け渡し: 連絡帳を書いた人が、ついでに出す | 規則（年度で変わりうる） |

### 4. 崩れやすい時点で、確かめ方を問う

情報の流れの要素ごとに、要素の種類から効く時点を選んで一度だけ問うた。選択肢は、要素の答えを受け継ぐ。

| 要素 | 種類 | 使う選択肢 | 時点 | 確かめ方に答えられるか | 扱い |
| --- | --- | --- | --- | --- | --- |
| 欠席を連絡した人が予定を作る（ついで） | 人が渡す | 1ア、2ア、3ア | 人を抜く | 夫が連絡するまれな日（年2〜3回）は、夫にその習慣が無く、作り忘れうる（条件5） | 崩れやすさに書く。補う点5で拾う |
| 同上 | | | 時を進める | 妻がアプリで連絡した直後は続く。ピアノの連絡帳の時は、端末から離れており、薄れうる | 同上 |
| 家族のカレンダーの通知と、相手の予定にも通知が付くこと | 自動、当てにする事実 | 1ア、1イ | 外を変える | 通知の仕様や、端末の通知の設定が変わると、黙って届かなくなりうる（条件5） | 崩れやすさに書く。補う点5で拾う |
| 教室のアプリが残りと期限を見せ、夫も見られること | 当てにする事実 | 基準（全ての選択肢） | 外を変える | アプリが振替の残りを見せなくなると、スイミング・英会話の条件1・4を満たさなくなる | 選び直す条件に書く。一覧の束は、この変化に強い（得るものに書く） |
| 毎朝予定を作るscript | 自動（作ったもの） | 1イ | 作ったものを止める | 止まると、締切の7日前に気づけない（条件5） | 補う点5を組む |
| 同上 | | | 外を変える | Googleの仕様や上限が変わると、止まりうる | 同上 |
| フォームで記録する（ついで） | 人が渡す | 1イ、3イ、4 | 人を抜く | 夫が連絡する日は、夫がフォームの場所を知っていれば記録できる | 二人のスマートフォンのホーム画面にフォームを置く（一覧の束を取る時） |
| 同上 | | | 時を進める | 連絡・予約のついでとして続く見込み。予約の写しは、予約が教室のアプリの中で終わるため、薄れうる | 崩れやすさに書く |
| 規則（ピアノ。年度で変わりうる） | 当てにする事実 | 3ア、3イ | 外を変える | メモや計算式が古いと、条件1の確かめ方（規則と一致する）に答えられない | 年度の始めに、規約とメモ・計算式を見比べる |
| 一覧への写し（三つの教室の欠席と予約） | 置き場所の二か所目 | 4 | 置き場所を見比べる | 夫が教室のアプリで予約し、一覧への写しを忘れると、一覧とアプリが食い違う | 崩れやすさに書く。補う点5で拾う |
| 教室ごとの担当 | 家族の決めごと | 2イ | 人を抜く | 「片方がいない時は、もう片方」の決めごとで、締切までに予約できる人に決まる（条件6を満たす） | ― |
| 週に一度の見比べ | 人が渡す（決まった日） | 5 | 人を抜く | 見る人がいない週は、もう片方が見る決めごとが要る | 二人のどちらかが見る、と決める |
| 同上 | | | 時を進める | 繰り返しの予定で起こせば続く。起こさないと習慣に頼る | 繰り返しの予定で起こす |
| LINEで知らせる作るもの | 自動（作ったもの） | 1ウ | 作ったものを止める、外を変える | 止まると気づけない。LINEの料金や仕様が変わりうる | 崩れやすさに書く |

### 5. 得るもの・払うものを出す

作る時間、続ける時間、お金は、材料の費用から読んだ（[対案ごとの費用](../materials/alternatives/README.md#対案ごとの費用)、[候補×補う点](../materials/alternatives/README.md#候補補う点)）。作る時間は、部品ごとの三点と補正（約4倍）があることを確かめた。崩れやすさは、材料のきっかけの無い操作と、上の4から読んだ。手間が減ること、変化に強くなること、満たさない条件は、この層で出した。

| 選ぶ所 | 得るもの | 払うもの |
| --- | --- | --- |
| 一覧の束（1イ・3イ・4） | 手間: 予定作り（約2〜3分×年20回＝約1時間）が、フォームの記録（約30秒×20回＝約10分）に減る。三つの教室を一度に見られる。ピアノの残り回数と締切を、手で数えなくて済む。変化に強くなる: 教室のアプリが振替の残りを見せなくなっても、表計算の計算で崩れない。得たいもの: 作る楽しみ（小さい） | 作る時間: 補正後16／32／62時間。続ける時間: シートの書き換え約20分、保守約2時間（年）。崩れやすさ: スイミング・英会話の欠席と予約を一覧へ写す（基準では要らなかった受け渡し）、scriptが止まる |
| 作らない組（1ア・3ア） | 作る時間が無い | 続ける時間: 予定作り約1時間（年）。崩れやすさ: 夫のまれな連絡とピアノの連絡帳の時の作り忘れ、ピアノの残り回数を手で数える |
| 全部作る（1ウと、作る一覧で3・4） | 一覧の束が買うものに加えて、知らせを家族のカレンダーに任せず自分で送る。得たいもの: 作る楽しみ（一覧の束より大きい） | 作る時間: 補正後42／76／144時間（画面の枚数は材料`experience-sketch`から）。続ける時間: 保守約4〜12時間（年） |
| 補う点2: 予定の名前（2ア）／教室ごとの担当（2イ）／一覧の列（2ウ） | 2イ: 欠席のたびに決める受け渡しが無い | 2ア: 予定作りのたびに決める手間、書き忘れ。2イ: 片方がいない時の決めごとを覚えておく。2ウ: 記録のたびに書く |
| 週に一度の見比べ（補う点5） | 作り忘れ、写し忘れ、scriptの停止、カレンダーの通知が届かなくなった時を拾う | 続ける時間: 約5分×52回＝約4時間（年）。崩れやすさ: 繰り返しの予定で起こさないと、習慣に頼る |

満たさない条件: どの選択肢にも無い（どの選択肢も、条件1〜8を満たす）。

## 解き方の選定の決め方

### 1. 決め手が依る事実を確かめる

| 事実 | 種類 | 確かめた先 | 結果 |
| --- | --- | --- | --- |
| 教室のアプリが振替の残りと期限を見せ、夫も見られるか | 利用者しか持たない事実 | 認識合わせ（[論点1](discussion.md#論点1-出どころは何を見せ誰が見られるか)） | スイミング・英会話は見せ、夫も見られる。ピアノはアプリが無い |
| 保護者のアカウントを家族で共有してよいか | 利用者しか持たない事実（規約は利用者の端末のアプリの中にある） | 材料の決定過程（[材料の論点3](../materials/alternatives/discussion.md#論点3-教室のアプリのアカウントを家族で使ってよいか)） | 同じ世帯の保護者で共有してよい |
| scriptの定期実行の上限 | 動かさないと分からない事実の一部 | 頼む先のskillを吟味していない | 確かめていない。一覧の束の決め手は、上限に依らない（毎朝一回の実行）ため、両側で書く必要は無い |

### 2. 補う点（組）ごとに、境目で比べて選ぶ

| 選ぶ所 | 選んだもの | 次点 | 論点 |
| --- | --- | --- | --- |
| 一覧の束を取るか | 一覧の束 | 作らない組 | [論点2](discussion.md#論点2-一覧の束を取るか) |
| 誰が予約するか | 教室ごとの担当（2イ） | 一覧の列（2ウ） | [論点3](discussion.md#論点3-誰が予約するかを予定の名前に書くか教室ごとに決めておくか) |
| 週に一度の見比べを取るか | 取る | 取らない | [論点4](discussion.md#論点4-週に一度の見比べを取るか) |

### 3. 作る理由を切り分ける

一覧の束が約32時間で買うもののうち、条件に効くのはピアノの分だけである。手間が減るのは年約50分で、作る時間に見合わない。三つを一度に見られることと、アプリの表示が変わっても崩れないことは、得るものとして小さくない。主な理由は、作る楽しみである。決め手にそう書いた（正本の[解き方の選定](../README.md#解き方の選定)）。

### 4. 選び直す条件を書く

| 選んだもの | 選び直す条件 |
| --- | --- |
| 一覧の束 | ピアノが教室のアプリで振替の残りと期限を見せるようになった（一覧の束が条件に効く所が無くなる）。scriptの保守が年2時間を大きく超えた。作る楽しみが得られなかった、または作り終えて続ける楽しみが無いと分かった |
| 教室ごとの担当 | 片方がいない時に、もう片方が予約し忘れたことが起きた |
| 週に一度の見比べ | 見比べで一度も取りこぼしを拾わないまま、半年が経った |

## 確認

| 揃えば満たした | 満たしたか |
