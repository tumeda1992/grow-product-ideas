## 受け取った物差しと前提

[なぜ作るか](../README.md#なぜ作るか)の四つの言い分を受け取る。require-buildは手段の条件へ混ぜず、後の選定で守る。全案への不参加・出所・AI補填禁止・無許可転用禁止は[前提](../README.md#前提にする条件)に従う。
2026-11-21原入力の来週末の土日・二室・撤収まで。制作12時間・同僚準備2時間・当日4人時/日。観測70人分/日は内数。全て合成提供設定である。

## 決め方

### 1. アウトカムの言い分を割り、言い分ごとに要ることを問う

| 言い分 | 欠けると崩れること | 導く条件 |
| --- | --- | --- |
| 参加・不参加を自分で選ぶ | 書かないと読めない、呼び止められる、端末がないと触れられない | C1・C6 |
| 出所を取り違えず他者の見方を受け取る | 運営の問いを来館者の実話や資料の正解と思う | C2 |
| 同じ資料へ戻って確かめる | 問いと物が違う、物へ戻れない、見る場所を見出せない | C3 |
| 自分の問いを望む範囲で後の人へ渡す | 希望した範囲外へ残る、受領だけで渡ったと誤表示、撤回しても残る | C4・C5・C7 |

### 2. 全ての条件が成り立っているのに、言い分が崩れる具体例を作る

#### 最初の条件群v0

1. D1: 希望者は参加せず鑑賞へ戻れる。
2. D2: 受取る言葉に出所と不確かさが付いている。
3. D3: 言葉がどの資料についてか受取人が同定できる。
4. D4: 渡す人は届け先・期間を知り選び、適格な問いがその範囲内で後の人から読める。
5. D5: 訂正・取下げを受けた言葉は、その後に渡す対象から除かれる。

構成例（実際の展示ではない）: 日曜に資料番号17の袋は既に片付けられ、番号と題名が一致する問い札だけが台に残る。来た人は自由に退出でき、札に運営作成と未確定の問いが明記され、17だと分かる。投稿者が選んだ日曜の閉場まで札は残り、別に資料18の問いを作者が取り下げ、運営は札を回収して新たに渡さなかった。D1は退出の自由、D2は明記、D3は番号の一致、D4は17の期間内の閲覧可能、D5は18の実際の取下げと回収というそれぞれの根拠で全て真だが、同じ袋を自分の目で見直す言い分は偽。取下げが起きなかったことをD5の充足根拠にはしていない。
原因はD3が同定だけで、現物又は許された同じ対象の見方へ戻れることを欠く点。C3へ強める。全条件真という主張を単に宣言せず、上の五つの根拠へ対応させた。

#### 条件群v1への再判定

上の片付け例はC3が偽となるため、v1の全条件真の反例には数えない。片付け時に提供を終えるか、許された対象の表示へ移すことが必要になる。具体の方式は選定以降で比較する。

| 構成した場面・境界 | 条件判定と原因 | 戻す所 |
| --- | --- | --- |
| 文字が読めない子へ大人が問いを読み、答えを決めず袋を一緒に見る | C6で自分の速さの受取経路を支持。全員の内心の変化は保証しない | 実際の使いやすさは価値の測り |
| 作者の取下げ後に紙の札だけ残り、次の人が読む | C5偽。v1の反例ではなく実施の違反 | 対応案に回収の経路が要る |
| 二室の運営者の一人が離れ、残る人が無制限の投稿を受領し続ける | C7偽になりうる。引受けと期間内の提供根拠が無い | 費用と運用の候補比較 |
| ちゃんと読め、袋を見直せたが本人は価値を感じない | 条件だけで気持ちは保証できない。採用した姿は機会を持つ状態で、実際の価値は測りで確かめる | whyの採用済み測りを維持 |
| 最後の人が置いた問いを後の来館者が選ばない | 受取人の到来・反応は手の外。提供可能と受取実績を分ける | 閉じで未達可能性を採否へ返す |

探索は条件間の受渡し、日曜撤収までの時間、人の不在、展示対象の変更に絞った。一年継続の条件は今回の目標外。未経験の他者の内心を作らず、全条件真の反例が作れなかったことだけで十分性を保証しない。

#### 条件が本当に要るかを、逆向きにも試す

C3を『資料番号を表示する』に限定すれば、番号が無くても現物の横に問いを置いて同じ物を指せる正当な道を落とす。番号という媒体でなく同じ対象へ戻る性質へした。
C4を『記録に署名する』にはせず、本人が用途と期間を理解し選んだ根拠へした。紙で選ぶ道も口頭で確認し残す道も除かない。証拠が無い同意の推測は通さない。
C5を自動削除に限定せず、取下げ後に新たな受取が起きない性質にした。C6を全員が単独操作する条件にせず、本人が望んだ支援や同行者の読み上げでも戻れる経路を許す。C1を外すと受取るために投稿が必須の案が通るため、自由の性質は必要。

### 3. 一文の形にし、確かめ方を付ける

| # | 一文 | 確かめ方 |
| --- | --- | --- |
| C1 | 来館者は関わり始める前と途中で、受取るだけ・言葉を渡す・関わらず鑑賞へ戻ることを、発話や投稿を要求されずに選べる。 | 初めて来た人が、何もしない・受取るだけの経路を見つけ、実際に戻っても呼止めや入力要求が無いか。 |
| C2 | 受取人は言葉を受取る時、それが来館者の問い・記憶か運営の問いか、確認済みの資料説明かを区別でき、記憶と問いを資料の確定事実へ取り違えない。 | 同じ『袋』に付く運営の問い・来館者の記憶・公開説明を、それぞれの出所と不確かさの根拠へ照合する。 |

| C4 | 渡す人は受領前に、届く範囲・期間・残り方・取下げの方法を知って選べ、選んだ範囲を超えて言葉が使われない。 | 本人が選んだ根拠と、実際の提供先・保持期限を一件ずつ一致させる。未選択を包括同意にしない。その場限りの言葉を将来展示へ転用しない。 |
| C5 | 運営が提供を引受けた適格な問いは、本人へ示した期間中に後の受取人が選べる状態となり、取下げ・期間終了後には新たな受取へ渡らない。 | 受領と提供を分けて、後の経路から一件を受取れるかを確認する。取下げ後・終了後に同じ経路から新たに選べないかも確かめる。過去に覚えた内容の消去は保証しない。 |

#### 性質の異なる二つの手段を当てる

判定能力の検査用に置いた案であり未採用。入力は土曜、袋17がA室に展示中、来館者の合成の問いQ17『折り目は何度使った跡だろう』、期間は土日、作者はその期間だけの提供を明示選択。その後に取下げる。受取人は端末を出さず、運営者AからBへ交代する。

| 条件 | 紙だけの構成例 | ソフトウェアを含む構成例 |
| --- | --- | --- |
| C1 | 読む札と投函口を分け、何もせず通れる表示。読み札を取って戻る。 | 読む経路は投稿を要求せず、同じ札経路もある。閲覧後に戻れる。 |
| C2 | 原本に来館者の問い・期間を印字し、運営札と別表示。Q17は問いとして扱う。 | 保存した出所を画面と印刷へ出し、運営作成と混ぜない。 |
| C3 | 17の現物の横へQ17を置き、折り目を探す手がかりがある。 | 17を選ぶ表示と現物の札が一致し、印刷経路でも現物へ戻る。 |
| C4 | 本人が土日期間に丸を付けた原札を運営が根拠にし、別の用途へ写さない。 | 投稿前に範囲を選び、保存する根拠と表示期限が一致。紙の経路も同じ選択を記録する。 |
| C5 | Bが引継ぎ一覧から札を出し、取下げ申出時にQ17を回収して次の人へ渡さない。 | 保留と提供中を区別し、Bが取下げると新たな読取と印刷対象から除く。紙の回収もBが照合する。 |
| C6 | 紙の経路と任意の同行者読み上げで進め、説明巡回はしない。 | QR以外に紙の経路があるため通る。QRだけならC6不成立で落ちる。 |
| C7 | 原札と出した札の対応、未処理と取下げの記録をBが受取り、閉場に回収する。 | 現在状態と未処理一覧をBが読む。外に出した札を回収し、終了後の保持物を照合する。 |

どちらも上の行いを実施すれば成立の見込みがあるが、机上の構成例であり実利用の取得結果ではない。紙の読札を回収しない案はC5、ソフトウェアが受領だけで『届いた』と出す案はC5、番号を表示順へ再採番して片付けの17が別物を指す案はC3/C7で落ちる。媒体を理由に紙を落とさず、欄や画面の存在だけでソフトウェアを通していない。

### 4. 要るか、どこまでかが決まらない条件を扱う

C1/C2/C4/C5の取り違え・範囲外使用・投稿強要は一件も許さないという線を閉じで問う。C3の見直せることは現物又は許された同じ対象までで、全収蔵品ではない。C6は端末の有無で経路を失わない最低線で、全員の単独操作や全言語対応は上乗せしない。具体の使いやすさは実利用の測りへ残す。
C5は引受けた問いを期間内に提供可能にする線で、受取人の出現・読む行為・心情の変化を保証しない。閉場直前の受領で機会が無い時に受領しない又は別の期間を示す等の分担は、解決策の比較で選ぶ。未確認の来館数や処理時間から数値閾値を作っていない。
C7の引継ぎと撤収は選んだ目標の期間の終わりを守るもの。実在の利用許諾・機器・予算の不足は方式の成立へ渡し、取得済みにしない。今回は実測で初めて最低線が決まる条件を採用しておらず、独立校正を形式のために行わない。
