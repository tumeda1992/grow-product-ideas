## 中身

### 場面からの導出と、比較する一巡

開始で規則と順序を固定し、自分が一手を選び、規則による結果を確認し、迷った基点から別の手又は規則で試し、元と照らして次を選ぶ。途中でやめた時にも、どの回のどこかを指す場面が必要。自作画面の一覧から逆算しない。

| 場面 | 紙の案P | 表計算と紙の案S | 小さい自作の案C |
| --- | --- | --- | --- |
| 始める | 規則名と初期順を一枚に記し、手の列を作る | 同じ値を一つのsheetに置き、別条件は複製して原版を残す | 規則と順を入力し試行を始める。見込みは本人が記す |
| 一手を選ぶ | 札の値と蓄えを規則へ照らし、結果を記す | 本人が手を選び、式と手札を照合する | 本人が札又は休むを入力し、規則の結果を見る |
| 別を試す | 変える直前の記録を別紙へ写し、元を消さずに進める | 元sheetを保持し、分岐と変更箇所を記す | 元の基点と新しい試行を見分けて進める |
| 比べ次へ進む | 当時の見込み・結果・後の評価を並べて次を選ぶ | 値の差だけでなく紙の理由も読む | 元と比較先の規則・手と理由を見て本人が次を選ぶ |
| 中断・失敗 | 何手目かと途中の印を付ける。誤計算は旧記録を残し訂正 | 保存対象sheetと式を確かめ、元を上書きしない | どこまで保存済みか、失敗なら何が残るかを示す必要 |

### 比較用のラフ

```text
P: [規則V0 / 初期順] [元: 初手A3→...7点]
   [試す基点: 初手前] [別: 初手A2→...]
   [当時の見込み] [結果の違い] [次に試すこと]
C: [試行と規則 / 基点 / 何手目 / 蓄え / 手札 / 得点]
   [出す・休む] [見込みを記す] [別に試す] [元と比べる]
   [保存済み又は失敗] [次に試すことは本人が決める]
```

### ウォークスルーの返り

初手A3の後にA6は出せない。ラフが札名だけで入力を受け、元の試行へ上書きするならW2/W5を満たさない。C案には不成立の表示と保存の境界が必要。規則V1をその場で切り替えて途中の蓄えを使うと比較の根拠が変わるため、別の規則で開始し直す操作と同じ基点から手を分ける操作を区別する必要を返す。
紙の案でも、初期順と元の手・理由を保持するため同じ比較を始められる。こちらでCを選ぶ根拠にしない。全画面・全入力の詳細は選定後に同じ材料を育てる。

## 確かめた方法と限界

sketch-experienceの場面導出→人と道具の一巡→差のある案→文字ラフ→同じ入力のウォークスルーを行った。全案で本人が手と次の問いを選ぶ。実際の操作時間・使いやすさは測っていない。

前の比較ラフは残す。Cの「出す・別に試す」を、常に親nodeを明示する操作へ具体化した。前の比較が暗黙の現行選択を必要とするとの読みは採らない。選定の範囲は変えず、依頼元へ通知する。

### 選んだ版のtaskと二つの操作案

taskは出す札を迷う→見込みを残す→結果を読む→同じ出発点で別を試す→理由と差から次を選ぶ。暗黙の現行局面へplayする対話menuと、常に親nodeを指定するcommandを比較した。前者は短いが、保存後・表示前停止の再入力で二手目へ進む誤解が起きる。後者はID入力の手間がある一方、同じ親へ再入力しても同じ一手の並行枝になる。後者を設計へ推し、表示に次に使うIDと候補を置く。最適手を自動で選ばない。

### 全操作のラフ（仕様、まだ実装されていない）

起動形式は `python game.py --data <directory> <command>`。引数なしはhelpと保存先。任意の保存先を人が決め、初期入力は `start V0 --seed default` が既知の順で作る。startは新rootと初期nodeを返し既存を上書きしない。`start V1 --from-root <root>` は順だけを複製し初期値から始める。未知規則や不正順は変更なしのエラー。

```text
list
  保存先 / schema / revision
  r0 V0 / 初期順 / n0 0手, n1 1手, ... n6 6手終了
  r1 V1 / 元r0 / m0 0手 ...
show n1
  r0 V0 / 初期順A2,B5,A3,... / 親n0 / 1/6手 途中
  蓄え0 得点3 手札A2 B5 B2 / 選べる行い rest
  手1 A3 / 見込み「小さい札を残したい」/ 後の評価 未記録
  次: play n1 <card> --expect <text> 又は rest n1 --expect <text>
play n1 B5
  不成立: B5は手札にあるが蓄え0に対し値5。保存なし、n1のまま。
play n0 A2 --expect "小さい札を先に使うとどうなるか"
  保存済み b1 / 親n0 / 1/6手 途中 / 蓄え1 得点2
rest b1
  保存済み b2 / 親b1 / 2/6手 / 蓄え3 得点2
compare n1 b1
  共通r0/n0 / 規則・順同じ / 違い 手1 A3 vs A2
  経過の手と当時の見込み / 後の評価 / 途中1手を両列表示
  蓄え0 vs1 / 得点3 vs2 / 手札と残り5手
  次に試すことは本人が選び、指定した親からplay/rest/start
annotate b1 evaluation "次はA3を試す"
  評価を追記済み。見込みは変更していない。
annotate n1 correction "見込みの誤記。正しくは..."
  訂正を追記済み。元の記述と訂正を分けて表示。
show n6
  6/6手 終了。手の追加不可。compare 又は他の親から別の試行。
```

見込みは `--expect` を省けば未記録。比較対象は既知のID二つ、規則・順・経過が違えばその差も示す。初期順が同じだから規則も同じとはしない。長文はUTF-8で保存、空の評価は拒否。ID不明・引数不備は何を直すかとhelpを返す。

### 停止・故障・終了を含む歩行

成功の文言は保存が終わってから。lock中なら「他の書込み中、保存なし。終了後listを確認して再試行」。書込み失敗なら「新しい記録の保存を確認できない。list/showで現在を確かめるまで次へ進めない」。読取りJSON/schema/参照の異常なら原fileを変更せず、保存先を示し「原本を退避し別の保存先又は紙から再開」。成功表示が無くてもlistでn1があれば保存済みの一手を読む。無ければn0から試す。

操作は一回で終了し、quit commandや常駐は不要。中断で「終了した回」に変更しない。手の誤りは親へ戻って別の枝、文字の誤りは訂正追記。削除・巻戻しで原記録を書き換える操作は設けない。

六手のV0を順にたどるとn6は蓄え2/得点7・終了。V1の別rootで同じ六手なら5/7。V0の別初手A2でも7点となるため、画面が得点しか出さなければW3/W4の比較にならない。上のcompareは途中の手・理由・蓄え・手札まで読み本人が次を決められる形にした。全体の所要時間・読みやすさは未測であり、初回利用で確かめる。
