## 中身

### 入力と切り口

対象は[五条件](../what-must-hold/README.md)、比較期間は3週、予算は0円・6時間。既存の語りと規則を引継ぎ、利用者の過去の実装見積りと実績は無いので補正できない。
必須の三切り口は、現状から元を残す手順だけ足す、普段の紙と表計算を使う、現状を変えない、で実施した。追加で、両端（全手作業／全自動）と、着想を反証する最強の紙の道、時間の幅（当日だけ／3週再開）を使った。他者への引受けは一人用という対象に合わず採用しない。他領域の体験探索は比較を変える不足が今回無く、型のために追加しない。

### 候補の事実と、状態への対応

| 候補 | 得られている根拠 | W1/W2 | W3/W4 | W5と残る不足 |
| --- | --- | --- | --- | --- |
| A0 現状の紙 | 初期入力は規則・順序・手の一回を持つ。戻す時迷った語りもある | 根拠はあるが、毎回どう照合するかは手順が無い | 理由の原文は一部ある。全て分かるとはしない | 原記録を残すかの行いが未整備。情報の存在だけで完了にしない |
| P 紙の局面・分岐・見込みの記録 | 既存の12枚と紙で具体の六手を照合できる。追加の契約・API不要 | 計算と照合を当人が行えば届く見込み | 分岐の時に見込みを残し後の評価と分ける | 元と途中を区別する手順で届く見込み。手計算・写しの負担とミスは残る |
| S 表計算＋紙 | 四則演算ができるという提供設定。特定製品の式と保存挙動は未検証 | 式と手札の正しさは未確認 | 理由を紙で対応させる必要 | 複製忘れ・式の上書きの扱いが必要。便利な履歴機能を仮定しない |
| C 小さい手元の道具 | ルールと入力は既知。[体験の比較](experience-sketch.md)で必要な操作が出た | 中核の実行と拒否の根拠が必要 | 元と別を区別し、本人の入力を残す設計が要る | 保存・停止と中断の根拠が未確認。現時点では成立済みにしない |
| P-day 当日の比較だけ | Pの一回を別紙で比べる所は行える | 当日の比較には届く見込み | 当日の見込みと選択を残せる | 当日分を残さない場合W5未達。翌週の再開は約束しない |

全自動の最適手の再生だけでは、本人が次を選ぶW4に届く保証が無い。比較後に自分で選べる補助にするなら別の組となるが、初期入力に要求が無く今回は作る境目を増やさない。スマホ配布・Web共有は対象外で、その差のために費用を払う価値が未採用のため外した。

### 成立する一巡と、残る人の行い

Pは、原規則と初期順を一組で保持→当人が手を選び計算→迷った所の直前と理由を別紙へ写す→元を残して別の手を試す→見込み・結果を照らし次を選ぶ。保管と再開のきっかけは、次に遊ぶ時に元の一組を開くこと。紙を失えば復元の根拠が無くなり、保管が人に残る。
Cでも、最初の規則と順序の入力・思考と理由の記入・比較と次の選択は人が行う。道具は規則の計算と分岐・記録を支える。紙と同じ価値へ届く可能性はあるが、そのための本実装や成立の根拠はまだ無い。
P-dayは今の迷いをその場で比べる改善で、低い準備負担を持つ。3週の記録へ戻る価値は失う。Pとの差が小さく、残す手間を払える当人ならPの方が有力となる。無理に部分案を選ぶ結論にはしない。

### 費用の一次見立てと、依頼側へ返す不足

| 道 | 準備時間の見立て | 3週で人に残る行い | お金・作る楽しみ・未知 |
| --- | --- | --- | --- |
| P | 記録の枠を整える15／30／60分。未校正の推定 | 毎手の計算、比較基点の写し、残す紙の保管。回数不明なので合計時間は未確認 | 新規契約0。道具を動かす楽しみは得ない |
| P-day | 5／15／30分。未校正の推定 | 当日の比較と計算。次回はやり直し | 新規契約0。翌週の根拠は失う |
| S | 式と保存の確認が未取得で、今回は部品別費用を完成していない | 式の確認、手札と理由の照合、複製・保存 | 製品機能の未確認を未達へ置き換えない |
| C | 表示・入力、中核、記録・読取り、配置、失敗・訂正の部品がある。構成の返り後に三点を積む | 理由・比較と次の選択、記録の持出し・実利用の観測 | 新規契約0の候補。時間短縮は未測、作る楽しみは別の値打ち |

Cの保存を単なる上書きにしてよいか、止まった時に何が残るかで部品と費用が変わる。依頼側へ構成の比較と技術の具体の検査を返す。本文のない「約4時間」で採用を促さず、この材料は選ばない。

## 確かめた方法と限界

propose-alternativesの探索・候補事実・状態表・一巡・部分改善と損失・費用の方法を使った。原情報は初期入力、紙の行いは机上の組立て。外部サービスの機能を検索した事実は無い。C/Sの未取得を満たす又は既知の未達にしない。

## 構成・技術の受領後に返す費用

[同期の構成](implementation-structure.md)と[6件の検査](technical-feasibility/README.md)を受け、最初の比較を消さず費用を補う。単位は分、三点は楽観／最も確か／悲観。実際の当人の見積り・実績が無いため全て未校正の机上推定で、6時間内の完成を保証しない。

| 道・部品 | 作る又は整える時間の三点 | 3週で続ける行い | 配置・失敗等を含めた根拠 |
| --- | --- | --- | --- |
| P 枠・規則照合・保管 | 5/10/20 + 5/10/20 + 5/10/20 = 15/30/60 | 六手の計算と分岐を写す。繰返し回数不明、総分数は不明 | 紙の訂正は取り消し線、原記録の保管。新規契約0 |
| P-day 枠・当日の計算手順 | 5/10/20 + 0/5/10 = 5/15/30 | 計算とその場の比較。翌週は元が無い場合やり直し | 保管しない分を減らす。W5の価値を失う |
| S 式・手札照合・複製保存の確認 | 20/40/80 + 20/40/90 + 15/30/60 = 55/110/230 | 理由の対応、式破損の確認と複製、利用回数不明 | 数値は確認に要する推定。実製品未特定なので、この時間で成立する事実ではない |
| C 入力と表示 | 20/40/70 | 本人が理由・次の選択を入れる | CLI、候補と失敗表示 |
| C 中核と分岐 | 25/45/90 | 規則変更はV0/V1まで | 規則の再現と不成立拒否 |
| C 永続化と読取り | 25/45/90 | 保存場所の保管 | rootと分岐を消さない |
| C 排他・結果の照合 | 20/40/70 | 保存の成否が不明なら現行を読む | 同期lockと原子的切替 |
| C 導入・訂正・退避 | 15/30/60 | 破損なら原本退避し紙へ戻る | 設定は保存directoryのみ。常駐・外部API・利用者認証は不要 |
| C 受入れと観測の仕込み | 25/50/90 | 初回と3週目の自己記録 | 同じ六手と境界、価値は未実測 |
| C 合計 | 130/250/470（約2時間10分/4時間10分/7時間50分） | 保守頻度不明。1回の復旧は退避・再起動・紙の再開。実測の総時間なし | 既存scriptを製品として再利用した値ではない。契約0、実行機材の追加購入なし |

外部サービス契約、他者の同意取り、定期実行はどの現候補にも無い。したがってその差は0であり、保管や毎回の計算まで0とはしない。実際の時間短縮は未測、過去の12分全てが削減対象ではない。
