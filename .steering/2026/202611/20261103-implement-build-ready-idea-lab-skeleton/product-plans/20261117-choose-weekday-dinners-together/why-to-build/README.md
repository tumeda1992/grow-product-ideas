# なぜ作るか（二人の夕食）

- 状態: 閉じた。[層の閉じ](discussion.md#決定論点2)

- 決定過程: [discussion.md](discussion.md)

## 受け取った物差しと前提

[固定入力](../input.md)のC2とD2の語りと一回の出来事だけを使う。本人二人への実際の聞き取りではない。準備30分、新規有料契約を避け、週末15〜20分・平日一人5分程度、常時の全在庫記帳と担当固定は続ける自信が無い。本人役の採否で前提へ確かめる。

## 決め方

### 1. 体験理解 — 価値を見つけ、目標を選ぶために現実を捉える

日曜は二人で候補を話す楽しみ、月曜はD2が遅くてもC2が予定を実行できた良さがある。火曜の時点でC2は玉ねぎと卵の残りを知らず、後で卵があったと判明。水曜は食べられた残りをC2が知らなかった。見える料理名、食材の現実、食べる気持ち、実際の引受けは別。C2の「細かく決める」は当時の感想、D2の「帰りの都合で相談」は後の評価であり、一方を正しい原因へ即断しない。

因果の仮説は、日曜の候補を平日の確定と読み、変化と不明を扱う口が無いため、帰りに全て再相談になること。役割の不平等や会話が嫌いという事実までは無い。買い足しの全時間と頻度は不明。症状だけ減らして共同の選択や自由を落とす仮説を比較する。

### 2. 価値発見 — 体験を動かして、何を変える価値があるかを見つける

| 仮説と変える体験 | 支える所／覆す所 | 得失と負担 |
| --- | --- | --- |
| H1 週末に全て固定し平日の問いを無くす | C2の当時の案を支えるが、D2の変更の自由・担当固定困難で覆る | 確認は減る可能性、変更の言いにくさと予定のための我慢が残る |
| H2 共同の選択をその日の変化へ繋ぐ | 日曜と月曜の良さ、火曜と水曜の不明が支持 | 共同の選択と自由を保ち、変更時の確定・不明・引受けを扱う。二人に少量の行いが残る |
| H3 食材を全量把握し食費を最小化する | 卵の重複購入は支えるが、全帳簿の継続困難と強い節約希望の不在 | 食材ロス減の可能性、二人に全更新の負担。今回の目標にする根拠が足りない |

症状を消すだけでなく、一緒に選ぶ期待を平日に持ち越せる価値へ広げた。反実仮想として、メモが完璧でもD2が変更を言えなければH2は届かない。変更自由でも誰も作らず買物だけ重複すれば届かない。二人が同じ好みでなくても別々に食べる等の選び直しで関係を保つ可能性はあるが、特定の解き方は後で選ぶ。公平な分担・栄養・最安を広げることは将来の候補として残し、今回は根拠と予算から外す。

### 3. 目標設定 — 広がりを比べて、今回選ぶ変化へ畳む

H2を提案する。姿の言い分は、共同の選択を保つ、変更を受ける、候補と不明を混ぜない、引受けと実際の夕食へ繋ぐ。二人の平日と週末を対象とし、全食材の完全追跡・全ての日の同一献立・栄養点数は含めない。病気や営業時間等の外の事情を保証する姿にはしない。

初週の変更があった夕食で、候補と実際の違い、いつ何を知らなかったか、誰が引き受けて食事がどうなったか、確認・記入の分数を記録する。2週後、日曜の楽しみが残るか、変更を言う抵抗や帰りの再相談・買い足しが減ったかを二人別々に振り返る。5分以内に収まる実績はまだ無い。二人の負担又は自由を損なえば選び直す。
作る楽しみの望みは入力に無く、ソフト開発を価値に上乗せしない。食べた実績は当初の月曜のみの検査用設定で、提案の効果は未観測。
