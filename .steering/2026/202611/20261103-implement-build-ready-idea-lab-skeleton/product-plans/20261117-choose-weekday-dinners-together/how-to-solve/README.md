## 決め方

### 解き方の選択肢

#### 1. 出どころの事実を確かめる

初期入力の料理名と両者の語り、現物の食材と食べた本人が出どころ。サービス名、同期/既読は未取得。通知を付ける案には不可欠だが、テキストを見て連絡する案はその性質を保証しない範囲で比較できる。知らない卵の数を列へ入れて解決したことにしない。

#### 2. 出どころを直接見る形と、足りない点を出す

日曜の会話、冷蔵庫の現物、変える/食べた本人へその時に確かめ、実際に作る人へ引受けを聞く基準。月曜は成立した設定、火曜は現物の確認が帰宅までできず、水曜は食べた本人の変更が繋がらなかった。確認ができれば届くが、帰りの全再相談と帰宅後までの不明は残る。

#### 3. 補う点ごとに、選択肢を出す

共同の候補と変更の再相談を補う組A、現物・残りと実行の確定を補う組Bへ分けた。Aは記述と相談の入口、Bは現物を知る人と実際に買う/作る人の行いが必要。Aだけの部分改善も独立して比較する。材料のFはA+Bの強い非開発、PはAを先に試す部分案。着想のメモを候補に入れ、現状維持N、いつもの道具F/P、補助自作Bを比べる。

#### 4. 崩れやすい時点で、確かめ方を問う

日曜は候補と確定の読み分け、変更が起きた時は相手の実際の応答、購入前は現物の根拠、残りを食べた直後と次の調理前は更新を問う。FもPも連絡できず・圏外なら「まだ決まっていない」が終わりで、通知を読んだことにしない。メモとメッセージで現行が割れたら、二人が同じ引用を確認するまでは未確定。古い候補へ勝手に戻らない。自作Bは同じ人の実際の入力が無い限り現物・引受けを補えず、技術だけで突破しない。

#### 5. 得るもの・払うものを出す

材料の部品別三点はF 15/30/60分、P 10/20/30分、B 210/440/840分。全て未校正。比較期間2週、献立変更回数と通知製品が不明で、総時間と月の費用を捏造しない。新規契約0の道を比較し、Bの実装・同期や複数端末の技術は未確認。Pの約束を食材の把握へ広げない。

### 解き方の選定

#### 1. 決め手が依る事実を確かめる

Aは既存のメモを読書きした設定と両者の候補を話す望みに基づく。Bは毎回の現物確認と実際の応答が要り、いつ誰が必ず応答できるか不明。全体目標が成立済みとはしない。今は2週の生活上の実験でAの手間と価値を測り、Bの未達を残す選択を提案する。

#### 2. 補う点（組）ごとに、境目で比べて選ぶ

| 八つの軸 | AのPと全体のFの境目 | 自作B/現状Nをどう比べたか |
| --- | --- | --- | --- |
| 手間が減る | Pは候補と変更理由を一から言い直す所だけを減らす見込み。Fは現物/引受けまで毎回確認する。削減実績無し | Nは再相談が残る。Bも現物と意志の入力が人に残る |
| 得たいもの | 両方共同の選択と自由を支える。Pは夕食への全接続を約束しない | 開発の楽しみは全案で望まれていない |
| 変化に強くなる | Pは希望を候補と区別、Fは残り/担当の変化まで確認 | Bも更新無しでは追従しない。Nは都度相談 |
| 作る時間 | P10/20/30分、F15/30/60分、Fは準備30分を超える枝 | B210/440/840分で30分を大きく超える。N0 |
| 続ける時間 | Pは変更日の記入と相談、5分で未確定なら帰宅後へ。Fは現物にいる人の確認と担当の実応答、毎日5分に収まる実績無し | Bは両者の入力に加え保守、Nは現状の再相談 |
| 崩れやすさ | Pも読み忘れ・同期不明、Fも在宅不在と入力忘れ。成功へ補わず未確定を扱う | Bは止まる/未更新の二重の脆さ。Nは当人の記憶 |
| 満たさない条件と失う価値 | PはW1とW2の希望保持だけ、W2の購入前の相互確定、W3/W4/W5の現物/引受け/日跨ぎの完全接続は未達。帰りの往復と重複購入が残る。Fは人が全確認すれば届くが継続未実証 | Bの表示だけでも同じ未達。Nは入力の痛みが残る |
| お金 | 既存の道具、追加契約0。新しい食事代の増減は不明 | Bも追加契約なしの候補だが機会時間を払う |

AだけのPを選ぶなら全体の条件を下げず、得られない価値を受け入れる。Fが不可能だからではなく、初めから毎回の全確認を引き受けるより、共同の候補と変更の入口を少なく試す選択。保留/現状は手間を増やさないが元の良さと変化の繋ぎ目を何も試さない。

#### 3. 作る理由を切り分ける

自作の楽しみは入力に無い。Aの改善のために新ソフトを作る理由は得られず、テキストの手順を使う。節約の実績は未観測。

#### 4. 選び直す条件を書く

初週に5分程度で相談へ戻れない、どちらかが変更を言いにくい、希望を確定と誤る、2週で同じ重複購入/残りの衝突を主な痛みとして評価するなら、Pを止める又はBの現物/引受けの組をFで補うか選び直す。新ソフト・同期保証・全在庫の記帳へ黙って進めない。

## 部分案の値打ちの再評価

[同じ火曜/水曜のN/Pの比較](../materials/experience-sketch.md#同じ火曜水曜でのnpの差後の再評価)と[候補材料の訂正](../materials/alternatives.md#中身)を受領した。Nには既に二人が読める候補と変更連絡がある。Pの記述/引用で相談をやり直さなくなるという判断には、誰のどの行いが変わるかの根拠が足りず、前の確認表の「満たした」だけで補えない。
Pの5分程度で区切る枝は、不明のまま買う代わりに帰宅後の確認へ回せる見込みがある。しかしその行いはメモへの追記無しの対照でも可能で、帰宅後の負担も残る。Pの記述の値打ち、区切って待つ行いの値打ち、現物/引受け/夕食の未達を分けて比べる必要がある。
前の採否と出口は検査用の履歴として保持する。独立の改善が成立した又は実利用で効果が出たと追認せず、試行で選び直すための根拠不足として残す。この再評価は両者の新しい了承や、Pから対照/Fへの選定を作るものではない。再開時は材料に示した観測と追加負担から、P/より軽い道/中止又はFを比べ直す。作る方針が変わるなら正本の有効な指定に照らして別に選定する。
