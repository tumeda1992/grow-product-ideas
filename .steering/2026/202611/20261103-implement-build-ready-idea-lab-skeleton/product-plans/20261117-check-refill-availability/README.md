## なぜ作るか

### 体験と価値

K1/K2を回り、互換不明の似た品を買わず帰ったC3の一回を扱う。画像を店頭在庫と思った振返りを手がかりに、必要な品の同一性と入手見込み/未確認を分け、確かめないまま寄り道を重ねない価値を目指す。当日在庫一覧は着想であり目標そのものへ固定しない。

### アウトカム

C3が次回の寄り道を決める前に、必要な替芯と入手見込みの根拠・未確認を区別し、来週までに一組を得るための店選び又は別の入手/確認の行いを選べる。

| 持つもの | 中身 |
| --- | --- |
| 言い分 | G1品の同一性、G2対象/時点を含む入手見込みと未知の区別、G3期限/負担から次の行いを選ぶ |
| 大きさ | 一人の指定ペンに合う黒0.5mm替芯一組。次回買物前から行いの選択まで。全店全品/最安値/予約決済自動化は含めない |
| 測り | 次の実際の機会に、同一性/在庫又は別の入手の根拠、当時の未確認と選んだ行い、確認の手間/空振り/入手結果を照合。35分全部を短縮可能にしない。未実施 |

### 作ることで得たいもの

在庫をまとめて見る着想はあるが、制作自体の喜び/学習は未提供。入手の価値へ働く制作として比べ、予算0円/初期1時間/買物前5分程度の確認検討と照らす。電話/店/通販を実際に確認したことにはしない。

根拠: [体験と価値の比較](why-to-build/README.md)、[検査用の閉じ](why-to-build/discussion.md#論点2-層を閉じる)。

## 検討の到達点と不足

[候補の比較](materials/alternatives/README.md)では、包装照合から本人が一件確認する道、通販等の別入手、元の着想の複数店集約、一店だけの取得処理、本人の確認記録を整理する小さい処理を比べた。[判定の根拠](materials/core-logic.md)では、黒0.5mmだけを同一品にせず、画像/通販/店頭在庫/未回答を区別する。現時点でこの品/店の在庫を一件も確定できない。

[技術の返り](materials/technical-feasibility.md)は、実在店/商品key/URL/取得条件が無く対象へ届いていないという不足であり、APIが不可能と実証した結果ではない。probeは実施せず、架空の在庫API/回答済み店を作っていない。B3確認記録の部分部品0.75/1.5/3hは無補正見立てで、配置/入口/受入れを含む総時間や初期1時間内の成立ではない。元の確認に記録を足してどの行いを減らすかの値打ちも未確認。
