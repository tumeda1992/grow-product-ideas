## 受け取った物差しと前提

[入力V1](../materials/input-v1.md#当該案件の原文)は架空のC2/D2の一回と語り。方針は[require-build](../README.md#開発方針)だが、新規アプリへの喜び/費用上限や本人の合意を追加しない。週末15〜20分、平日各5分ほど検討可能、初期30分、継続契約回避、全食材の帳簿は続ける自信が無いことが設定にある。

## 決め方

### 1. 体験理解 — 価値を見つけ、目標を選ぶために現実を捉える

| 場面 | 当時の行い/認識 | 後の評価と仮説 |
| --- | --- | --- |
| 日曜 | 二人で15分話し候補を決め、C2が料理名を共有メモへ、D2も読んだ | 二人で選ぶ時間は良い。読んだだけで調理/変更を引き受けたとは言えない |
| 月曜 | D2が遅くなると連絡、C2が一人で炒め物 | 決めた物を作れたのは良かった。日曜の相談を無駄にしない価値の根拠 |
| 火曜 | D2は辛い物を望まなくなり、双方在宅せず卵/玉ねぎの現状不明、往復と買い足し | C2は細かく決めればと思ったが、D2はその都度相談したい。『固定すれば解決』は片方の良さを損なう |
| 水曜 | C2の残り利用の想定と、D2の昼食で消費した実態が違う | 見えない変化を無かったことにせず、責めない形で次の判断へ渡す必要という仮説 |

同時編集/通知/既読/圏外同期は未取得。実際の節約時間や費用、何週間も続く実績は無い。C2だけの最初の見立てを二人の合意へ替えない。

### 2. 価値発見 — 体験に根ざして、変える価値のある可能性を育てる

| 仮目標 | 同じ火曜の変化 | 得る/失う、担い手 |
| --- | --- | --- |
| 週の予定を詳細に固定 | 買う物は先に決まりやすいが、D2の今の希望を言いにくくする可能性 | C2の再計画は減る狙い、変更する自由を失う |
| 食材を全部数え常に正しい在庫を保つ | 卵の重複を防ぐ狙い | 二人に全数の継続入力を課し、続ける自信が無い制約に当たる |
| 変更を言えて、その時の根拠と引受けから次へ進む | 候補は保ちつつ、今分かる食材/分からない食材と次に誰が何を確かめるかを共有 | 二人が相談/一部の変化記録を担う。全在庫の保証は目標にしない |
| 自動で献立を決める | 相談の往復を減らす可能性 | 好きな共同選択を代行する。本人の望みは未提供 |

誰が知る/いつ関わるかを動かすと、C2だけが冷蔵庫を覚え答える形を改め、消費/変更をした人からその時の判断へ渡す可能性がある。ただし『食べるたび記入できる』等の新習慣の実績は無い。良い週末の相談を保ち、平日も変えられる共同選択へ広げる候補が、両者の語りへ最も直接に繋がる。

### 3. 目標設定 — 目指す変化を選び、whatの物差しへ畳む

提案する姿: 二人が週末に選んだ夕食候補を使いながら、平日の希望や食材の変化を責めずに出し、分かることと未確認を分けて、C2一人の確認に頼り続けずにその日の料理と次の行いを引き受けて進められる。

言い分: G1二人の候補と変更可能性を保つ、G2その時分かる食材と未確認から判断する、G3確認/調理/買足しをC2任せにせず引受けて進む。『全員必ず5分以内』『買足し0』『何週も続く』は入力で保証できず姿にしない。

範囲はC2/D2の週末相談から平日変更/買足し/残り利用まで。朝昼の全食事計画や栄養/最安値は望み未提供、ただし昼食の残り消費は夕食の前提を変える出来事として含む。初回は日〜水の元の場面を通して比べ、続く週の観測は本人の実施があって初めて取得する。

測りは初回の各夕食後、変更希望を出せたか、何を根拠に料理/買足しを決め誰が引き受けたか、未確認のまま買った重複/残り消費の取り違えを記録と照合。二人それぞれに週末選ぶ楽しみと平日の相談/記入負担、C2の確認役が続いたかを振返る。未実施日は成功に数えない。時間/食費の基準値が無いため数値の節約を事前に作らない。

制作そのものの楽しみや学習動機は両者とも未提供。価値へ働く制作案を後で探すが、require-buildを創作の喜びへ読み替えない。片方の希望を固定する/全帳簿を続ける/初期30分を超える仕組みなら選び直す。サービスの性質は後で候補の必要な範囲で確かめる。
