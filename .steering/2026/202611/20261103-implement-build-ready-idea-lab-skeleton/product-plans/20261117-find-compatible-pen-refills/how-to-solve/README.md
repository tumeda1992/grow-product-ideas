## 決め方

### 解き方の選択肢

#### 1. 出どころの事実を確かめる

原包装とペンは当人の家にある設定だが内容は未提供。K1/K2は架空符号なので実店/連絡先を特定できない。店頭/通販/時点を区別して答えられるsourceが未取得。技術の返りは未検査であり「API無し」の反証ではない。

#### 2. 出どころを直接見る形と、足りない点を出す

基準は原包装で品番を確かめ、実際の店/原資料へ同じ品か、店頭か、いつの在庫かを直接確かめ、期限内の受取と残る不確かさを比べて行く/別の道を選ぶ。K2の似た物を同一とせず、表示だけで行った先で買えるとしない。今は最初の商品同定と店対応で止まり、原資料の根拠も取得不能。単なる一覧では埋まらない不足。

#### 3. 補う点ごとに、選択肢を出す

商品同定の組Aは原包装と対応原資料、入手根拠の組Bは店舗/通販への直接確認か既存情報か集約、崩れた時の組Cは残る期限で一件確認/別の入手/見送りへ戻る。着想の集約案も残すが、A/Bのsourceの実在を先に確かめる必要がある。候補材料は未完成の比較として保持する。

#### 4. 崩れやすい時点で、確かめ方を問う

品を比べる時の互換、行く/注文する時の店頭と時点・到着、行くまでの売切れ、回答無し/情報更新失敗、必要日を過ぎる時が崩れる時点。元に戻る時は同じ商品と残る期限を保つ。直接電話にも繋がる/回答/取置きの保証は無い。集約案の更新日時が直近でも実在庫の時点と同じとはしない。

#### 5. 得るもの・払うものを出す

候補材料に八軸と、入力/根拠取得に要する準備の三点を置いた。ただし実際の送料/納期/店の回答とAPI利用条件は未確認で、比較を閉じられない。過去35分を毎回削減できる時間としない。1時間以内で確かめ終わる保証も無い。

### 解き方の選定

#### 1. 決め手が依る事実を確かめる

互換・店舗の対応はどの有力候補にも先行し、答えで直接確認/既存情報/集約の成立と費用が変わる。架空の利用者役は包装に何と書いてあるかを新しく作れない。原入力を変える理由は無く、現在の停止点と必要な入力を残す。今の時点で候補を採用・層を閉じる根拠は無い。

#### 2. 補う点（組）ごとに、境目で比べて選ぶ

未選定。Aの商品同定とBの実store対応の取得が先。電話1件なら速く確かめられる可能性と電話の負担、既存ページなら軽いが通販/古い在庫の危険、集約なら複数店を見られるがsourceと維持の費用、を候補に残す。根拠を得ないまま重み付けしない。

#### 3. 作る理由を切り分ける

開発自体の楽しみは語られていない。集約が必要という根拠は未取得。自作採用はしないが、自作不可能と断定もしない。

#### 4. 選び直す条件を書く

現在は保留の復活条件へ渡す。原包装/ペンの品番又は写真と対応原資料、K1/K2又は実際に対象とする店/通販のURL・正式名称の対応が揃ったら1の出どころ確認から再開し、対象・時点/入手根拠・利用条件を確かめて費用を比べる。必要日が変わった時はwhyの期限に関わる差だけを返す。
