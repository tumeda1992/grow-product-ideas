## イテレーション0: 未設定を外部待ちにせず、明示した検証設定で往復する

<a id="iteration-0-record-1"></a>

### 検証: 目標と範囲の根拠を持って、whyの出口まで一件を通せるか

#### 主張・合格条件・方法

使う方法は論点56反映後のwhy-to-build.mdである。既存の振替の入力、妻が覚えて頼む負担、先生との関わりを保ちたいこと、作る楽しみは維持する。
ここから下の追加設定は、この検証のためにassistantが先に置くものとする。実際に家族へ聞いたことにも、前の自演で既に分かっていたことにも変えない。最終目標は先に固定しない。

追加する出来事と望み:

- 学校行事: 子どもが週の初めに、週末締切の遠足の参加同意書を妻へ渡した。妻が読んで必要な署名を夫へ頼み、途中で二度思い出して声を掛け、提出されたかまで気にした。提出は間に合い、子どもは遠足の準備を楽しんだ。同じような申込み・同意は学校行事で繰り返しある。
- 妻の学校についての望み: 学校の様子を子どもから聞き、行事の準備を一緒に楽しむことは残したい。夫へ頼むことも、次に誰が何をすれば終わるかを自分だけが見張ることも手放したい。読む・話すという望む関わりと、覚え・割り当て・促す負担は、本人の中で同じではない。
- 平穏な夜: 振替の期限と学校の同意書が気にかかり、妻がそれぞれ確かめた。振替だけが進んでも、学校の方を動かすことは自分の役割のままだと感じている。母親が家族の全分野を担うという設定にはしない。
- 夫の他分野の役割: 家計の更新や払い込みの期限は夫が担い、妻はそれらの進捗を催促していない。夫は学校行事の対応も引き受ける意思があるが、毎回妻から指示されて始める形は変えたい。毎晩長い照合作業を増やすことは望まない。
- 子どもと親子の良さ: 既存の、普段の友達との関わりや、家で歌を聞いてもらう楽しさを保つ。下の子は時々一緒に歌いたいが、毎日新しい練習の義務が増えることは望んでいない。親も家族の余白を全て新しい学びで埋めたいわけではない。

これらの追加設定を固定した後、何を重く見て目標と範囲を選ぶかは、ユーザー役（assistant）がこの望みと出来事を根拠に応答する。設定や回答は検証用のものであり、この利用者本人に架空の家族の正解を問わない。

期待するのは、振替だけの改善、子どもに関わる行事を含む役割の改善、家族の全期限、学びの拡張を、名前の大小で決めないことである。
範囲を外すと約束が壊れる場合と、別に価値が残る場合を確かめ、選んだ理由・外した理由・残す未確認を伴う目標を得る。
姿をwhatへ試し割りした時、始める前の情報の受け取りや割り当ての負担を、目標の外へ追い出していないかも具体の場面へ戻す。
条件の全列挙と手段選定をwhyで済ませず、出口は姿・大きさ・測り・体験と価値の根拠・作ることで得たいものとする。
実運用の成果や、全ての題材での有効性はこの検証のclaimに含めない。既存の模型の正本は、検証の結果だけを理由に上書きしない。

#### 実行1 — 学校の一回へ戻り、役割と良さを分ける

以下の発言は、この検証用設定の当人役をassistantが演じた応答である。実在の人の発言でも、過去に既に取得した回答でもない。

assistant（体験理解）: 同意書を受け取ってから提出が終わるまで、何をし、いつ何を気にしていたか。残したい場面はどこか。

妻役: 子どもから遠足の話を聞くのは楽しかった。紙を読んで夫へ署名を頼んだ。でも、渡した後も、書いたか、子どもへ返したか、提出されたかを私が気にしていた。夫が書くことだけを引き受けても、その前後を見張るのは私だった。遠足の準備を一緒にする時間は残したい。

assistantの判断: 役割を他の人が行えることと、始める・次へ進める・終わりを確かめる責任が移ることは違う。学校も同じ構造と断定する前に取るべきだった具体の経過が、この設定では出た。読むこと・子どもと話すことまで消す案は、残したい良さを失う。

assistant（価値発見から別の体験へ戻す）: 家族の他の分野にも、妻が動かして確認する役割があるか。うまく任せられていることはあるか。

夫役: 家計の更新や払い込みは自分が管理し、妻は進捗を聞かない。学校のことも自分が引き受ける意思はある。毎回妻に手順を言ってもらって始める形は変えたいが、毎晩長い照合作業を増やすのは避けたい。

assistantの判断: 家族の全期限を母親が背負っているという大きな目標は、この設定に合わない。すでに夫が自ら回せている体験は、他の人へ指示し監督し続けなくても回る未来を描く根拠になる。具体の道具を真似る話でなく、どんな担い方なら望む変化といえるかを育てる材料にする。

#### 実行2 — 候補を同じ場面に当て、何が成立し何が残るかを比べる

| 目標候補 | 叶った一日の変化 | 残るもの、失いうる良さと根拠 |
| --- | --- | --- |
| 三つの教室の振替の対応を、妻が覚えて頼み続けずに回す | 振替の気がかりと催促を減らせる | 改善自体に価値はある。しかし学校の同意書では、妻が夫を動かし提出まで追う役割が残る |
| 振替と学校行事の申込み・同意で、機会を選ぶ所から対応を終える所までを妻の一人の管理に頼らず回す | 妻が何もない日に子どもの複数の手続きを追う役割から離れ、家族が望む機会を選び実行できる。先生や子どもとの関わりは保つ | 家族の全分野の気がかりを消す目標ではない。情報が届いた時の役割も変わる必要がある。担う親の負担と、続くかの確認が要る |
| 家族の全ての期限の担い方を変える | 必要な分野にも広く同じ変化を目指せる可能性 | 家計は既に夫が自ら回しており、妻は監督していない。対象を増やすことだけで価値は増えず、既に望ましく回る役割まで変える理由は無い |
| 親子で楽しむ学びをさらに増やす | 家で歌う等の良さが新しい体験へ広がりうる | 有望だが、親子は日々の余白を全て新しい練習や義務に使いたいわけではない。今回必要なのは、既に大切にしている学びや関わりを守り、受講数の消化のために押し潰さないことでもある |

assistant（目標設定）: 振替だけの改善にも価値はあるが、学校の同意書を最後まで追う役割は残る。両方へ同じ担い方の変化を求めることと、家計等も含めて全分野を変えることは別である。何を引き受ける価値として選ぶか。

妻役・夫役の選択: 三つの教室の振替と学校行事の申込み・同意について、妻が家族の行動を起こし続けて最後まで追う形を変える。学校を紙だから外さず、同じ役割が残ることと、変われば得られる余白から含める。既に任せられている家計等まで変えることは今回の目標にしない。先生や子どもと関わる楽しみは保ち、空いた時間を全て新しい学びで埋めることも目指さない。

これは検証用の固定設定を踏まえてassistantが生成した自演内の選択である。選択を実在の利用者の合意へ置き換えない。
振替だけに限定した候補を、改善が成立しないから捨てたのではない。改善は成立するが、学校でも残る同じ望まない役割と、得られる暮らしの差を重く見て、今回引き受ける変化を選んだ。

#### 実行3 — 姿を書き、範囲の始点を問い直す

最初の姿は、担う親が必要な事情を知り、予約・提出とその後の対応を期限内に終える、とした。
その姿を具体の学校の一回へ戻すと、妻が全ての知らせを読み、必要な行いへ仕分け、担当を決めて渡した後だけを親が引き受ける形も通せる。妻が一人で初動を作る役割が目標の手前へ追い出される。
体験理解へ、同意書の署名を頼む前に何を行っていたかを返すと、受け取り・必要な行いの理解・担当の判断も、手放したかった負担に含まれると読める。
そこで範囲を対象名だけでなく、機会が生まれ・知らせが届いてから、対応を終えるまでとして姿へ戻した。

一方で、受講・行事への参加そのものが必ず実現すると書くと、体調や催行中止まで家族が保証する強さになる。
ここでは家族が機会を選び、そのために必要な家族側の行いを終える状態と、その結果として実際に望む機会へ届いたかの測りを区別する。予約だけ済めば終わりとはせず、当日までの家族の行いを含める。
条件へ落とす時に手の外の事情へどう寄せるか・何を受け入れるかはwhatで扱い、家族が予約や提出を実施しなかったことを外部事情へ混ぜない。

試作した姿:

> 三つの教室の振替と学校行事の申込み・同意について、機会の発生から対応の完了までを妻一人の記憶・仕分け・割り当て・催促に頼らず、家族が本人たちの望みと必要な事情を踏まえて対応を選び、受講・参加を選んだ分の予約・提出・当日に必要な家族の行いがそれぞれの期限までに済み、望む先生・子どもとの関わりの機会を保っている状態が続いている。

この一文に全ての価値を押し込まず、下の体験の根拠・範囲・測り・後続へ渡す材料を併せて持つ。

#### 実行4 — whyの出口としてまとめる

体験と価値:
振替では妻が記憶し、夫へ頼むことまで担っていた。学校行事でも、妻が紙を読むだけでなく、署名や提出を他の人に促し、最後まで気にする役割があった。
一方、家計は夫に任せられ、妻が監督せずに回る体験がある。妻は先生や子どもとの関わりは望んでおり、全てを手放したいわけではない。
そこから、子どもの機会に関する必要な行いを、妻が始動と進捗を管理するのに頼らず家族が引き受け、本人たちの望みを踏まえて機会を選べる暮らしに価値を置いた。
これらは全て、既存の自演と今回追加した設定に基づく。実際に観測した家族の変化ではない。

アウトカムの範囲:
三つの教室の振替と、学校行事の申込み・同意を対象にする。情報を受けた後だけでなく、機会の発生・知らせの受け取りから、必要な判断・行いが終わるまでを含める。
家計等の既に本人たちが望む形で回る分野、家族の全事務、新しい家庭学習全般は含めない。価値が無いとは判定せず、この設定では今回選んだ変化のために同時に変える必要や優先が確認されなかった、と残す。
当日何を担うか、どの規則と期限を読むか、入院等の不在や外部の中止時にどうなるかは、whatが条件を導くための確認材料へ渡す。未確認を確かめた事実にはしない。

測り:
機会を知り、対応を選び、必要な家族側の行いが期限内に済んだかと、妻が依然として初動や次の行いを追っていないかを、具体の数件から振り返る。
単に未使用の振替を減らすだけでなく、本人たちの望みを踏まえた見送りと、知らずに逃した機会を分ける。子どもや先生との関わりが失われた場合も、その経過から何が不足したかへ戻す。
実際に選んだ機会へ届いたか、余白や気がかりがどう変わったかも見る。家族側の行いが済んでも外部事情で届かないことと、準備・行いの不足を分ける。
妻が毎晩全てを照合して記録することを測りとして課すと、目指す変化を壊す。日々の一巡と忙しい時期に起きた具体の出来事を使い、二人と必要に応じ子どもの振り返りから見る。観測していない今回を成功と判定しない。

作ることで得たいもの:
暮らしの改善と、発案者の作る楽しみを独立して残す。この題材で作りたいという元の動機は保つが、その楽しみを理由に作る判断をwhyで確定しない。

#### 実行5 — whatへの試し割りと、選択後の再評価

| 姿の言い分 | whatが確認・導出すること |
| --- | --- |
| 機会が生まれ、知らせが届く所から妻一人の役割に頼らない | 情報を受けた人・必要な行いを理解する人・担う人の間に、妻が全件を仕分けて配らないと動かない隙間が無いか。妻が受け取った一件を扱うことと、全件の起点を担うことを区別する |
| 本人たちの望みと必要な事情を踏まえて、対応を選ぶ | 意味ある候補が閉じる前に、何を誰が知る必要があるか。受講数を増やすことや、大人の都合だけを判断の代理にしない |
| 予約・提出・当日に必要な家族の行いが期限内に済む | 担当が決まるだけで実施を求めていない隙間が無いか。予約の成立、提出の受領、当日に必要な行いをどう確かめるか。家族側と手の外の事情を分ける |
| 望む先生・子どもとの関わりの機会を保つ | 管理を他の人へ渡した時にも、本人が望む関わりが排除されないか。望まない関わりまで強制しない |
| その状態が続く | 忙しい時期や不在で、妻が起点・進捗の管理を黙って引き取る形へ戻らないか |

全条件や手段をこの場で確定していないが、何を物差しとしてwhatへ渡すかと、どの根拠を使うかは示せた。
学校を含むという対象名の変更だけでなく、初動を作る責任が目標の外に残るという反例から、始点を含めて範囲を選び直した。
また、対象を家族全般に広げることや学びを増やすことは自動的に選ばず、その家族の良い体験と望み・残る負担から、今回引き受ける変化を選べた。

検証内の利用者役は、この意味で目標と範囲、姿・測り・動機の整理を受け入れた。これはこの実演の着地であり、実在の利用者本人の回答を代作したものではない。
既存の模型の正本・whyの閉じの記録は書き換えていない。ここに示した全ては、方法を確かめる別途明示した自演の結果である。

#### この結果で支持できることと限界

現行whyの三つの仕事を往復し、追加設定を含む一件で、体験と価値から、選択の理由を持つ目標・範囲・姿・測り・動機の出口まで進めた。
自演の情報を固定した範囲では、whyが「症状を裏返す」だけにも、「候補を並べて選んだことにする」だけにもならず、whatへの物差しへ接続できることを示した。
実際に家族へ聞いたわけではなく、方法の作者が役も設定も作っている。発見の網羅性、実利用での効果、別の題材や家族での有効性、三つの仕事の最小性・不可分性は証明していない。
この結果をもとに、現行版を今回のsteeringで使うwhyの方法として全体で採用するかを問い、未検証を理由に無条件の完成ともしなければ、全ての未知が消えるまで同じ方法の説明を繰り返し続けることにもしない。

### 判断: 現行whyを、今回のsteeringで使う方法として全体で受け入れられるか

#### 判断対象と選択条件

個別に合意した論点を再承認するのでなく、現行why全文と記録1の自演を照合し、入口から出口までを一つの方法として使えるかを判断する。
必要条件は、体験の根拠と仮説・当人役の選択を分けること、価値を広げた上で目標と範囲を選んだ理由があること、アウトカム・値打ちと期間・測り・動機を持ってwhatへ渡ること、反例や後続の指摘から描き直す往復が実行できたこと、責務の先取りや新しい管理役を増やしていないことである。
一件の自演を、実際の価値発見・実利用での効果・他の全題材での有効性・三つの最小性の証明にしない。
現行why全文を読み直し、各仕事の「揃えば満たした」「止める時」「閉じ」と、自演で実際に残した内容を照合する。不足があれば資料と自演の結果を補い、方法自体が不足していればその箇所を修正案へ戻す。

#### 全文との照合で補った出口の内容

記録1だけでは、値打ちと期間が出口として明示されていなかったため、旧自演の保存済みの値と、今回の具体の負担から補った。
失効は旧設定で年約5回・約12,500円であり、スイミングはあと3年、英会話はあと5年、ピアノは続く見込みである。これらは今回新しく実測した値ではない。
今回追加した学校の一回は提出に間に合っており、失敗件数や金銭損失は発生していない。それでも、妻が渡した後にも二度声を掛け、数日気にかける役割が残ることに、本人役は負担を感じている。
金額へ無理に換算せず、今回の優先は、この役割から離れることと、先生や子どもとの望む関わりを保つことに置いた。家計等で妻が監督しなくてよい良い体験も、望む未来の根拠になった。
対象とする期間は、現在の通学・習い事で親が予約や申込み・同意を担う期間とする。学校について根拠のない残年数を作らず、子どもの自立度、学校や教室、家族の担い方が変わったら、目標と役割の選び直しに戻す。
手段ごとの実際の費用と負担はhowで比較する。毎晩長い照合を増やしたくないという既知の望みを渡し、それを越える手段しかないなら目標の選択へ返す。
