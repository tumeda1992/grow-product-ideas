# 内部検討記録: 論点53 — 価値を保ってアウトカムへ畳む

**discussion:** [implementation_review.md](../implementation_review/implementation_review-51-55.md#論点53-発見した価値を失わずwhatへ渡せるアウトカムへどう畳むか)

**論点:** 論点53

## 開始context

whyの仕事は、症状から体験と可能性を広げ、目指す変化を選び、whatが条件を導けるアウトカムへ畳む所まで含む。
論点51・52では、意図した見送りと機会の喪失、当時知っていたことと後から分かったことを分け、価値の仮説と必要な体験を具体化した。
今回は、その意味を落とさずに姿・範囲・測りへ畳む方法を、一件の条件付き試作で吟味する。
方法の吟味のため、「選ぶ余地を失わず、妻だけが覚え頼み続けず、望む関わりは残す」変化を目指すと仮置きする。
この仮置きは架空の家族の新しい了承や、現実の利用者の優先の回答ではない。
実際の自演の正本とwhatは変更しない。条件の全列挙、全ての実現手段の比較、why全体の閉じもこの論点では確定しない。

## イテレーション0: 価値の言葉を、状態と測りへ畳んで具体の場面へ戻す

<a id="iteration-0-record-1"></a>

### 検証: 条件に割れる姿へ畳んでも、選べる価値の意味が残るか

#### 主張・合格条件・方法

姿・範囲・測りを組にして試作し、元の体験を当て直すことと、whatがどの言い分から何を導くかを試すことの両側から吟味する。
合格条件は、知って見送る場合と知らぬ間に失う場合の区別、選ぶ時に意味を理解すること、妻だけが記憶と依頼を担わないことが、条件へ割る際も失われないことである。
さらに、本人の望む関わりを残すことと、未来の後悔や外部の都合を全てなくすことを混ぜないことを求める。

[現行whyのアウトカム](../../../../../what-defines-a-product/why-to-build.md)と、[whatの決め方](../../../../../what-defines-a-product/what-must-hold.md)を読み、姿は手段に依らず言い分へ割れ、条件を導ける状態であることを確認した。
測りは姿の言い換えではなく、姿へ近づいたかと、実際に痛みが解け望む体験になったかを見る役割を持つ。
既存の「気持ちは測りへ」の方針を、必要な事実や判断材料の不足まで測りへ追い出す口実にはしない。

机上で、まず「家族が納得して選べ、後悔しない」という圧縮案を、本人の望みが後から変わる場面に当てる。
次に「期限前に気づき、予約できる」という状態案を、希望する枠が早く閉じる場合と、その回の意味を知らずに選ぶ場合へ当てる。
その結果に応じて姿を具体化し、意図した見送り、妻だけが段取りを持ち続ける場合、両親が動けても誰も予約しない場合へ戻す。
いずれも新しい本人の回答や実測ではなく、論点51・52の仮定を使った意味と境界の検証である。

#### 圧縮して失った意味と、過剰になった約束

「納得して選べ、後悔しない」案では、選ぶ時の材料が揃っていても、後で本人の望みが変わる場面まで未達になる。
whatが条件を全て満たした結果として未来の気持ちを保証することはできず、姿の言い方が強すぎる。
逆に「期限前に気づき、予約できる」案では、形式上の締切前でも望む枠が無い場合、回の意味を知らずに選んだ場合を落とす。
いずれも予約可能性は残るが、今回仮置きした選ぶ価値には届かない。

この差から、姿へ残すのは、当人が選べる時期、判断を左右する事情を知ること、実際に選び、その選択に沿って動くことであると具体化した。
気持ちの語を消すだけでは畳めたことにならず、その気持ちに効く、手の内で揃えうる状態まで落とす必要がある。
「予約できる」だけでは誰も動かない場面も許すため、試作では決定と、その決定に沿った予約・受講まで述語に含めた。
手の外の満席や体調は、whatで寄せるか受け入れるかの判断を引き続き残す。

#### 姿の試作と、whatへの試し割り

試作は次の一文とした。

> 三つの教室の振替について、本人が望む先生との関わりを保ちながら、担う親が妻の記憶や声掛けに頼らず、受講機会が残る間に候補の日時と選択を左右する事情を把握して受講するか見送るかを決め、受講する分の予約・受講が期限内に済んでいる状態が続いている。

この文は、この価値を選ぶと仮置きした条件付きの試作であり、現行の家族のアウトカムではない。
後半を「できる」だけにせず、決定と実行が抜けない状態にした。
また、望む関わりは背景資料へだけ退けず、姿の意味にも残した。whatが姿だけを物差しにした時、全てを代行して関わりを失う道を無条件に成功扱いしないためである。

| 試しに割った言い分 | whatが具体化する問い |
| --- | --- |
| 本人が望む先生との関わりを保つ | どの関わりを残したいか。選んだ解き方でも、その関わりを失わずに済むために何が要るか |
| 妻の記憶や声掛けに頼らずに担える | 誰が担っても、何を知り、何に気づき、自分の担当と分かり、動いた結果を知れる必要があるか |
| 受講機会が残る間に、判断を左右する事情を把握する | 本人が比べたい候補は何で、いつ閉じるか。日時・枠・締切に加え、受講目的や家族の予定のどの事情が選択を変えるか |
| 受講か見送りかを決め、受講分は予約・受講を済ませる | 未決のまま失う場合と、事前に決めた見送りをどう分けるか。誰が何をいつ行えば決定が実行へつながるか |
| その状態が続く | 行事が重なる時や片方が不在の時も、必要な状態を保てるか |

これは条件の完成表ではなく、姿がwhatの条件導出へつながるかを試したものである。
「選択を左右する事情」という語だけでは広すぎるため、この試作では、論点51・52の判断が分かれた場面と、その事情をwhyの材料として一緒に渡す。
具体的には、望む日時の枠が閉じる時点、その回を見送ると本人の受講目的にどんな影響があると分かっているか、比べたい家族の予定や本人の望みである。
全ての未来を知ることや全候補を常に確保することへ読めるなら、whatが勝手に線を決めず、whyへ問いを返す必要がある。
今回、その事実の全てを取得したとは扱わない。

#### 元の場面へ戻した結果

意図して見送る場面では、事前に決めた見送りを失効の失敗と同一視せずに済む。
気づいた時には望む枠が無い場合は、形式上の締切前に予約できても、「機会が残る間」の不足として見える。
回の意味を知らずに選んだ場合は、判断を左右する事情の不足か、そもそも知りうる情報の範囲を越える期待かを調べる必要がある。
「本人が後悔した」という結果だけを測りに置いて、この不足の検討を終わらせない。

妻だけが段取りと依頼を担い続ける場合は、選べるようになっても、記憶・声掛けに頼らない姿が満たされていないか、姿では表現しきれていない残る負担があると分かる。
両親が予約できるが誰も決めず予約しない場合も、決定と予約・受講を述語へ含めたため、成功とは扱わない。
一方、当時分かる事情を踏まえて選び、必要な行動を終えた後に、本人の望みが変わって後悔した場合は、姿が未達とは自動で判じない。
何が変わったかを理解して、望む価値や範囲を選び直す材料へ返す。

#### 測りを組にした試作

測る時点は、この例では運用を一か月通した時と、次に行事が重なる時期を仮置きする。
期間そのものを全企画共通の固定値にはしない。普段の一巡と、元の痛みが重なる場面の両方を見るための試作である。
選んだ数回の出来事を辿り、事前に選べた見送りと、気づく前に失った機会を分ける。
また、判断に要る事情が後から初めて分かったか、妻が気づき・照合・依頼を抱え続けたか、本人が望む先生との関わりを保てたかを、元の体験との違いとして見る。
失効の総数だけで採点せず、実際に意味ある選択になったか、頭の負担が変わったかも当人の語りで確かめる。

この測りは、姿の達成状況と、姿が望む価値につながったかの両方を見る。
後悔や不満が出た時は、判断材料や行動の不足、知りえない外部変化、本人の価値の変化等を、具体の経過へ戻して見分ける。
結果が悪かったことだけで条件を際限なく足すことも、気持ちだから測りへ置いて終えることもしない。
測るための新しい毎回の記録作業を、この試作だけで家族へ課すものではない。

#### 支持できたことと残る境界

価値の言葉を機械的に姿と測りへ分類するだけではなく、姿に必要な状態を落としていないかと、満たしても価値へ届かない場面が無いかを、具体へ戻して吟味する方法を提案できる。
今回の試作では、機会の期限、判断材料、決定と行動、望む関わりを姿の意味に残し、未来の無後悔は保証しなかった。
ただし、機会の埋まり方・必要な事情・知りうる範囲は未確認であり、これだけでwhatの条件が完成した、家族の目標が決まった、whyが閉じたとは扱えない。
仮説を実際に採用する判断と、whatでどこまでを手の内の条件にするかは、それぞれの判断として残す。

<a id="iteration-0-record-2"></a>

### 検証: 記憶と声掛けだけを外した姿が、確認の責任の集中を許さないか

#### 主張・合格条件・方法

記録1の姿は、妻の記憶や声掛けに頼らないことを述べたが、外部のきっかけで妻だけが毎回確かめ、未決を拾い続ける場合に、覚えて頼み続ける責任から離れる価値を失わないかを再確認する。
この場合に、元の価値を得た成功として扱わないこと、妻が自分で望む先生との関わりは残せることを合格条件とする。
記録1の姿と、担い続ける役割を明記した修正案を、この仮定の一日へ当て直す。
ここでも実在の家族の新事実や、特定の解き方を採用した結果は作らない。

#### 当て直した結果と修正

記録1の姿では、外からのきっかけで妻だけが毎回確認し、必要なことを拾う日も、妻の記憶や声掛けに頼らないと言えてしまう。
したがって、「妻だけが覚え頼み続けない」という価値を、この言い方だけで保てたとは言えない。
確認の責任が残ることは、感情の評価だけではなく、現実に誰が仕事を抱えているかの不足である。
記録1の「姿では表現しきれていない残る負担」を未解決のまま測りへ渡さず、姿の言い分を修正する。

修正後の姿は次のとおりである。

> 三つの教室の振替について、本人が望む先生との関わりを保ちながら、覚えて確認し必要な行動を頼む役割を妻一人が抱え続けず、担う親が受講機会が残る間に候補の日時と選択を左右する事情を把握して受講するか見送るかを決め、受講する分の予約・受講が期限内に済んでいる状態が続いている。

この姿なら、妻だけが毎回確認して未決を拾い続ける日は、その役割を抱え続けない言い分が満たされないと分かる。
whatは、誰が何を把握し、未処理に気づき、必要な行動を引き受け、片方が不在の時も回るために何が要るかを、この言い分から導ける。
役割を誰にどう割り当てるかという解き方は、ここで決めない。

修正前に確認した他の場面にも戻した。
意図した見送りは引き続き区別でき、機会が閉じる前の判断材料と実際の行動も残る。
本人が望む先生との関わりを保つ言い分も維持しているため、責任から離れるために、その良さまで一律に手放す姿にはしていない。
未来の後悔を保証しない扱いも変わらない。
この修正をdiscussionの現在の試作へ反映し、記録1の最初の姿と発見過程は残す。

### 提示前の文書レビュー

論点52への合意の原文と範囲を保存し、仮定の聞き取り結果を家族の新しい事実としていないことを確認した。
論点53は、既存の姿・範囲・測りの型をもう一度採否するのでなく、価値が落ちた圧縮案と修正した姿、whatへの試し割り、元の場面への戻しまでを判断材料にした。
特に確認の責任が残る日は、気持ちの測りへだけ渡して終えると価値が落ちるため、記録2で姿を修正し、既確認の場面も当て直した。

姿の試作の採用前提、情報の未確認、手の外の判断、測る時点の仮置きを明示し、現行正本やwhatの更新を合意済みにしていない。
試作の一文と試し割りの言い分を照合し、修正で他の価値を落としていないことを確認した。
実際の該当事例を観察できない時は未観測として残し、期間を通しただけで価値を得たと判定しない。
文面を条件へ割れることと、本人の望む価値が確定したことを分けて提示する。

### 合意と、現行の層fileへの接続

利用者の「ok」を提案0への合意として保存した。
体験理解・価値発見・目標設定を具体に往復した結果を、現行whyの層fileへ組み直す段階に進む。
改稿の照合では、現行の出力と正本の雛形が「痛みの核心から、痛みが解けた姿を出す」形に閉じており、方法だけを直しても、選んだ価値の根拠が後続へ残らない可能性を確認する必要がある。
自演の家族の新しい目標を採用する作業には広げない。

合意後の`doc-enricher`の提案レビューでは、今回の一般的な検証原則は既存標準にあり、具体の畳み方はwhyの層fileへ組み込む対象であるため、別READMEへの重複した知識提案はGate Gで見送った。
