## 論点56: 目標候補の関係を確かめ、引き受ける変化と範囲を組み立てる

**ステータス:** 反映済み

**親論点:** 論点49

**種別:** 目標設定の方法の具体化

### イテレーション0（論点56）: 候補の関係と、外すことの意味から目標を選ぶ

#### 開始の入力（論点56）

論点54でwhyの改稿を反映し、論点19の自演で体験から仮の姿をwhatへ渡した。そこでは学校の期限を含む範囲の優先等が未確認のまま、三つの教室の振替を試作の範囲に置き、後続の予約完了の欠落の修正（論点55）へ進んだ。
利用者の「今考えるべきは何？」に対し、assistantは、whatの穴埋めへ寄りすぎたことを認め、whyが広げた価値から目標と範囲を選ぶ判断の中身が本筋だと説明した。
それを受け、利用者は次を依頼した。

> ok。じゃあ考えるべき論点について深めて提案して

新しい家族の目標を選んだという応答ではなく、whyの目標設定を深めて具体案にする依頼として扱う。
論点49の「暮らしの姿を描き、範囲で変わる価値を比べる」という選び方は維持する。その中で、候補どうしの関係と、何を外したのかを実際に判断できる方法を、下位の論点として詰める。

#### 提案0（論点56）

広げた価値から目標を選ぶ時は、**候補がどんな体験を何によって良くするかを確かめ、引き受ける変化と範囲を一緒に組み直す**方法にする。
そのための具体の本文として、why-to-build.mdの目標設定の前半を、下の完全diffへ置き換える案を提案する。
今回の採否は、この選び方をwhyへ組み込むことについて求める。三つの教室、家族の期限全体、子どもの学びのどれを架空の家族が選ぶかを、利用者へ問うものではない。

##### 候補を、同じ軸の大小だと思って並べない

「振替の管理負担をなくす」「家族の期限を一人で背負わない」「子どもの学びを豊かにする」は、小・中・大の三案として選べるものではない。
管理負担を減らすことが学びを支えるかもしれないが、それだけで子どもが望む学びが増えるとは限らない。
同じ場面へ当て、一方が叶っても他方が叶わない日、両方を目指すとぶつかることを描き、候補の関係を確かめる。

その結果、候補を並べ直すだけでなく、目指す変化を描き直す。
例えば、望む先生との関わりを残すことと、教室の管理を丸ごと抱えることを分けられるなら、「全部を手放すか、全部を担うか」から、「望む関わりを保ちながら、望まない管理の役割から離れる」という目標候補へ育てられる。
この関係も、本人の体験へ戻して確かめる仮説であり、assistantが名前を付ければ成立するものではない。

良い体験が見つかった時も、その良さを守りたいのか、さらにどんな体験へ広げると価値があるのかを描いて、当人と確かめる。
家で歌った一回が楽しかったという自演の設定だけで、「学びを増やす」を主目標にしない。一方、そこから育つ可能性を、困りごとが無いからという理由で捨てもしない。
「学び」の方が抽象度の高い言葉だから優先することや、母親の負担を減らす価値をその下へ従属させることもしない。

##### 外すと約束が壊れるのか、別の価値が残るのかを確かめる

ここが、範囲を選ぶための具体の分かれ目になる。
次は判断の違いを確かめる思考実験であり、この家族の望みや優先を確定する回答ではない。

| 選ぼうとしている変化との関係 | 学校の期限を外す時の判断 |
| --- | --- |
| 「家族の期限を妻一人が背負わない」を約束し、学校でも同じ役割が残る | 振替だけでは約束に届かない。学校を含めるか、価値の差を示して目標を選び直す必要がある |
| 「振替について覚え確認し頼む役割から離れる」を選び、学校は別にも成立する改善である | 学校が残ることだけで、その改善が失敗とはならない。ただし、学校まで変える候補との得失と、なぜ今回この変化を選ぶかは比較する |
| 二つは別に成立するが、本人が引き受けられる時間や変化への負担を取り合う | 別の候補として残すだけでは足りない。どちらの体験をどれだけ変える価値があるかと、引き受ける負担の差から、今回の優先を選ぶ |

「三つの教室」を先に固定して、その中に収まる目標を後から作らない。
同時に、振替の改善を大きな言葉で言い換え、家族の気がかり全体が解けると約束することもしない。
どの変化を引き受けるかと、その価値に必要な範囲を、往復して選ぶ。
ある範囲で改善が成立することは、その範囲を今回選ぶ理由とは別である。後者まで根拠を持って判断する。

##### 選択を変える問いを、体験と価値へ返す

未確認を列挙して止まるのでなく、何が分かれば、どの候補や範囲をどう選び直すかを示す。
例えば、妻が何も起きていない日に気にして確かめた一回を、何を見て、何が分かれば確認を終えられ、何が気にかかり続けたかまで辿る。
学校の期限も有力な候補なら、直近の一回の、知る・動く・最後まで気にする役割と、得たこと・失ったことを取る。
その答えで、振替だけを変えた時に外れる役割と、学校まで含めないと残る役割、どちらを目指す価値があるかの理解を更新する。

目標の成立に効く未確認と、別の有力な候補が今回の目標・優先を変える未確認は取りに戻す。
「別の価値だから今は外す」という札を、比較を省く理由にはしない。
一方、今回の選択理由を変えないと根拠をもって示せる不確かさは、選び直す条件とともに残せる。全ての可能性を否定することまで要求しない。
手段を比べなければ分からない費用は、whyで先に確定せず、既存のhowから選び直す接続へ渡す。

材料が育ったら、assistantは、なぜその変化を今引き受ける価値があるか、他の有力な候補との得失、残る負担と推す理由を示す。
当人の望みや制約を踏まえて利用者が選び、その根拠を持ったまま、後半の姿・大きさ・測りへ畳む仕事へ進む。

#### 検討記録（論点56・イテレーション0）

論点49には既に、価値の名前だけで選ばないこと、学校を紙という理由だけで外さないこと、関わりと負担の両方を吟味することがあった。
今回の不足は、その方針を自演へ適用する時に、目的・それを支える変化・残したい良さ・別に成立する価値を十分に描き分けず、範囲を選んだと言える根拠を育て切れなかったことである。
そのため、範囲を変えて差を見るという原則の再確認から、候補の関係を場面で確かめ、外すことの意味に応じて目標・範囲・次に問うことを変える操作へ降ろした。

同じ学校の期限でも、選んだ目標を壊す場合、独立した改善の場合、別だが優先が競合する場合に、異なる判断が必要になることを机上で照合した。
良い体験の保全と拡張、管理と望む関わり、共通する価値のある候補、手段次第の費用にも当て、初案の「他の候補には無い価値」を必須に読める言い方等を修正した。
これは本人の優先や実利用の成果の検証ではなく、方法が異なる入力を区別して扱えるかを確かめた範囲である。

採用すれば、今回の本文案で自演の未確認へ戻り、どの答えでどんな目標を選び直すかを実行する。今回の採用自体を、架空の家族の目標の確定や、why全体の磨き込みの完了にはしない。
実際の本文への適用は今回の案への応答後とし、この提示時点では層fileも模型も変更していない。

#### 提案0（論点57）

個々の方法への合意を取り直すのではなく、体験理解・価値発見・目標設定を一件で往復した結果を見て、whyの設計をこの版で一区切りにできるかを判断してほしい。

対象は論点54・56を反映済みの[why-to-build.md](../../../../../what-defines-a-product/why-to-build.md)全文である。
以下に、今回の判断材料となる自演の追加設定、選んだ理由、アウトカムとwhatへの引き渡しを示す。
追加設定や当人役の応答はassistantが用意した検証用のものであり、実在の家族への聞き取り結果にはしない。

##### 自演で取った体験と、広げた可能性

元の入口は「習い事の振替の期限と残り回数を管理したい。失効をなくしたい。作るのは好き。LINEで通知が来ればいい」である。
妻が覚えて夫へ頼むことまで担い、何もない日にも気にし続けること、先生や子どもとの関わりは残したいことを出発点にした。

未設定だった学校の一回を、次のように追加設定してから自演を続けた。
遠足の同意書は期限内に出せたが、妻が読んで夫へ署名を頼み、二度声を掛け、提出まで気にしていた。学校の様子を聞き、子どもと準備を楽しむことは残したい。
一方、家計の更新や払い込みは夫が自分で担い、妻が催促しなくても回っている。
親子は家で歌う楽しさも保ちたいが、空いた余白を全て新しい練習の義務に変えたいわけではない。

この設定で、受講の失効を減らすことから、家族が望む機会を選ぶこと、妻が初動と進捗を管理し続ける役割から離れること、残したい関わりと余白まで可能性を広げた。
家計の良い体験は、自分が監督せず他の人が引き受ける未来を描く根拠にもなった。

##### 何を選び、なぜその範囲にしたか

| 候補 | 自演での判断 |
| --- | --- |
| 振替だけを変える | 改善自体は成立する。しかし学校でも、妻が動かし最後まで追う同じ望まない役割が残る |
| 振替と学校行事の申込み・同意を変える | 今回選んだ。両方で残る役割と、それが変わった時の暮らしの差を重く見た。紙かアプリかを理由に選ばない |
| 家族の全期限を変える | 家計等は既に本人たちが望む担い方で回っており、同時に変える理由が無い。対象を大きくすること自体を価値にしない |
| 新しい学びを増やす | 可能性はあるが、今回は既にある楽しさと余白を保つことを重く見た。抽象的に上位に見える言葉だからと優先しない |

この選択は、自演内のユーザー役が固定した出来事と望みを踏まえて行った。
振替だけでは改善が成立しないから学校を足したのではなく、成立する改善どうしを比べ、今回は学校でも残る役割を変える価値を選んだ。

対象名を選んだ後も、姿を試作すると、妻が全ての知らせを仕分けて担当を決めて渡した後だけ、他の親が対応する形を通せてしまった。
体験理解へ戻り、手放したい負担にはその初動も含まれると確かめ、範囲の始点を機会の発生・知らせの受け取りまで戻した。
これは三つの仕事を一度ずつ埋めたのではなく、後ろの試し割りから体験と目標へ返して、実際に範囲と姿が変わった箇所である。

##### whatへ渡したwhyの出口

体験と価値の根拠は上の出来事と望みである。今回選んだ価値は、子どもの望む機会を家族で選び、そのための必要な行いを、妻が始動と進捗を一人で管理することに頼らず引き受け、望む関わりと余白を保つことである。

姿:

> 三つの教室の振替と学校行事の申込み・同意について、機会の発生から対応の完了までを妻一人の記憶・仕分け・割り当て・催促に頼らず、家族が本人たちの望みと必要な事情を踏まえて対応を選び、受講・参加を選んだ分の予約・提出・当日に必要な家族の行いがそれぞれの期限までに済み、望む先生・子どもとの関わりの機会を保っている状態が続いている。

範囲は、振替と学校行事の申込み・同意について、機会が生まれる所から必要な家族側の対応を終える所までである。
既に回る家計、家族の全事務、新しい家庭学習全般は含めない。価値が無いと断定せず、今回同時に変える必要や優先を確認できなかった可能性として残す。

測りは、必要な行いが期限内に済んだかと、実際に望む機会や関わりへ届いたかの両方を持つ。
妻が初動・進捗を追い続けていないか、意図した見送りと知らずに逃した機会を区別できるか、関わりや余白を失っていないかを、日々の一巡や忙しい時期の具体の数件から振り返る。
測るために妻へ毎晩の照合・記録を課して、同じ負担を戻さない。
体調や催行中止等の外部事情と、予約・提出等の家族側の行いの不足は、経過へ戻して分ける。

値打ちは、旧設定の失効の年約12,500円に加え、提出が間に合っても何日も気にして促し続ける負担と、望む関わりを保つことにある。金銭へ無理に換算しない。
続くのは、親が現在の教室と学校行事の対応を担う期間である。旧設定ではスイミングはあと3年、英会話はあと5年で、学校の残年数は根拠なく作らない。子どもの自立度や家族・学校の担い方が変われば選び直す。
暮らしの改善と、この題材で作る楽しみは独立して残す。作るか、どの負担を受け入れるかは、手段と費用が出るhowで選ぶ。

whatへは、次の言い分と材料を渡せた。

| 言い分 | whatが問うこと |
| --- | --- |
| 起点から妻一人の管理に頼らない | 情報の受け取り・必要な行いの理解・担当へ至る間に、妻が全件を仕分け配る役割が残らないか |
| 本人たちの望みと必要な事情から選ぶ | 意味ある機会が閉じる前に、誰が何を知る必要があるか |
| 家族側の行いを期限内に終える | 担当の決定と実施の完了を分け、予約・提出・当日に必要な行いを確かめられるか |
| 望む関わりの機会を保つ | 管理の引受け先を変えても、先生や子どもとの望む関わりが排除されないか |
| 状態が続く | 繁忙や不在で、妻が全体の起点・進捗を黙って引き取る形へ戻らないか |

条件の全列挙や最低の線、教室や学校の規則・実際の情報の出どころ、外部事情へどう寄せ何を受け入れるかは、what側で確かめる。未確認を確定した事実にはせず、そこで目標が強すぎる等と分かればwhyへ返す。
今回、whatやhowの新しい条件・手段を選び終えたとはしていない。

##### 今回採用することと、残る限界

現行版で、体験に潜る、価値を育てる、目標と範囲を選ぶ、姿・大きさ・測り・動機へ畳む、whatへ物差しと根拠を渡す所まで、一件で繋がったと判断する。
この版を今回のsteeringのwhyの土台として使い、後続の実物への適用で反例が出たら、該当する仕事へ返して改稿する方針で一区切りにする。

作者が設定と当人役を兼ねた一件の自演であり、実際の望みの発見や実運用の効果、他の全題材での有効性を証明していない。
三つの仕事の数・境界・文言を固定せず、統合・削減・置換が必要と分かれば見直す。今回受け入れるのは使う設計版としての全体であり、揺るがない最終形という評価ではない。

既存の模型の新目標への置き換えや、what・howの修正内容を、この提案へ未提示のまま含めない。
合意後は、この自演と既存模型の差分を具体化し、次の必要な判断まで進める。反映報告と「次にやること」だけで継続を止めない。

## 論点60: whatの条件を試す時、判定の根拠と不足の返し先を明確にする

### イテレーション0（論点60）: 自己申告の合格と、不要な遡及を防ぐ

#### 提案0（論点60）

対象は[what-must-hold.md](../../../../../what-defines-a-product/what-must-hold.md)の「3. 一文の形にし、確かめ方を付ける」の、二つの手段を試す段落と合格条件である。

##### 今の案にあった問題

「用件を拾う」「望みを踏まえる」等は、考えるべき内容を示している。
しかし「必要な時点」「必要な事情」「望む関わり」の意味と、何を示せば満たしたと言えるかが曖昧なままだと、後続の担当が目標を再解釈しないと判定できない。
一方で、案の説明に「共有できる」「担当を決める」「完了を確認する」と並べるだけでも、条件を満たす説明に見えてしまう。
これは抽象化によって残すべき合否の差を落とした状態である。

抽象化では、特定の道具や操作を外しても、選んだ価値が成り立つための関係と、満たしたと言える下限を残す必要がある。
何でも通せる共通の言葉へするのではなく、違う手段にも同じ物差しを当てられるようにする。
条件の文章だけでなく、それを支える具体の事実と、満たす場面・外れる場面も必要になる。

##### 同じ入力へ具体案を当てた結果

次は判定能力だけを試すテスト用の設定であり、模型の家族の事実を変更するものではない。

##### 判定できない時の戻し先を変える

現行文は、二手段のどちらかで「一部」「場合による」となったら条件の一文が緩い、としている。
しかし上の説明不足の案は、内容を補えば満たす形にも満たさない形にもなり得る。条件自体やwhyを直すべきと決まったわけではない。
修正後は、条件の曖昧さ、案の説明不足、最低の線を左右する事実の未確認、目標や価値の未決を分け、それぞれの不足へ返す。
判定材料が足りない案を合格に数えず、同時に、条件違反とも決めつけない。

使う前には、案が示す具体の行為と受け渡しから、成立する見込みと崩れる所を評価する。
まだ起きていない完了を観測済みにしたり、全未来の成功の証明を要求したりしない。
条件を試すための具体化と、howで手段を選ぶことは分け、実装を先に終える手続にも変えない。
