# archive

レールの見直し（このsteeringの論点22。退避は論点34）の途中で、リポジトリの`what-defines-a-product/`と`.agents/skills/`のうち、まだ新しい形で吟味していない層fileとskillを、ここへ退避した。下の表の場所は、リポジトリの根からの退避前の場所である。

| 退避したもの | 退避した理由 |
| --- | --- |
| `what-defines-a-product/README.md` | 問いを単位にした書き方（問いの形式、系統、一段目等）が中心であり、問いを外して層と層が決めるものにした決定に合わない。材料の節と、作らない・保留へ向かう答えの節は、新しい形で吟味し直してから戻す |
| `what-defines-a-product/what-to-build.md` | 何が成り立てばよいか（`what-must-hold.md`）と、どう解くか（`how-to-solve.md`）に置き換えた |
| `what-defines-a-product/why-to-build.md`、`how-far-to-build.md`、`how-to-build.md` | まだ新しい形で吟味していない |
| `skills/`の九つ | まだ新しい形で吟味していない。`settle-question`と`grow-product-idea`は、外した問いを単位にしている。`settle-question`は戻さない。層ごとに違う中身は層fileへ移り、どの層にも同じ規律は`what-defines-a-product/`の共通の所に書き、進め方は`grow-product-idea`が持つ（論点35・提案1） |

吟味して新しい形にしたものから、リポジトリの元の場所へ戻す。退避先は、はじめリポジトリの`archive/`だったが、利用者の指示で、このsteeringの中へ移した（論点34。論点35の提案1へのフィードバックで指示）。`.agents/skills/propose-alternatives`は、この見直しの中で吟味したため残した。論点36・37の決定で、頼まれ方（何のための依頼か、依頼した側へ返す、材料の決定過程）を書き直した。`sketch-experience`と`grow-product-idea`は、論点36・37の決定で書き直して`.agents/skills/`へ戻した。ここにある二つは、書き直す前の姿として残す。どの層にも同じ規律は、今は共通の所に書かない（論点37の行うことへのフィードバック）。
