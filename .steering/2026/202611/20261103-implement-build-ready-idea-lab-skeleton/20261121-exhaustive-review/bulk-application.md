# 既存レビューの残指摘の全件適用と、その後の再レビュー

## 委任と順序

2026年11月21日の利用者の[指示原文](../pending-escalations/009-theme-complete-review-and-findings-review.md)に基づく。
既存レビューの残り11件は全件適用・検証・commit・pushまで委任された。指摘ごとの再承認は求めない。
新レビューの結果の適用まで委任されたとは扱わず、保存・pushしてから今回のエスカレだけをプラグインへ適用し、製品repositoryへ戻って新指摘を一件ずつ議論する。

1. 今回のレビュー改善を保留エスカレ009へ保存する。既存001〜008は今回適用しない。
2. 残り11件を下の順で現物へ照合し、1指摘1コミットで適用・検証する。誤指摘なら根拠を記録し、変更済みと数えない。
3. 全体の参照・状態・残り指摘を確認し、feature-16をpushする。
4. 修正後のHEADを固定して、現行exhaustive-reviewと今回の明示指示を使いAstraでゼロベースの全体レビューを行う。
5. 指摘一覧自身がテーマの重要な不足を覆うか再評価し、観点を変えた探索を繰り返す。既存指摘を解消しても残る崩れを追加・再構成する。価値の薄い些末な候補だけなら水増しせず終了し、範囲と限界を残す。
6. 再レビューの指摘と優先順をdiscussionへ保存してcommit・pushする。
7. エスカレ009だけを正本プラグインで個別に適用し、元repositoryへ戻る。

## 再レビューのテーマ

小さな整理済み入力だけでなく、原依頼自体が約1000字で複数の人・目的・約束・制約・背景が混在する企画と、whyが約1000字の壮大な未来像を扱えるかを中心に見る。
発散して価値を育て、範囲と損失を選び、条件・候補・費用・成立・設計・再開・受渡しへ有機的に繋がるかを、初見で検討する。
重要な未知の欠陥が絶対に存在しない保証は出さない。未解消の懸念を明示し、何を確認して指摘集合がテーマを覆うと判断したかを記録する。
