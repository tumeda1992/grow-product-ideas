# CR-015の適用と検証 — 不足を候補ごとに分け部分的な再開を可能にする

## 現物の問題と修正

出どころと候補の不足を、識別子・公開で調べる性質・候補固有の事情へ分け、依存する比較だけを止める。how・専門・進行skillの取得と返りを接続した。

## 具体例の机上追跡

型番も店舗もない場合、対象商品を決めつけず必要な入力を残して保留する。
型番と適合根拠だけ届いた場合、同定・公開候補の調査は再開できる。特定店の在庫は未確認で、取得済みにしない。
店だけ届いた場合、その場所は同定できるが対象商品の適合・在庫の主張は進められない。既存の公開情報で対象商品の同定までできる根拠があればその範囲は使える。
両方届いた場合、対象を絞った比較へ戻る。試運転の接触・購入禁止は引き続き守り、在庫の根拠がなければ未確認を残す。

## 検証の意味と限界

本文と雛形を入口・判定・記録・後続への順に読み戻し、上の判断が手順から導けるかを照合した。
文書reviewでは初見の実行可能性、誤用の境界、旧版から削った要素、根拠と仮説、参照・現在表示を確認した。
この原因の恒久的な知識は修正本文へ収めたため、doc-enricherの独立した重複提案は行わない。
机上追跡を自律agentの実利用・外部仕様の実測とは扱わない。機械検査は隣のJSONへ記録する。
