# 修理会の次の一歩を考える合成依頼

以下は試運転のために親担当が作った架空の依頼。実際の利用者の発言や実在の団体の事実ではない。

私は、壊れた日用品を持ち寄る小さな修理会を二人で続けている。傘や布のかばん、木の小物のように、その場で直せることもあれば、部品を探したり、今日は手を出さないと判断したりするものもある。いま困っているのは、受付の記録と物の棚と、誰かの頭の中にある「次に何を確かめるか」が離れることだ。前回、持ち主へ確認したいことがあったのに担当が交代し、預かった物だけを見て別の人が続きを始めかけた。確認前なので止めたが、持ち主はもう直ったのかと来てしまった。受付票をきれいにするだけでなく、持って来た人も手を動かす人も、自分にできる次の一歩を分かって選べるようにしたい。

ただ、最短で修理を終える窓口にしたいのかというと、それだけではない。初めて道具を持った人が、経験者の「ここで止めた」という判断にも触れ、次は自分で試せるようになると嬉しい。直せなかった物を持ち帰る時も、勝手に失敗扱いにせず、何を確かめ、何は分からず、なぜ今は続けないのかを本人が説明できる感じが欲しい。何年も続いた先には、専門家へ預けて終わるだけでも、何でも自分で直すべきという場でもなく、人が互いの判断の違いから学べる場所にしたい。別紙の未来像も原入力として読んでほしいが、来月にその全部を約束したいわけではない。

最初の着想は、預かり品ごとに次の確認と試したことを短く残し、本人に見せる控えも作れる小さいwebの道具だ。修理写真を公開するSNSや、AIが修理の正解を断定する道具に決めたわけではない。受付を待つ人、道具を使う人、途中で帰る人が同じ画面を見たいとも限らない。紙で話す方が安心する人もいる。既にあるCSVと棚番号と返却案内を作る小さいscriptは使える。書式を変える必要があるなら、そのscriptや、前から預かっている品を扱う人まで困らないようにしたい。

二週間後から四回、同じ工房で土曜10〜12時に試す余地がある。運営は私と相棒の二人。週ごとに来る人は入れ替わり、初心者が次の回も来る保証はない。常連から追加の当番を取れると決まってもいない。持ち主が品物を預けることと、練習に使ってよいこと、判断の記録を他の参加者に見せてよいことは別だと思う。私は運用と自分の制作時間は決められるが、他人の言葉や物の扱いまで代わりには決められない。誰かに取り下げられた時、もう他人が見た記憶まで消せるとは言わないでほしい。

初回前に二人で使える準備は合計6時間、私のソフトウェア制作は16時間を目安にする。四回の試行に出せる現金は合計8,000円で、大きな立替を誰かに任せるつもりはない。大きな仕組みを全部作れなくてもよいが、意味のある作る部分を含めて進めてほしい。既存道具や人の仕事と組み合わせ、小さい版でも誰に何が届き、何がまだ届かないかを比較して選びたい。受付数だけ増えて、学べたかも、持ち主の判断が変わったかも分からないものにはしたくない。

今回は作り始められる設計まで詰める。実在の団体・参加者への連絡、外部への送信、本番公開、購入や契約はしない。提供したローカルな写しと合成データで必要な技術確認を動かすことはできる。原依頼に無い回答が必要なら、合成利用者役の親担当へ具体的な問いを返してほしい。都合の良い許諾・人数・実績を作って先へ進まないでほしい。
