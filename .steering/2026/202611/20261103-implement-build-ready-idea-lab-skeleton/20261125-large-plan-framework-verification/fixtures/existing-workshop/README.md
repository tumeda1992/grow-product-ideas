# 既存資産の合成の写し

CSVのcase_idは継続して使う受付番号、owner_refは別紙の持ち主番号。棚の位置と修理の進捗は別の意味を持つ。return_note.pyは受付番号から返却時の控えを印字する既存の利用箇所である。実在の人の連絡先はこの写しに無い。

現在のCSVは運営二人のPCで読み、品物の付箋にも受付番号を記す。工房の来場者や別の会へCSVそのものを見せてよいという許諾は無い。今回のローカルな技術確認で写しを変更し、既存scriptとの接続を試すことはできる。元のfixtureは保存し、実験は写しで行う。

これは手順・コードの存在を示す設定。修理時間、支援の速さ、来場者の反応、ソフトの効果を測定したデータではない。
