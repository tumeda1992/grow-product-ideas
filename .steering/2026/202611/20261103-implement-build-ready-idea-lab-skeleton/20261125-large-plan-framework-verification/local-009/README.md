## 静的対照

以下は本文に照らした机上の対照であり、別案件の再受領や実際の観測ではない。

- 別領域: 配送窓口の一人が決まった時間に温度記録をする一方、時刻を選べない荷物破損の受付を費用内に含む。記録中に受付が発生すれば、危険物の隔離を先に行い、欠けた記録対象・時間と代替の温度記録の同等性を選定と測りに返す。費用内だから両立したとは言えない。
- 真の非競合: 固定観測と随時対応を、各々その場所と機器を使える別の担当が引き受け、対象となる一件について担当・機器・場所が重ならず、終了までの時間も確認済みなら、損失を作り出さず根拠を残す。単に別時刻に空きがある、又は担当追加を仮定しただけではこの対照にならない。
- 損失を残す部分案は、対象と価値の欠落・負担を明示し本人が理解して選べば比較に残る。代替案は必要な対象と機会を保持する根拠および追加仕事が必要である。どちらも今回の写しでは未採用。
