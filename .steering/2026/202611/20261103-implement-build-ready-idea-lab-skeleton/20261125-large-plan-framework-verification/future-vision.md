# 修理会で遠い先に得たいものの合成原文

これは同じ架空の依頼者の未来像として親担当が構成した入力。今回の版の機能要件や、実在の参加者が合意した成果ではない。

遠い先の景色をもう少し話すと、修理に詳しい人が答えを教え、他の人が順番を待つだけの関係から、少しずつ離れられたらと思っている。経験のある人も、初めて触る素材では迷う。その迷いの中で、何を見て次を試すか、どこから先は本人に選んでもらうか、今日は直さないことにどう納得するかを、一緒に考えられたら嬉しい。失敗談を公開する競争や、説明の上手い人だけが残る集まりにはしたくない。

たとえば持ち主が「このかばんは形が変わっても使えればいい」と話した時、きれいに直すことだけを想像していた人が別の直し方を考えられることがある。逆に思い出の跡を残したい人もいる。どちらが上かを道具が決めるのではなく、違いを知って選べるようになってほしい。直った件数や壊れた状態の写真だけを並べても、そういう変化があったのかは分からない。本人が何を選べるようになったかを、無理に答えさせず聞ける余地が欲しい。

常連の一人が休んでも、以前の判断を正解集のように守るのでなく、「これはどんな条件で試した話だったか」を見て続きを考えられるようになりたい。ただし、記録を残せばその人を代わりにできるとも思っていない。手触りや、言いにくくて口にしなかった事情もある。その時の本人の選択を後の人が知れることと、本人のいないところで別の使い方を許されたことは、混ざらないでいてほしい。

手を動かさず見ていた子が、後で家の小さな物について「ここは自分で確かめたい」と言えるのも価値だと思う。本人が修理を上達させたいのか、今日は家族の品を受け取りたいだけなのか、参加の仕方は違う。楽しむために作業の途中を見たい人に、最短の受取り経路を押し付けず、早く受け取って帰りたい人に、学びの話を聞くことを求めないようにしたい。続けて来ることを成果の条件にすると、その日だけ来た人の変化を取りこぼす気もしている。

将来、別の小さな会が同じような工夫を使うことになっても、品物の一覧を移せば場所が育つとは限らない。自分たちが引き受けられる範囲、持ち主との約束、誰が何を判断したかが土地や人で違うからだ。初めから共通の会員制度を作ったり、全部の修理履歴を集める必要があるかは分からない。人が少し楽になることと、人が相手に関われる余地が増えることの両方を、減った手間だけの数字に押し込めず考えたい。

来月の四回でここまで全部変わるとは期待していない。今の着想から別の道へ進むこともあると思う。それでも、小さい版を使った本人が何か一つ選びやすくなり、こちらも何が起き、何はまだ分からず、次に何を試すかを自分たちで選べたら、その先につながる。逆にソフトだけ動き、運営の二人が説明と記録に追われて誰の変化も見られなかったら、どうしてそうなったかから考え直したい。最初から立派な成果の言葉を作って、その言葉へ体験を合わせることはしたくない。
