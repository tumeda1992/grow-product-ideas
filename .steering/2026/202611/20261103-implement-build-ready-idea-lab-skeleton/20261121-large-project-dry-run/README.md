四processとも終了値0。予約・HTTP・保存モデル等の有限検査であり、本製品の全実装や実物の回収を検証した結果ではない。

- [親の実行記録](parent-verification/execution.json): 対象hash、実行出力と終了値、案件19 Markdown・178リンクの検査、再実行中の案件不変。

親のrunner参照検査は、最初に起動位置と異なる基準の相対pathを渡して拒否された。
絶対pathで再実行して成立した。文書を直して検査を通したものではない。

## この実行で確かめていないこと

本製品の全API・認証・実browser、施設機器と紙・印刷物、実際の所要時間と来館者への価値は未検査。
案件は実装後の受入れと停止・選び直す境界を持つ設計として採用したもので、完成・稼働の報告ではない。
スキルの取得元はtumeda-dev 9.1.1の固定sourceであり、nativeな自動発見・自動reloadの試験でもない。

案件を一巡できたことから、レール全体の十分性や未実行の分岐の成功を補わない。
