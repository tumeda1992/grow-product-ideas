# DRR-009　費用に含めた取下げ一件でも、約束した観察当番と回収当番が重なる

- 優先度　P2
- 固定版　`80b3836aae18bdc4e9f2daf9db6fa2eb0e359c34`。[対象一覧](../evidence/scope-sha256.json)
- 対象・行　[観察と費用を含めた提案87–88、採否116–118行](../../product-plans/20261121-reframe-local-collections/how-to-solve/discussion.md)、[当日の役割表15–25、欠測29行](../../product-plans/20261121-reframe-local-collections/how-to-build/operations-and-acceptance.md)、[観察を含めた価値の測り](../../product-plans/20261121-reframe-local-collections/README.md)
- 観点　有限な部分版の価値・費用・安全な運用の両立。DRR-007の中断復旧とは独立。
- 由来　当日の運用と、LR-004で保持することにした観測が重なる時の実行不足。採否未判断、未着手。

## 問題と根拠

右室の観察は10:45〜11:00、Bが一人で行い、Aは入口を担当する。土曜10:50に10:20から左室に出ている17の問いが本人の控えで取り下げられたとする。表はAに端末の覆い、Bに該当紙すべての回収とAとの照合を割り当てる。Bは右室を観察しながら左室の札を回収できない。計85人分には二件の取下げが含まれており、これは想定外の物量でない。四つの定時更新を観察枠とずらしても、来館者が選ぶ申出の時刻はずれない。申出が同じ一件でも10:35ならこの衝突はない。

安全に閉じることと観察できなかった時間を欠測にすることは、既に指示されている。問題は、費用比較で通常の有限例に二件を入れ、観察の二つの枠を保てる構成として選んだのに、その例の中でも回収と観察を同時には提供できない条件を、その版の損失として本人へ返していないこと。現物を読んだ人が直ちに安全停止を選べる点まで欠陥とはしない。

## 改善案と振る舞いへの影響

相手が時刻を選ぶ作業と固定の当番が人・場所を取り合う時だけ、二人がどこにいて何を優先するかを時間順に通す。すぐに覆い、回収を優先するため観察を短くする案なら、失われた観察枠、欠測の残し方、選定・whyの再評価を示す。代わりの観察枠で同じ資料・機会を見られる場合は、その時刻・人・増減を示し、元の採否に効く差を本人へ返す。追加人員や観察の省略を暗黙に引き受けない。押し寄せる全件へのサービス水準は求めない。

## 検証方法・証拠

同じ二人・一件・左室の紙という設定で10:35と10:50を静的に比較した。修正後の設計から、本人の言葉の使用停止と回収、欠ける観察、その版を選んだ費用と負担を順に説明できること。実施設の観察速度や回収時間は未測定。
