- 状態　再検討で撤回。有効な指摘と適用候補から除外。
- 固定版　`80b3836aae18bdc4e9f2daf9db6fa2eb0e359c34`
- 対象　[価値の測りと選び直す条件](../../product-plans/20261121-reframe-local-collections/README.md)、[月曜の判断の実応答203行](../../product-plans/20261121-reframe-local-collections/why-to-build/discussion.md)、[運用と保存する集計27–32行](../../product-plans/20261121-reframe-local-collections/how-to-build/operations-and-acceptance.md)

同じ来館者の問いを入口で読んだ時と現物横の紙で読んだ時は、資料別の見直しと任意回答の分類が同じになり得る。F0後の集計からこの媒体の差を推定できない。一方、合成利用者が採用したのは、見直しの具体例・負担・未観測を比べて継続、受渡しや問いの見直し、終了を選び、不足なら判断を保留することである。KとRの媒体別効果を識別することも、次に採る版まで必ず決めることも求めていない。入口端末と紙の比較に資源を賭ける場面が後から生じた時は新たな判断になる。既に保留にできる契約に、匿名の追加質問を必須とする理由は得られなかった。
