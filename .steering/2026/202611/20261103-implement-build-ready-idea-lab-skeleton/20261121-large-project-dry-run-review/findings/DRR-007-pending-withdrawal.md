## 問題と根拠

Q17とQ18がともにactive・掲示済み。17の取下げの申出を確認してcoveredにした直後、紙を回収する前に停止し引き継ぐ。同じ時刻に18の取下げだった場合も、記載された保存結果は同じ。runtimeは日・mode・epoch、各問いと紙はactive/placedのまま。どの申出を受けたか、どの紙の回収を続けるかを保持する途中状態・対象は無い。両者の原札が在ることも、どちらの作者が今撤回したかを示さない。合成モデルは次の行で前もって知っているQ17-P1を指定している。不明なら休止を保つのは安全だが、どれを除いて再開してよいかは解決しない。取下げを確定した上で物理的回収を続ける設計も、今のwithdrawnの意味を変えずには選べない。

## 改善案

取下げを受けた時点、該当IDと出力版・残る紙・状態、回収終了を分ける。受付を確定した後は、新しい提供や別の入替えがその対象を再公開できず、後任は永続した最小の記録又は管理下の対応票から仕事を続けられるようにする。受付より前の停止で結果不明なら照合し、既に受理した申出の再申告や職員の記憶へ依存させない。F0で途中票も回収し、解けないものは権限範囲で残件へ。

## 振る舞いへの影響
