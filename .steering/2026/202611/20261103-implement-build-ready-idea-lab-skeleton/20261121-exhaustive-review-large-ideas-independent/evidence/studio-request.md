# 練習室を一緒に使う人を探す企画

## 検査入力 A

以下は書き下ろしの架空の依頼原文。段落末までを受入れ時の一つの入力とする。

> 市民音楽サークルで、練習室の空きと、一緒に音を出したい人を結ぶ小さなウェブサービスを作りたいです。今は部屋を押さえた人がグループのメッセージに「水曜七時、あと一人」と書き、行ける人が返しています。先月は帰りの電車で募集を見つけたのに、行ってみたら別の人が先に返事をしていて、結局ロビーで聴いて帰りました。毎回こうなっているわけではなく、先にいる人に誘われて一曲だけ合わせられた日もあります。すぐ返せる人だけが得をする仕組みも、たまたま居合わせて遊べる良さを無くす仕組みも、どちらも寂しいです。
>
> 私が大事にしたいのは、空室を埋めることだけではありません。一人で来たばかりの人にも、誰と何をしてみたいかを自分で選んで、一度だけでも一緒に試せる機会を作りたい。前からいる二人には、途中で新しい人を入れるかどうか、自分たちで決めてもらいたいです。半年後に「あの日の二人で、また同じ曲をやろう」と誘い直せたらもっと嬉しい。誰がどの夜に来るかをサークル全員に見せたり、来なくなった人を追いかけたりして実現する気はありません。
>
> 画面には空きのカレンダーと楽器のアイコン、参加ボタンがあるのかなと思っています。でも、入口で今日合わせてみたい短いフレーズを交換するだけでも、人が動くようなら面白いです。枠を持つ人が部屋の予約者で、会館が持っている予約台帳は今までどおりです。ここから会館の予約を変えることはできません。当日、扉の前で部屋が変わったと分かった時や、返事をした後に仕事が延びて行けなくなった時に、誰が誰を待っているか分からなくなるのは避けたいです。
>
> 来月の公開練習の案内が出るまでに、最初にどう始めるかを決めたいです。私は週末なら準備できます。受付の係は鍵を渡す本業があり、いつ来るか分からない人を毎晩探す担当にはできません。職場では私用の携帯を開けない仲間もいます。家から参加したい日を先に出す人と、帰り道になって初めて寄れると分かる人とで、同じ仕組みが親切とは限らないでしょう。自作の経験はありますが、作ること自体を優先したいわけではありません。紙と今の連絡で同じことができれば、そのやり方も見たいです。
>
> 会費は今のままで、追加の支払は月に三千円まで。音源を録って流す案は、録られたくない人が一緒に来られることを守れるなら考えたいです。誰かが参加を押しただけで一緒に演奏した数を増やさず、練習に加わらずに聴いて帰る選択も大切にしてください。

## 検査入力 B

「どの町へ引っ越しても、昔の海辺の匂いや街角の音を持ち寄り、見知らぬ人の記憶を自分の散歩として歩ける未来を作りたい。一人が別の人の場所を一人で辿れる良さと、作者と聴き手がお互いに道を作り替える良さがある。どちらの未来へ半年を使うか、実際の一週間の往復で相手が何を変えたくなるかを見て決めたい。どちらか一方を今選ぶことは望まない。」

これも構成例。実在の記憶、記録、許諾、利用者の意思を取得していない。Aは日常の行いを持つ案件、Bは類似の実績がなく目標そのものを選ぶ案件として使う。
