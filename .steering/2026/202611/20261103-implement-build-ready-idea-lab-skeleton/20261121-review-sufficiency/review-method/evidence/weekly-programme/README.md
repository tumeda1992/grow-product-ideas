# 週の教室案内

地域の会報に年を通じて載せる教室の案内を、参加する人がそのまま使えるか検討するための小さな構成例。各教室は毎週、会場の同じ曜日・同じ開講時刻に始まる。会場は各地にある。参加者は会報で当週の開講日時を読む。会場からは初回の日時が地域名付きで入る。入力は平日の午前で、休講や変更のない期間を扱う。

編集者が同じ回を再登録しても案内は一つにする。当週分の生成中は一人の編集者が同じ台帳を使う。正しい教室と回を一つに特定する入力は受付側で確認済み。保存・配信は別の処理であり、今回検討するのは受領してから当週の案内を台帳へ返すまで。
