# 大きな企画を作り始める設計まで運べるか

**既存12件を記載どおり直すだけでは、まだ任せ切れない。** 新しい字幕の表示・消去・復帰は全て正しく、正しい既存プロジェクトへ設計を渡せても、共有する進行表を振り直した結果、従来の音響係は別の場面で鐘を鳴らす。何に依存して新しい仕事が動くかは追えても、変更する共有物に依存している別の仕事を見つける責任が抜けている。[SR-001　既存の読み手を含めて選ぶ](findings/SR-001-existing-consumers.md)

価値を広げ、比較し、具体に落とす方法は既にある。劇場では「全ての台詞を読める」と「他の観客と同じ時に笑える」を分け、紙・会場投影・個人端末を比べ、選んだ版で行17の消去から19への復帰、古い応答、初日の移行まで辿れた。未経験の未来像でも、二つの手が今触れ合うことと、前の人が去った後に形を継ぐことを、本人が選べる別の体験まで育てられた。これは構成例による設計の追跡である。[劇場](evidence/theatre.md)・[二つの海辺](evidence/tide.md)
