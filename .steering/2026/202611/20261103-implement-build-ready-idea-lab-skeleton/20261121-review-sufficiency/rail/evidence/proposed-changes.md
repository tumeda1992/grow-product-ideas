# 旧12件に仮定した修正と、今回の反例への効き方

旧16件の反映後の現物を起点にした。LR-001は[応答待ちの提案](../../../20261121-exhaustive-review-large-ideas/evidence/LR-001-proposal.patch)にある五ファイル、他は各個票の改善案と検証条件の範囲に限った。修正の採否は全て未判断である。[旧LRの索引](../../../20261121-exhaustive-review-large-ideas/README.md)・[旧IRの索引](../../../20261121-exhaustive-review-large-ideas-independent/README.md)

| 指摘の責務 | この責務で判断が変わる例 | そこから引き受けたと仮定しないもの |
| --- | --- | --- |
| LR-001　決定・引受け・許諾の主体と期間 | 演者の署名は自分の抜粋の初演用だけ。別会場の当番は未確約。企画者だけでも最初の会場案は選べる | 音響係が署名していないことと、その人のノートが字幕の書込みで壊れることの発見は別 |
| LR-003　本番の線を校正する限定版 | 潮の模型の同時感が成立する遅延限界は未知。明示した交代合図で成立する試行の条件だけ先に定められる。合図自体も働かない装置を成立させない | 長期の目標を自動で選ばない。物理装置の成立を推測しない |
| LR-004　選定後も観測の根拠と担当を保つ | 字幕閲覧数は同じでも、観客が自ら舞台へ戻った場合と復帰不能の場合がある。観察担当を削れば、代わる合図・聞けた範囲と未判定を取り直す | 匿名の観客の好みを全員分取得したこと、設計の受入れが実利用効果の実測になったこと |
| LR-005　初版が閉じる将来の道 | 今回の匿名の地形を即時破棄する案は、離席後の別人がそこへ重ねる道を閉じる。承諾がある断面だけを残す場合と、現在の手間を比べる | 将来を残す方を必ず選ぶこと、実在しない再許諾 |
| LR-006　支払う時点と立替主体 | 仮に投影機の使用料が差引2千円でも、初日に8千円を払い6千円が後払いで戻るなら、手持ち4千円では開始できない。既存機なら前払不要 | 工数から初回提供日まで自動計算する能力。期限の別仮説は[判断記録](../coverage.md)で照合 |
| LR-007　新しく採る非開発運用の立上げ・終わり | 紙ガイドへ切り替える初日、配布済みの旧版の回収又は差分掲示を誰が行い、持参者へどう伝えるか。完全な現状維持には不要 | ソフトの初回設計全般、選ばなかった版のための移行作業 |
| LR-008　既存の出口と受領済みの訂正 | 旧字幕設計は採用済みでも、次の公演で利用許可が失効したと既に届いているなら、元の採否と今回渡せる範囲を分ける | 対象版も外部事実も据え置いたまま、今回の選択自体が既存資料の意味を変える場合 |
| LR-009　証拠の保存と二次提供の許容範囲 | 稽古中にのみ読める台本を内部記録からも再転記しない。架空の三行と許された要点で、古い行が遅れて届く受入れを再現できるかを読む | 読めない本番原文で実機検証を完了した扱い、共有物と別の利用者との関連の自動発見 |
| LR-010　基準版の自己完結と現在の採否の入口 | 持出し時の企画はそのまま読み切れ、後続の新しい決定場所は受付後に実在する担当記録へ繋ぐ。受付前には未来のリンクを作らない | 書き換える共有物の妥当性。リンクが存在しても音響ノートは別の場面を指せる |
| LR-011　途中での明示撤回 | 二会場とも上演そのものを取り止める権限のある人が終了を表明したら、未合意の版を選ばず終了する。片方だけ中止なら残る会場を再評価する | 単に返答待ちである企画を取り止めとすること |
| IR-001　組み合わせた場合の便益を有力な対案と再比較 | 同じ観客への復帰機会が二会場で重なる場合と、別の観客へ初めて届く場合を区別する。一人の役割が複数の行いを変えて初めて変わる場合も同じ単位で見る | どちらの会場の字幕受益にも入らない旧音響ノートを、書換え対象の他の読み手として探索すること |
| IR-002　受け入れた版を実装する先の識別 | 既存進行表アプリの拡張ならその保守場所・版と流用した対象を、新作なら新しい実装先を引き渡す。製品版が動けば選定が依った差を再照合する | 同一版のまま共用表の書込先を変えた時、新案の成立が依らない既存の読み手まで調査済みとすること |

LR-002は異なる目的のラフをwhyから取り寄せられるため撤回済み。IR-003は二つの未来を体験する短期目的を本人が選べるため撤回済み。潮の模型でどちらも現行の経路を組めた。両者は12件に含めない。[未来像と選定の分岐](tide.md)

**集合に対する反例。** 袖・演者から必要な許諾と工数が揃い、出演者以外に台本を渡さず、新しい字幕と初回受入れは成功し、正しい既存repoの版へ持ち出せると置く。新たな便益の重複や将来の移行もない。共用表の番号を振り直しただけで旧ノートの音響合図が別の場面を指す。上記のどの責務も飛ばしていないのに、実装者は既存の公演を続けるため構成と費用を選び直さなければならない。[SR-001の独立性と正常対照](../findings/SR-001-existing-consumers.md)
