# SR-001: 変更する共有物の既存の使い手を選定と受入れへ通す

## 修正と根拠

新しい一巡の外にいる既存利用者を、変更する資産の利用箇所から調べる。互換維持・合意した移行・分離を候補の得失と既存業務の受入れへ結ぶ。

対象: `what-defines-a-product/how-to-solve.md`, `what-defines-a-product/how-to-build.md`, `.agents/skills/functional-structure-design/SKILL.md`, `.agents/skills/grow-product-idea/templates/canonical.md`。

## 具体例と判定

字幕が同じ順で出ても、番号振直しで旧ノート18が消去を指す案はそのまま通さない。元18を鐘に保つ分離案は通る。料金を指示数で計算する別利用者がいれば番号固定だけで終えない。読み取り専用や完全分離された新表には全既存業務の総点検を課さない。

## 検証の意味

該当する現行手順から上の判断が導けること、独立した正常例を止めないこと、前の判断との接続を読み戻した。document-reviewで実行できる具体性、例外、原文・仮定・実測の区別と参照を照合した。元の判断へ必要な知識は本文へ収めたため、doc-enricherの重複する提案はない。実利用・効果やドライランの成功をここで先取りしない。
