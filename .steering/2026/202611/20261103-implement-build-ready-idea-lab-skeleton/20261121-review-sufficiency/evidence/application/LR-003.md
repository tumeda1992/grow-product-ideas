# LR-003: 本番条件の閉じ前に限定校正の材料を取得する

## 修正と根拠

新しい層状態は設けず、whatが所有する独立の校正経路を定義。本番の未知を開いたまま、既知条件で本当の体験を届ける限定試行の設計と実施を専門材料として依頼できる。

対象: `what-defines-a-product/what-must-hold.md`, `what-defines-a-product/README.md`, `.agents/skills/grow-product-idea/SKILL.md`。

## 具体例と判定

本番値既知は通常の閉じへ。本番だけ未知なら明示の合図で成立する限定会を設計・承認し結果を本番条件へ戻す。限定会にも未知の値や許されない追跡が不可欠ならその方法は止め、別観測か保留。校正の受入れを本番条件の確定・製品合格にしない。

## 検証の意味

該当する現行手順から上の判断が導けること、独立した正常例を止めないこと、前の判断との接続を読み戻した。document-reviewで実行できる具体性、例外、原文・仮定・実測の区別と参照を照合した。元の判断へ必要な知識は本文へ収めたため、doc-enricherの重複する提案はない。実利用・効果やドライランの成功をここで先取りしない。
