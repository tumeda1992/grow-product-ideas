# LR-008: 出口の返答前に既知の訂正と有効期限を照合する

## 修正と根拠

状況照会でも現在の根拠を照合し、旧採否を維持したまま有効範囲と失効を表示する。再開の権限や新しい採否は補わない。

対象: `.agents/skills/grow-product-idea/SKILL.md`, `what-defines-a-product/README.md`。

## 具体例と判定

変更なしと無関係な訂正は以前の結果を維持。期限切れ又は成立を崩す訂正は旧採用と今の不足を分ける。保留中の別候補の材料だけ変わった時は影響先だけを表示し、自動再開しない。持出し済みの現在版は後続へ渡す。

## 検証の意味

該当する現行手順から上の判断が導けること、独立した正常例を止めないこと、前の判断との接続を読み戻した。document-reviewで実行できる具体性、例外、原文・仮定・実測の区別と参照を照合した。元の判断へ必要な知識は本文へ収めたため、doc-enricherの重複する提案はない。実利用・効果やドライランの成功をここで先取りしない。
