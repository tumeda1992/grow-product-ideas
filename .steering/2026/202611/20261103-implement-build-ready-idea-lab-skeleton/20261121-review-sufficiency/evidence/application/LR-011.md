# LR-011: 明示撤回を未閉じのまま取り止めとして記録する

## 修正と根拠

非開発版の採用や保留とは独立した取り止めを設け、権限のある明示撤回を未閉じの層から受ける。

対象: `README.md`, `what-defines-a-product/README.md`, `.agents/skills/grow-product-idea/SKILL.md`, `.agents/skills/grow-product-idea/templates/canonical.md`, `product-plans/README.md`。

## 具体例と判定

空きが不明なら不足又は保留。会場消滅でも別日を望むなら検討継続。全案を明示撤回すれば復活条件なしに取り止め。片方の会場のみ撤回なら残る判断へ。require-buildと過去の採否は書き換えない。

## 検証の意味

該当する現行手順から上の判断が導けること、独立した正常例を止めないこと、前の判断との接続を読み戻した。document-reviewで実行できる具体性、例外、原文・仮定・実測の区別と参照を照合した。元の判断へ必要な知識は本文へ収めたため、doc-enricherの重複する提案はない。実利用・効果やドライランの成功をここで先取りしない。
