# 少し大きい企画を入口から実装へ渡せるか

**前回16件を反映した現行レールは、長い原文から目標候補を育て、紙と自作の別解を具体化できる。一方、少し大きい企画をそのまま任せられる水準には、なお10件の不足がある。** 合意した人に別の人の負担を引き受ける権限があるか、本番の条件が未知でも価値のある試行を始められるか、選んだ版で価値の測りと支払いが実際に成立するかが、企画の扱いを変える。全件レビュー提案であり、製品への採否・適用は未着手。

対象はfeature-16、`fea97767d741b2a174261a240996d4f11d8c2361`。原文に人・目的・約束・手段・制約が混在する服の直し会（960字）と、経験のない未来への願いを語る共同物語（1019字）の二つを構成し、全四層・専門・状態・引き渡しを机上で追った。例えば後日7,000円返る9,000円の会場は、純額2,000円でも初日の立替枠6,000円では始められない。紙案の受付も、旧台帳が残る初日に誰へ現物を渡すかまで決まらなければ導入できない。[構成した依頼](evidence/long-inputs.md)・[場面と専門の返り](evidence/walkthrough.md)

## 議論する優先順

まず誰が約束を変えられるかと何を持ち出せるかを確かめ、価値を探索する実験、その結果を受ける通常版、導入・再開・持出しへ進む。次の順は議論の推奨順。各指摘の採否は個別に判断できる。

| 指摘 | 重要度 | 独立して判断する問題 | 修正後に効く対照 |
| --- | --- | --- | --- |
| [LR-001](findings/LR-001-decision-authority.md) | P1 | 主催者の採否だけで、別の班の当番や提供者の許諾を成立扱いにできる | 主催者の当番／別班の当番／提供者の拒否 |
| [LR-009](findings/LR-009-transferable-evidence.md) | P1 | 企画内だけで読める原稿を受け取ると、原文保存と実装担当への一式コピーを両立できない | 企画者だけが読める原稿／後続へ渡せる要点 |
| [LR-003](findings/LR-003-experiment-before-threshold.md) | P1 | 試行でしか分からない本番の最低線が、条件を決める層で実験版への道を塞ぐ | 本番の猶予は未知／限定会では明示の合図で成立 |
| [LR-004](findings/LR-004-observable-value.md) | P1 | 選んだ版で観測の担い手が消えても、whyの価値をいつ何で測るかが更新されない | 二投稿は同一／参加者や途中退出、観測する当番が異なる |
| [LR-006](findings/LR-006-cash-timing.md) | P1 | 期間の総費用が予算内でも、初日に立て替える人が支払えない | 純支出／支払時点の最大立替額 |
| [LR-007](findings/LR-007-nonbuild-transition.md) | P1 | 「作らない」で業務を変えると、稼働初日の旧案件を引き継ぐ担当と手順が抜ける | 通常日の紙受付／既存予約を引き継ぐ初日 |
| [LR-008](findings/LR-008-new-evidence-at-exit.md) | P1 | 保留・完了案件で根拠が訂正された時、古い出口を現在も有効と返せる | 過去には採用／現在は根拠が失効 |
| [LR-005](findings/LR-005-future-options.md) | P2 | 同じ初版から後で移れる道と、現在の選択で閉じる道を並べずに段階案を選べる | 初夜の価値は同じ／二度目の公開に移れる範囲が違う |
| [LR-010](findings/LR-010-downstream-reference-boundary.md) | P2 | 持出し先の現在の採否を写しから指すと、案件内リンクの規約と検査が食い違う | 持出し前の閉じた写し／受付済みの後続採否への案内 |
| [LR-011](findings/LR-011-withdrawn-project.md) | P2 | 開催が消滅して企画者が撤回しても、未閉じの案件を取り止めとして確定する出口がない | 一時の保留／全案を明示撤回した終了 |

## 十分性の判断と索引

10件を全て解消したと仮定して、最初の書き手がいない場、入退室の偏り、紙への切替、支払いと返金の時差、訂正の到着順、匿名資料の持出しなどを再検査した。現行で扱える経路と各指摘の修正・検証条件に帰着し、テーマに効く独立した追加原因を見いだせなかった。採用後の結果や実利用は未検証。[各周回・反例・停止根拠・限界](coverage.md)

「whyが決まるまで紙ラフで体験を比べられない」という仮説は、別々の仮の終点で出した二件の専門依頼をwhyへ戻すと現行で扱えたため撤回した。固定IDを残し、有効10件の集計から外している。[LR-002の撤回根拠](findings/LR-002-experience-before-goal.md)
