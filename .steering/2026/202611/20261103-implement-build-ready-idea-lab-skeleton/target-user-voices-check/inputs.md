# 検査の入力と、提供記録の模型

F1–F6はこの局所確認のためassistantが作った架空の提供記録である。実際の家族の語り・行動・価値・効果の証拠ではない。専門の整理に入力と違う意味が紛れないかを確かめる。

## 依頼と前提

目的は、家族の学校への対応で、用件が見えることと、自分で始動し完了まで引き受けることにどんな違いがあるかを探ること。最初から通知や役割移譲を目標として採用していない。
A・Bは同じ家の大人、Cは子どもという検査用の役である。紙の受け口と共有の予定があり、どちらもA・Bが使えるという設定だけを与える。具体の製品の機能・料金は与えない。

### F1

W1月曜、Aの記録: 「紙の受け口から同意書を読み、金曜に回収だと分かった。Bに『これをお願い』とメッセージを送った。」

### F2

W1水曜、Bの記録: 「Aのメッセージを見て、紙を読んだ。木曜の夜に署名する予定を自分で入れた。」

### F3

W1金曜、Aの記録: 「昨日一度、Bに署名したか聞いた。今朝、回収されたと確認できてほっとした。自分は始まりと最後の確認を気にしていた。」

### F4

W2月曜、Bの記録: 「19:30に自分で受け口を見て、Cに参加したいか聞いた。紙の期限と二人の予定から、今回の対応を自分が引き受けると決めた。」

### F5

W2金曜、Aの記録: 「今週はお願いも催促もせず、Bが対応した。Cが何を楽しみにしているか話せて嬉しかった。」

### F6

W3月曜、Aの記録: 「Bが四日不在なので、自分で受け口を見た。誰がどこまで対応できるかまだ分からず、また自分が全部覚えることになりそうと感じた。」

## 依頼側が読み戻す問い

- 価値の仮説: 用件が見える・期限に間に合うこと以外に、何が変わる意味として読めるか。
- 条件の吟味: 二人が読め、署名・回収が済めば、Aが全件の始動と追跡を抱えないことまで言えるか。
- 候補の吟味: 受け口の確認から本人が引き受ける道を候補へ残す時、何の行い・制約・未確認を渡す必要があるか。

この検査の中でも、新しい目標や条件・候補を利用者が採用したことにはしない。
