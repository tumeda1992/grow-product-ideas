# 他者の体験の探索・整理の局所確認

論点78で作成した本文を、同じassistantが依頼側と専門の役で順に適用したBの局所確認である。別agentの独立review、新しい案件への一式適用C、実際の家族の調査ではない。

- [入力と架空の提供記録](inputs.md): 当時の行い・評価・不在を含む検査用の架空入力。実際の利用者の声に数えない。
- [提供記録の整理](provided-experience.md): 一回と継続、始動と読取りを分け、価値・条件・候補へ返す材料。
- [旧資料の読み直し](existing-source-audit.md): 解説・規則・機能から親の行いを推定した古い材料への返り。旧案件の採否は変更しない。
- [公開投稿の材料](public-experience.md): HTTPで取得したNextcloud Tasksの元投稿を、使用報告・希望・参照経験・見込みへ分けた実物。
- [公開資料の取得の観測](public-source-observations.json): 実際に届いた範囲と届かなかった範囲。全threadや現行機能の検証ではない。
- [依頼側へ渡した結果](consumer-results.md): 既存の価値・条件・候補の方法で読み戻し、使える範囲と不足を確認した記録。

新しい専門の登録と、各層からの依頼・受領の案内の同期はまだ行っていない。実物の本文と返りを吟味した後の変更集合で扱う。
