# 議論記録（検査用の当人役による判断）

全ての当人役はassistantが演じる。実際の利用者の応答・採否ではない。

## 論点1: 自動反映の根拠の不足をどの判断へ返すか

**ステータス:** 決定

**種別:** 検査用当人役の判断

### イテレーション0（論点1）: 手動へ黙って変えずに、自動版の不足を返すか

#### 提案0（論点1）

自動版を閉じず、howへ対象APIと利用条件の特定を返し、T1へ照合・再送・変更と見つからない時の意味を問う。全件の人手へ変える場合は別の版として負担と損失を選び直す。

#### 検討記録（論点1・イテレーション0）

起点は[層の記録](README.md)。固定入力と実際に返った材料から判断する。

[内部検討記録](internal-records/discussion.md.topic-1.md#iteration-0)

正常の作成と取得だけではIDを失う停止を支えない。情報に実施中を持たせるだけでもW1/W2は区別できない。手動照合なら元の選定の決め手が変わるので、自動版の成功へ数えられない。

#### 提案0へのフィードバック（論点1）

**結果:** 検査用当人役の判断。実利用者の応答ではない。

> 検査用当人役（assistant）: 自動版は閉じない。対象と必要な性質を先に確かめ、全件の手動照合に変えるならhowで選び直す。

### 決定（論点1）

どう作るか層を閉じない。howの対象と利用条件の選定を確かめ直し、その対象のT1で必要な性質を確認する。技術の不可能や恒久的な中止とはしない。
