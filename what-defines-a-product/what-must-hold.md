# 何が成り立てばよいか（what-must-hold）

この層は、「何が成り立てば、痛みが解けたと言えるか」を決める。決めるものは、満たすべき条件の一つである。

条件は、次の[どう解くか](how-to-solve.md)層が、解き方の選択肢を判定する物差しになる。物差しは、競う選択肢を見る前に固める。選択肢を見た後で決めると、作りたい人は、作らない道が満たせない条件を足したくなる。着想を持つ人は、着想が満たせない条件を外したくなる。どちらも、作らない判断を曲げる。そのため、この層は、どう解くか層と分けて先に閉じる。

## この層の閉じ

閉じで、利用者は次を確かめ、論点ごとに応答する。

- アウトカムをどの言い分に割り、言い分ごとにどの条件を導いたか
- 利用者の手の外にあるもの（相手の都合、空き枠、体調等）を、条件で寄せるか、届かないものとして受け入れるか
- 程度のある条件の、最低の線

条件を導く中で、アウトカムの言い方が強すぎる、または近づいたかの測りが無いと分かった時は、なぜ作るか層へ返す。

## 満たすべき条件

### 何を決めるか

アウトカム（なぜ作るか層から受け取る、痛みが解けた時の暮らしの姿）が成り立つために、どの手段で解いても満たさなければならない条件である。手段の言葉（通知、一覧、アプリ、LINE、カレンダー等）を含まない。

正本には、条件ごとに一文と確かめ方を書く。一文は、誰が・いつ・何が成り立つか・どこまで、で組む。要るか、どこまでかが事実や利用者の考えに依って決まっていない条件には、何で決まるかを添える。

後ろでは、次のように使われる。

- どう解くか層が、選択肢ごとに、崩れやすい時点で確かめ方を問い、答えられるかで満たす／満たさないを決める
- 作った後に、作ったもの（と運用）が痛みを解いたかを、同じ確かめ方で見る

### 決め方

#### 1. アウトカムの言い分を割り、言い分ごとに要ることを問う

アウトカムは一文の言い切りであり、その中に、成り立っていなければならない言い分がいくつか入っている。言い分ごとに「これが成り立つには、何が成り立っていなければならないか」を問い、出たものを条件にする。

痛みの場面や観点（使いやすさ、速さ、自動であること）から条件を寄せ集めない。寄せ集めると、アウトカムに届くのに要らない好みが混ざり、要る条件が抜ける。

例として、振替の件のアウトカム「振替のことを妻が一人で抱えず、二人のどちらが動いても、使える振替を期限の内に使い切れている」は、三つの言い分に割れる。ア 妻が一人で抱えない。イ 二人のどちらが動いても。ウ 使える振替を期限の内に使い切る。イを問うと「欠席を連絡した人が、もう片方に頼らずに、その欠席を記録できる」が出る。痛みの場面から寄せ集めた前の要求には、これが無かった。記録は妻がするという前提に、気づかず立っていたためである。

- 揃えば満たした: 全ての言い分から条件が出ている。全ての条件について、どの言い分から出たかを言える。
- 外れている時（どの言い分からも出ない条件がある）: 「1分以内に記録できる」「計算が自動で行われる」。手段を比べる時の好みであり、条件ではない。どう解くか層の、得るもの・払うものへ回す。
- 外れている時（アウトカムを超える上乗せがある）: 「予約まで任せられる」。使い切るのに、予約を人に任せる必要は無い。
- 外れている時（主語が言い分より狭い）: 言い分が「二人のどちらが動いても」なのに、「夫が、妻に聞かずに知れる」と書く。妻が知れることも同じく要る。

必要なもの（must）と、あれば嬉しいもの（better）には分けない。言い分から出たものは全て、欠ければアウトカムに届かない。言い分から出ないものは、条件ではない。

#### 2. 全ての条件が成り立っているのに、言い分が崩れる日を作る

条件は、一つずつ見れば、それぞれ正しく書けていることがある。それでも、全ての条件が成り立つのに言い分が崩れる日があるなら、条件と条件の間に隙間がある。崩れる日は、条件同士の関連を見定め、条件群の輪郭（どこまでを覆い、どこに隙間があるか）を捉えるために作る。

全ての条件が成り立っていると置いたうえで、それでも言い分が崩れる具体的な一日を、言い分ごとに作る。作れたら、十分ではない。作れなければ、その言い分については十分である。

日は、次の四つの進め方を手がかりに作る。進め方は日を作る手がかりであり、日の分類ではない。どの進め方からとも言いにくい日は、そのまま書く。

| 進め方 | 問うこと |
| --- | --- |
| 条件の間を辿る | 言い分に沿って、ある条件が成り立った次の一歩が、どの条件にも無いことは無いか |
| 時を進める | 一週間後、三か月後、一年後に、言い分はまだ成り立っているか |
| 人を抜く | 片方が二週間いない時、片方が忙しい月に、言い分は成り立っているか |
| 外を変える | 相手の決まり、使っている道具が変わった時に、言い分は成り立っているか |

手段が無いと問えないこと（同じ事実を二か所に置いた時に片方だけが変わる、作ったものが止まる）は、この層では問わない。[どう解くか](how-to-solve.md)層が、選択肢ごとに崩れやすい時点で問う。

作れた崩れ方は、次の四つのどれかに分ける。分け方で、打ち手が違う。

| 崩れ方 | 打ち手 |
| --- | --- |
| 条件が足りない。利用者の手の内で、まだ条件にしていないことがある | 条件を足す |
| 条件の一文が緩い。条件はあるが、崩れる日を許す言い方になっている | 一文を締める |
| 利用者の手の外にある（相手の都合、空き枠、体調等） | 条件で寄せる（手の内で、崩れにくくする条件を足す）か、届かないものとして受け入れ、その旨を書く。どちらを取るかは、利用者の採否であり、閉じの論点にする |
| アウトカムの言い方が強すぎる、または近づいたかの測りが無い | なぜ作るか層へ返す |

振替の件で作った日の例を挙げる。

- 二人とも期限の7日前に気づいたが、二人とも「相手が予約するだろう」と思い、どちらも予約しなかった（条件の間を辿る）。気づく条件は成り立っているが、気づくことと予約することの間に、誰が予約するかという隙間がある。条件を一つずつ見ても、この隙間は見えない。条件が足りない。「気づいた日のうちに、その振替を予約する人が一人に決まる」を足す。
- 予約する人に決めた夫が二週間の出張中で、予約しなかった（人を抜いた日）。一文が緩い。「予約の締切までに予約できる人に決まる」に締める。
- 期限までの振替の枠が、全て埋まっていた。手の外である。欠席したその週のうちに振替の日を決める条件で寄せるか、空き枠が無く使えない振替は失効として受け入れるかを、利用者が決める。
- 条件は全て成り立ち、失効も無いが、妻が不安で毎週こっそり教室のアプリを確かめている。アウトカムの測りが無い。妻の頭から振替が外れたかを測りに入れるかを、なぜ作るか層で見直す。

- 揃えば満たした: 言い分×進め方の全ての枡に、作れた日（崩れ方と打ち手）か、作れなかったことが書かれている。作れた崩れ方を全て四つのどれかに分け、打ち手を決めた。
- 外れている時（作っていない進め方がある）: 時を進める日だけを作り、人を抜く日、外を変える日を作っていない。振替の件では、人を抜く日を作らなかったため、予約する人が不在の日を一度落とした。
- 外れている時（条件を一つずつ見るだけ）: 条件ごとに、その条件が崩れる日だけを作る。条件どうしの間の隙間（気づいた後に、誰が予約するか）が見えない。
- 外れている時（崩れ方を分けずに条件を足す）: 手の外にある空き枠を、条件の一文で満たしたことにする。利用者が受け入れるか寄せるかを決める場面が消える。

#### 3. 一文の形にし、確かめ方を付ける

一文は、手段を比べる物差しである。どんな手段を当てても、満たす／満たさないが迷わず決まらなければならない。決められない一文は、判定を比べる人の感覚に預ける。

| 部分 | 中身 | 無いと |
| --- | --- | --- |
| 誰が | 言い分から出る主語。言い分が「どちらも」なら「二人のどちらも」 | 主語が狭くなる |
| いつ | その人が何かを決める、または行う時点。出来事（欠席した時、予約しようとする時）か、期限からの距離（予約の締切の◯日前まで） | 「すぐ」「いつでも」になり、手段が満たすかを決められない |
| 何が成り立つか | その時点で、その人が知れること・できること・取り違えないこと。決めるのに要る一件ずつの事実で書く。集計は、決めるのに集計が要る時だけにする | 「残り回数」のように、何を指すかが割れる |
| どこまで | 満たしたと言える最低の線。取り違えない、のように許す幅が無いものは「一件も」と書く | 程度のある条件で、どこからが満たしたかが決まらない |
| 確かめ方 | その人がその時点で答えられる問い、またはできる行い | 一文が言葉だけになり、判定できない |

確かめ方は、言える・できるだけでなく、言ったものが本当の記録（相手の規則、相手の仕組みにある記録）と一致するかまで問う。一文の述語は、確かめ方と同じ強さにする。

例として、「欠席を連絡した人が、その日のうちに記録できる」は、確かめ方「連絡した日に記録が済んでいる」より緩い。記録を忘れても、一文は破られない。「その日のうちに記録されている」に締める。また、確かめ方「夫が期限と予約の締切を言える」は、規則が変わって古い期限を言えてしまっても、満たすと出る。「言え、それが教室の規則と一致する」に締める。

決められるかは、性質の大きく違う二つの手段（例: 紙とホワイトボードだけのやり方と、作る仕組み）を当てて試す。どちらかで「一部」「場合による」と言いたくなったら、一文のどこか（いつ、何が、どこまで）が緩い。

- 揃えば満たした: 全ての条件について、性質の違う二つの手段のどちらでも、満たす／満たさないが迷わず決まる。手段の言葉が無い。確かめ方が本当の記録と一致するかまで問い、述語が確かめ方と同じ強さである。
- 外れている時（何を指すかが割れる言葉がある）: 振替の件の前の要求「どの振替がいつまで何回残るかを知れる」。残り回数が、期間ごとの上限の残りと、まだ使っていない振替の数の、どちらとも読めた。家族のカレンダーの道を当てると、判定が「一部」に割れた。
- 外れている時（手段の言葉がある）: 「期限前にLINEで知らせが届く」。知らせる手段の違う道（カレンダーの通知、毎日見るボード）と比べられない。満たすべき条件は「予約の締切の◯日前までに、二人のどちらかが、その振替に気づく」である。

#### 4. 要るか、どこまでかが決まらない条件を扱う

条件には、入れるか迷うものと、程度のあるものが残る。推測で線を置かずに、何で決まるかで扱いを分ける。

| 種類 | 例（振替の件） | 扱い |
| --- | --- | --- |
| 程度がある（満たすほど良く、どこかに最低の線がある） | 気づく時期。早いほど空き枠が取りやすいが、最低限は予約の締切より前 | 最低の線を一文の「どこまで」に書く。最低の線より上の良さは、条件ではなく、どう解くか層の得るもの・払うものへ回す |
| 最低の線が事実に依る | 気づく時期の最低の線は、教室の枠がどれくらい早く埋まるかで決まる | 「どこまで」を空けたまま、何の事実で決まるかを書き、利用者に事実として問う（認識合わせ） |
| 要るかが事実に依る | 「二人のどちらも、教室へ欠席を連絡できる」。夫が欠席を連絡することが実際にあるかで、要るかが変わる | 何が分かれば入る・入らないが決まるかを書き、利用者に事実として問う（認識合わせ） |
| 要るかが利用者の考えに依る | 「妻が確かめに行かなくても回っていると、妻が思えている」。妻の安心をアウトカムに含めるか | なぜ作るか層へ返す（アウトカムの言い方と測り） |

- 揃えば満たした: 迷う条件と程度のある条件の全てに、四つのどの扱いかが付いている。事実に依るものは利用者に問い、答えを得ている。
- 外れている時: 最低の線を推測で置く。例: 枠の埋まり方を問わずに「締切の7日前」と書く。

### 止める時

全ての言い分から条件を導き、全ての言い分で崩れる日を作ろうとして崩れ方を分け終え、全ての条件が一文と確かめ方で書け、迷う条件と程度のある条件の扱いが決まり、事実として問うものの答えを得た時に止める。

### この決め方の限界

一般には、関係する人を集めて要件を洗い出し、受け入れ条件（この状況で、こうしたら、こうなる）として書いて合意する。この層の一文と確かめ方は、受け入れ条件に当たる。

個人の企画では、条件を利用者とassistantで導くため、利用者の視野の外にいる人（相手の教室や店、他の家族、自分以外の利用者）の見方が落ちる。崩れる日も、二人が思い描ける日に限られる。自分以外も使う時は、材料`target-user-voices`の声とも照らし、落ちた見方を補う。
