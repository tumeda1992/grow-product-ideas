# なぜ作るか（why-to-build）

この層は、「何のために作るか」を決める。決めるものは、痛み、アウトカム、作ることで得たいもの、の三つである。

受け入れ時の入力（アイデア、作りたい動機、既にある着想）は、ほぼ手段の言葉（管理したい、通知が来ればいい）と、見えている症状（失効をなくしたい）で来る。この層は、そこから痛む人の体験に深く潜り、痛みの解像度を上げたうえで、次の[何が成り立てばよいか](what-must-hold.md)層が物差しにできるアウトカムに畳む。畳むことは、小さくすることではない。広げた体験を捨てずに、物差しと、下の層へ渡す材料にすることである。

作るか、作らないかは、この層では判定しない。比べる相手（作らない道、費用）が揃う[どう解くか](how-to-solve.md)層が判定する。

## この層の閉じ

閉じで、利用者は次を確かめ、論点ごとに応答する。

- 痛みの核心と、それを痛む人の語りから取ったか（依頼した人の見立てのままではないか）
- アウトカムの姿（言い分）と大きさ（含めたもの、外したものと理由）
- 近づいたかの測り
- 作ることで得たいものの内訳と、それぞれの強さ

## 痛み

### 何を決めるか

誰が、どの場面で、何に困り、今どうしのいでいるかを、一件ずつ。そのうえで、他の痛みを生んでいる核心と、原因の連なり、解く値打ちの大きさと、痛みが続く期間。

後ろでは、次のように使われる。

- アウトカムの根になる（この層の決め方の4）
- `propose-alternatives`が、痛みの構造（原因、一人に寄るか、期限・残数）から切り口を選ぶ
- どう解くか層が、満たさずに受け入れる条件を選ぶ時に、失うものを読む
- 正本を読む人が、誰の何のためのプロダクトかを知る

## アウトカム

### 何を決めるか

痛みが解けた時に何が成り立っていればよいかの状態である。着想をほどき、どの手段でも満たしうる状態に戻したもの。三つを持つ。

| 持つもの | 中身 |
| --- | --- |
| 姿 | 一文の言い切り。誰の暮らしで、何が成り立ち、それが続いているか。手段の言葉（通知、一覧、アプリ、LINE、カレンダー等）を含まない。成り立っていなければならない言い分に割れ、言い分ごとに条件を導ける。満たすべき条件が全て満たされれば届く状態であり、気持ちそのものは姿に置かない |
| 大きさ | どこまでを解けた姿に含めるか。含めたものと、外したもの（同じ形の痛み、アウトカムを超える上乗せ等）と、外した理由 |
| 測り | 近づいたかを、いつ、何で見るか。核心が解けたか、症状が消えたか、痛む人の気持ち（頭から外れたか、自責が無くなったか）が変わったか、のそれぞれ |

後ろでは、次のように使われる。

- 何が成り立てばよいか層が、姿を言い分に割り、満たすべき条件を導く。外したものの条件は足さない
- どう解くか層が、外したものを覆う選択肢を、得るものに数えない
- 作った後に、測りで、痛みが解けたかを見る

## 作ることで得たいもの

### 何を決めるか

痛みを解くことと、作ること自体（作る楽しみ、学び、自分の道具を持つこと）を分けたもの。それぞれについて、それだけが満たされなくても、やる意味が残るか。作りたいのはこの題材でか、題材は問わないか。

後ろでは、どう解くか層が、得るものの軸「得たいもの」と、選定の「作る理由の切り分け」に使い、作る所を得たいものだけを理由に選ぶ時に照らす。

## 決め方

### 1. 受け取った言葉を仕分ける

受け入れ時の入力を、言葉ごとに、目的・症状・手段・楽しみのどれかに分ける。手段（管理する、通知、LINE）は、どう解くか層へ預ける。ただし捨てずに、なぜその手段を思いついたか（毎日見る所に来てほしい、自分からは見に行かない）を、2で潜る入口にする。

- 揃えば満たした: 入力の全ての言葉が、四つのどれかに分けられている。手段の言葉が、痛みにもアウトカムにも残っていない。
- 外れている時: 着想（「期限の前にLINEで通知が来ればいい」）をそのまま目標にする。下の層は、それを物差しとして正しく受け取り、症状だけを消す手段を正しく選ぶ。

### 2. 痛む人の体験に潜り、広げ切る

広げることの中心は、痛む人の体験に深く潜ることである。痛む本人に、直近の一回の出来事を、時系列で、その時何をし、何を考え、何を感じたかと一緒に語ってもらう。ふだんの一週間と、どうなっていたいかも語ってもらう。

先に、声の出どころを確かめる。依頼した人と、最も痛む人が違うことがある。違う時は、依頼した人が痛む人に聞き、その答えとして書く。聞けない時は、聞けなかったことと、依頼した人の見立てであることを書く。

次の入口から潜る。入口は潜るための手がかりであり、埋める枡ではない。

| 入口 | 問うこと |
| --- | --- |
| ものごとの一生 | 対象が生まれてから消えるまでの段のどこで、何が痛むか |
| 人 | 関わる人は誰で、それぞれ何を担い、何に困り、何を得るか |
| 実際に起きたこと | 直近に、実際に何が起きたか。ヒヤリとしただけか |
| 今のしのぎ方 | 今どうしのぎ、それに何がかかり、どこで破れるか |
| 着想の裏 | なぜその手段を思いついたか。別の目的が隠れていないか |
| 隣の痛み | 同じ形（期限、残数、一人に寄る）の痛みが、他にあるか |
| 解いた後 | 解けた時に、誰が何を新しく引き受け、何を失うか。それに同意しているか |
| 期間 | この痛みは、いつまで続くか |

場面ごとに、行い、頭の中、気持ちを書く。

例として、振替の件で妻の直近の失効の一回を語ってもらうと、「あなたに言ったら『言ってくれれば予約したのに』って言われて、それがまた嫌だった。言うって、何を？」が出た。夫は頼まれれば代われるが、自分では気づけないため、頼むことまで妻の仕事になっていた。痛みを一行で「妻だけが担う」と書いた時には、見えていなかった。

- 揃えば満たした: 痛む人の言葉で、場面ごとの行いと、頭の中と、気持ちが語れる解像度になっている。声の出どころが書かれている。新しい入口から潜っても、新しい痛み、新しい人、新しい事実が出ない。
- 外れている時（入口の点検で済ませる）: 入口ごとに一行ずつ答え、潜らずに畳みへ進む。痛みの解像度が上がらず、核心は一行の分類から選ぶことになる。
- 外れている時（依頼した人の見立てのまま）: 振替の件の前の記録は、妻の痛みを夫の見立てのまま書いていた。

### 3. 痛みを吸い出し、つなぐ

広げたものから、痛みを一件ずつ取り出し、どれがどれを生むかをつなぐ。

- 揃えば満たした: 全ての痛みが一件ずつ取り出され、どの痛みが他を生むかがつながっている。
- 外れている時: 痛みを並べるだけで、つながりが無い。核心を、頻度や声の大きさで選ぶことになる。

### 4. 畳む

次の順に畳む。

| 段 | 何をするか |
| --- | --- |
| 核心を選ぶ | 他の痛みを生んでいる痛みを核心にする。「なぜ」を一段深めても、下の層の条件が変わらなくなる所で止める。深く降りすぎると（家事の分担の全般、家族の幸せ）、物差しにならない |
| どうなっていたいかを取る | 痛む人がどうなっていたいかを、その人の言葉で取る |
| 姿を書く | どうなっていたいかを、条件で届く状態として、手段の言葉を使わずに一文にする。気持ちは姿に置かず、測りへ回す |
| 大きさを選ぶ | 含めるものと、外すものと、外す理由を書く |
| 測りを付ける | 核心、症状、気持ちのそれぞれに、いつ、何で見るかを付ける |
| 値打ちと期間を出す | 損失×頻度×期間と、お金にならない負担（頭の負担、自責、子どもへの申し訳なさ）から、かけてよい重さの見当を出す。作る楽しみの分は別にする |

畳む時に、広げたものを三つに分ける。アウトカムに入れるもの、外したもの、下の層へ渡す材料（痛む人の望みのうち、アウトカムでも外したものでもないもの。例: 妻の「ピアノは自分でやりたい」）。広げた体験の表は、層の記録に残し、下の層へ渡す。

例として、振替の件の姿は「振替について知っておくべきことが妻の頭の外にあり、妻が覚えていなくても、頼まなくても、二人のどちらも自分で気づいて動け、使える振替を期限の内に使い切れている状態が続いている」になった。言い分は四つに割れる（ア 妻の頭の外にあり、覚えていなくてよい、イ 頼まなくても、二人のどちらも自分で気づいて動ける、ウ 期限の内に使い切る、エ 続いている）。妻が「覚えていなくても大丈夫と思えている」ことは、条件では確かめられないため、測りに置いた。

- 揃えば満たした: 核心から姿が導かれ、姿が言い分に割れ、手段の言葉と気持ちを含まない。大きさに、外したものと理由がある。測りが、核心・症状・気持ちのそれぞれにある。値打ちと期間が、お金にならないものを含めて書かれている。広げたものが、三つのどれかに分けられている。
- 外れている時（症状の裏返し）: 「失効しない」。核心（妻の頭の中にしかない）を落とす。
- 外れている時（気持ちを姿に置く）: 「振替のことが、妻の頭に居座らなくても」を姿の中心にする。条件を全て満たしても届いたと言えず、何が成り立てばよいか層の物差しにならない。
- 外れている時（小さく畳むことを目的にする）: 止めどころと外すものだけで畳み、広げた体験を捨てる。下の層が、最も余裕の無い場面（子どもが熱を出した朝）を知らずに、そこへ手間を足す。

### 5. 作ることで得たいものを分ける

作りたい動機の言葉から、痛みを解くことと、作ること自体（作る楽しみ、学び、自分の道具を持つこと）を分ける。それぞれについて、それだけが満たされなくても、やる意味が残るかを問う。作ること自体を得たい時は、この題材でか、題材は問わないかを問う。題材を問わないなら、痛みは作らない道で解き、作る楽しみは別の題材で満たす道もある。

- 揃えば満たした: 得たいものが分けられ、それぞれに、それだけで、やる意味が残るかと、題材を問うかが書かれている。
- 外れている時: 「作りたいから」。動機の写しであり、どう解くか層で作る理由を切り分けられない。

### 止める時

痛む人の語りで、場面ごとの行いと頭の中と気持ちが語れ、新しい入口でも新しいものが出なくなり、痛みがつながり、アウトカム（姿、大きさ、測り）と値打ちと期間が書け、得たいものが分けられ、広げたものが三つに分けられた時に止める。

### この決め方の限界

一般には、想定する利用者へのインタビューで、直近の出来事を時系列で語ってもらい（出来事の振り返り、一日の流れの再現）、痛みと、利用者が成し遂げたいこと（ジョブ）を取り出す。作るもの（アウトプット）と、それで起きてほしい変化（アウトカム）を分ける。

個人の企画では、痛む人が家族であることが多く、依頼した人の見立てが混ざりやすい。痛む人に語ってもらっても、家族の間では言いにくいこと（自責、相手への苛立ち）が落ちる。自分以外も使う時は、声を上げない人の痛みが落ちる。
